## 論述基礎與限制

本卡從兩句被使用者指出的條目文字抽出：「薄，而且它做的事情很單純」與「它不打算說服誰，它示範」。指正的理由：對根本沒看到這本書的讀者，書薄不薄、作者有沒有打算說服誰，都不是讀者要關注的點——書單文章的定位是引導讀者的知識需求，不是書評。回頭看同一批修訂，先前被使用者刪掉的「中譯本 504 頁」是同一條原則的第一個實例。依判斷標準掃整條書單線，「薄」另有三處命中、判定各異（一處純鑑賞刪除、一處翻成讀者側的時間語言、一處覆蓋狀態合法保留），連同起始兩句共五個實例。

限制：實例集中在書單文體；判斷標準（資訊要改變讀者的決定）推廣到其他策展內容（工具清單、課程清單）是機制類比、未在那些文體實測。

## 核心原則

**條目資訊的準入條件是讀者的決定：這個資訊改變讀者的哪個決定——要不要讀、什麼時候讀、怎麼讀、選哪個版本、去哪裡取得。指不出對應決定的觀察，是書評內容，不進條目。**

機制在視角：寫條目的人手上有這本書，視角自然滑進「描述這本書」的位置——那是書評人的位置，對象是書、動作是鑑賞。讀者沒看過書，站在決定的位置，對象是自己的知識需求。物件觀察（厚薄、頁數、裝幀）與作者姿態的鑑賞（打不打算說服誰、文筆如何）服務的是鑑賞情境；在引導情境裡它們是讀者不需要的資訊，佔掉的是條目的注意力預算。

這是借來的讀者框架家族的第四個成員：演講姿態把讀者當聽眾、書評體壓縮把讀者當地圖共享者、考核框架把讀者當受試者，本卡的書評視角把讀者當**鑑賞者**。跟 [#270](../decodable-from-text-already-read/) 借自同一個來源文體、借的東西不同——#270 借的是書評體的密度審美（形式層），本卡借的是書評的內容選擇（資訊層）。家族的現況清單以 [#254](../write-for-readers-not-audiences/) 的關係段為準。

## 判定與邊界

判定逐項可執行：對條目裡的每個資訊問「它改變讀者的哪個決定」。五個實例的判定示範了三種出口：

1. **指不出決定——刪除。**「薄，而且它做的事情很單純」：薄改變不了任何決定，刪掉後句子直接從「做的事情很單純」起步。「它不打算說服誰，它示範」：姿態鑑賞，而且它重複了前半句已經交代的證據形態（「演練而非論證」），整句刪除零損失。「這本薄，而且整本只推一個主張」同型：決定資訊在「只推一個主張」，薄是搭車的鑑賞。
2. **承載決定資訊——翻成讀者側的語言。**「這本書很薄，整本在回答這一個問題」出現在共讀選書的脈絡，薄承載的是時間成本、而時間成本改變共讀決定——保留資訊、換掉物件語言：「整本只回答這一個問題，很快就能讀完」。先前的「中譯本 504 頁，適合分段讀」同型：物件數字刪除、讀法決定保留（「不需要通讀，只讀其中一個章節都會有幫助」）。物件側的量（頁數、薄厚）翻成讀者側的行動（讀多久、怎麼讀）。
3. **對象不是書——不觸發。**「這一格的書單覆蓋最薄」的主詞是書單自己的覆蓋狀態，它告訴讀者這一塊沒有書可以指，直接服務讀者的預期——合法保留。

**留下來的物理與形式事實都要指得出決定**：「主體是圖表而非敘述」改變怎麼讀、「查不到中譯本、台灣通路要另外訂」改變怎麼取得、「細到會讓第一次讀的人覺得沒必要」設定閱讀預期、出版年份服務時效判定。同一類詞（薄）在不同句子裡判定不同——命中是候選不是判決，判定看資訊對到哪個決定。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------------ |
| 條目出現厚薄、頁數、裝幀、文筆、作者姿態的描述       | 問它改變讀者的哪個決定；指不出就刪，指得出就翻成讀者側的語言             |
| 物件側的量（504 頁、很薄）緊鄰一個讀法建議           | 量刪掉、讀法決定留下並寫成行動（不需要通讀、只讀一章也有幫助）           |
| 一句鑑賞跟在框架欄位的事實後面重複同一件事           | 鑑賞句整句刪除——事實已由欄位承載，重複的只有姿態                         |
| 「薄」的主詞是覆蓋、清單、預算這類非對象實體         | 不觸發——那是狀態陳述不是鑑賞，照決定測試判定                             |
| 寫條目時發現自己在描述書、而不是在回答讀者的哪個決定 | 視角滑進鑑賞位置的訊號——回到決定清單：要不要讀、何時讀、怎麼讀、去哪取得 |
