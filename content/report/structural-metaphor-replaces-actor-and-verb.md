## 論述基礎與限制

這張卡來自 2026-10-29 一次書單分類的擴充。站上的書單分類早期寫成三條「書線」，各篇用「這條線處理的是…」「另外兩條線」「四本各接一個面」「由 X 承接」「走 [某篇]」「判定住在某篇」「這條線的決定落在錢上」這組詞組織內容。agent 以這批舊文章為範本新寫一個書單，七個新檔照抄了同一組詞。使用者讀新稿時指出三類缺陷：「這條線」當主詞（單位名應該是「書單」）、「X 的決定落在 Y」誤用代名詞（決定是讀者做的，應寫「X 書單討論的主題放在 Y 上」）、「四本各接一個面」是廢話而且省略了主詞、用錯了動詞（應寫「這四本各自討論不同的面向」再逐本寫出）。

改寫之前在舊的 40 個檔裡量過命中：「線」當單位名 128 處、「承接／接得住／一個面」111 處、「決定落在／決定的對象」8 處。六個 agent 平行重寫之後，剩下的命中逐處判定為不同的意思（「技術路線」指職涯路徑、引號內示範對話的「那條線」指一條工作流）。個案只有這一個集合；其他集合有沒有自己的一組結構譬喻沒有量過。

## 核心原則

**集合的組織者替自己的結構取了空間與搬運的名字，這組名字之後被寫進正文，佔住了主詞與動詞的位置。** 寫第一批文章的人在腦中把分類想成幾條平行的「線」，每一篇「承接」一個題目，讀者沿著連結「走」到下一篇，判定「住在」某一篇。這組詞對組織者是一張方便的地圖；寫進正文之後，每一句的主詞與動詞換成了地圖上的元素：「這條線處理的是資本怎麼配置」的主詞是一條線，而做「處理」的是這個書單收的書；「四本各接一個面」的動詞是「接」，而每一本實際做的是討論、分析、記錄、量測某一件事；「走 [某篇]」的動作者是讀者，而讀者實際做的是讀那一篇。讀者讀這些句子時要先把譬喻換回實際的主詞與動作，換不回來時就只剩一句聽起來在交代分工、實際沒說出誰做了什麼的話。

**這組詞會通過範本傳下去。** 寫新文章的人（或 agent）以集合裡的舊文章為範本時，抄走的不只結構與段落順序，還有句型。舊文章裡的譬喻讀起來像這個集合的慣用語，於是新稿照用，而且用得更密：新稿的作者沒有那張地圖，只拿到詞。量測在這裡很清楚：同一組詞在舊檔裡的分佈，在新稿的七個檔裡幾乎原樣出現，連「X 的決定落在 Y」這個代名詞錯誤也一起複製了。

**三種形態各自藏掉不同的槽位**：譬喻當單位名藏掉主詞，搬運與居住動詞藏掉動作，轉化句藏掉動作者。

- **譬喻當單位名**（線、面、側）：佔住主詞或受詞，讀者不知道句子在講哪一個實體。修法是換成集合裡實際的單位名（書單、主題篇、面向）。
- **搬運與居住動詞**（接、承接、接得住、走、住在、落在）：佔住動詞，讀者不知道實際的動作是什麼。修法是寫出那個動作（討論、涵蓋、收在、讀、寫在）與它的動作者。
- **轉化句**（「把 X 從印象變成數字」「X 的決定落在 Y 上」）：把動作者藏在一個抽象的轉化或歸屬後面。「Accelerate 的價值是把團隊做得好不好從印象變成數字」裡，做事的是讀者，動作是用四項量測取代印象；「財務書單的決定落在錢上」裡，決定是讀者做的，書單做的是把討論的主題放在錢上。修法是寫出誰用什麼取代什麼、誰討論什麼。

## 反模式

- **用分類的組織譬喻寫正文**：「這條線」「另外兩條線」「管理線」寫進讀者看得到的文章，讀者要先知道作者心中的那張地圖。
- **「各接一個面」當分工句**：這一句交付的只有「每本書不一樣」，每一本做了什麼要讀者自己去讀各節；寫出來的時候，句子本身就是分工。
- **以舊文章為範本而不先掃它的句型**：範本的缺陷照抄進新稿，而且新稿的作者手上沒有那張地圖，比舊文章更難讀。
- **只修新稿**：舊文章裡的同一組詞留著，下一次以舊文章為範本時又被抄走。

## 修法

1. **寫新稿之前先掃範本**：用這個集合自己的那一組譬喻詞（這一次是 `條線|書線|承接|接得住|一個面|決定落在|走《|承擔的角色|住在`）掃要拿來當範本的舊文章，命中密集時先修範本、或至少在新稿裡不抄那幾種句型。
2. **單位名用集合裡實際的名字**：每一個「線」「面」換成它在讀者那一側的名字（書單、主題篇、面向），比較時寫「其他書單」「另外兩個書單」。
3. **每一個搬運與居住動詞換成實際的動作**：「各接一個面」→「這四本各自討論不同的面向：《A》討論…，《B》分析…」；「由課程承接」→「這門課涵蓋…」；「走 [某篇]」→「讀 [某篇]」或「…收在 [某篇]」；「判定住在某篇」→「判定寫在某篇」。
4. **轉化句寫出動作者與動作**：「把 X 從 A 變成 B」→「用 B 取代對 X 的 A」，並寫出 B 是什麼；「X 的決定落在 Y」→「X 討論的主題放在 Y 上」。
5. **新稿與舊文章一起修**，否則下一次以舊文章為範本時同一組詞會再傳下去。

## 判讀徵兆

| 徵兆                                                     | 判讀                                                       |
| -------------------------------------------------------- | ---------------------------------------------------------- |
| 正文用「這條線」「那一面」「這一側」當主詞或受詞         | 作者的組織譬喻寫進了正文，主詞是地圖元素而不是實體         |
| 分工句寫「各接一個面」「由 X 承接」「接得住」            | 動詞是搬運譬喻，每一本實際做了什麼沒寫出來                 |
| 「走 [某篇]」「住在某篇」「落在 Y 上」                   | 讀者的動作（讀）與判定的位置（寫在）被換成移動與居住       |
| 新稿與集合裡的舊文章用同一組少見的詞，密度還更高         | 新稿以舊文章為範本，句型缺陷跟著傳下來                     |
| 改寫時要補出原文沒寫的主詞或對象，而補的內容要回原文核對 | 譬喻底下原本就沒有決定指什麼，補的時候可能補錯，要對照原文 |
