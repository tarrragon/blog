## 論述基礎與限制

證據來自一次三輪九個 reviewer 的審查（本站一篇 work-log），加上使用者對另一批教學章節開場段的指認。「reviewer 的建議偏向補脈絡」是從該次 finding 的分布觀察到的，未跨批量測；成分還原測試的判別力在該次的四個實例上成立，樣本小。實例集中在中文技術寫作與 LLM 生成稿，其他語言與人工寫作的分布未驗證。

## 核心原則

冷讀者回報「讀不懂」「脈絡不足」「這裡突然冒出來」時，症狀相同而根因有兩種，修法方向相反：

| 根因     | 缺的東西                     | 修法               | 動作方向     |
| -------- | ---------------------------- | ------------------ | ------------ |
| 脈絡缺失 | 讀者缺理解這段所需的背景知識 | 補前情、定義、路由 | 加內容       |
| 成分缺失 | 主詞、受詞、指稱對象被省略   | 把成分補回句子     | 改句子、不加 |

判別可以機械執行：**把主詞、受詞與指稱對象補回去之後，這句還讀不懂嗎**。補回去就懂了是成分問題，補回去仍不懂才是脈絡問題。

中文允許省略主詞，所以判定不是「這句有沒有主詞」，而是「冷讀者讀到這裡，當場指得出是誰在做這件事嗎」。脈絡清楚的位置不需要逐句補主詞，補了反而囉嗦。

## 為什麼預設會選錯

三個力量同時把診斷推向「補脈絡」。

**生成端**：LLM 圍繞發想視角生成，施事者在生成當下是預設值、不會被寫出來。一段教學文字可以整段沒有主詞而讀起來完整——「算得出每個輸入的正確答案時用逐例斷言，算不出答案但寫得出條件時用不變量⋯⋯那裡的工作交不出去」，誰在算、誰在寫、交給誰，全都留在生成者的視角裡。

**審查端**：兩種修法的成本不對稱。補脈絡是寫更多，那是 reviewer 天然的產出形態，也看得出貢獻；補成分要進到句子內部重組，產出看起來只是換句話說。建議因此偏向前者。

**規範端**：寫作規範近期加強語句完整、閱讀節奏與引導，這些要求本身會增加字數與主詞，方向是對的。但它讓「補」成為預設動作，於是兩種根因被導向同一個修法。

## 四種常見形態

| 形態                 | 實例                                       | 讀者答不出來的問題 |
| -------------------- | ------------------------------------------ | ------------------ |
| 無主詞的動作句       | 「會走到這一步的情境不只一種」             | 誰走到這一步       |
| 指稱懸空的代名詞     | 「兩件事促成它」                           | 它是什麼           |
| 施事者省略的中性句   | 「commit 被 push 上去」                    | 誰推的、推到哪裡   |
| 整段無施事者的機制句 | 「判準的形態可以退階⋯⋯那裡的工作交不出去」 | 誰判、誰算、交給誰 |

修法都是補成分，不是補段落：「作者把 commit 推上遠端的預設分支」比「這裡建議補充說明推送的流程」短，而且解決的是讀者真正卡住的地方。

## 沒這樣做的麻煩

誤診的修法加了內容，卻沒有解決原本的問題——主詞仍然不在。下一輪 reviewer 讀同一段，仍然回報讀不懂，於是再補一次。每一次補都正確、每一次都補在錯的層，文章因此持續膨脹，而膨脹本身製造第二個問題：主題離開原本的寫作動機（見 [#280](../review-rounds-need-a-return-to-purpose/)）。

## 判讀徵兆

| 徵兆                                                       | 判定                                             |
| ---------------------------------------------------------- | ------------------------------------------------ |
| reviewer 的建議是「這段建議補充說明」而指不出補什麼        | 多半是成分問題被讀成脈絡問題                     |
| 同一段落連續兩輪被回報讀不懂，而中間已經補過內容           | 補在錯的層，改做成分還原測試                     |
| 一整段讀得完、卻答不出這段在講誰做的事                     | 施事者缺失，補主詞而非補前情                     |
| 段落裡的「它」「這件事」「那一步」要回頭找兩句以上才對得上 | 指稱懸空，就地具名                               |
| 文章長度在審查過程中持續增加而問題不減                     | 診斷分流沒有做，同時要檢查主題有沒有發散（#280） |

## 這條原則什麼時候不成立

省略是中文的正常語法，段落內主詞連貫時逐句補主詞會讓文字囉嗦。判定的單位是冷讀者能不能當場復原，不是句子的成分完整度——脈絡清楚的位置，省略是對的寫法。

診斷分流也不適用於真正缺背景知識的段落：讀者沒有前置概念時，補主詞不會讓他讀懂，那時要補的確實是內容。兩種根因可以同時存在，成分還原測試的作用是把它們分開處理，不是主張永遠只有一種。
