## 論述基礎與限制

本卡從一次對照實驗抽出。受測材料是一句已知有歧義的中文，取自書單分類修正前的版本：

> 到站之後有一層換算要自己做：**那一篇的三本**都以公開發行公司的報表為材料，附註、分部資訊與關係人交易揭露在自家帳上不存在，能對得上的是**三表**之間的關係與各科目的意義。

兩個歧義點。`三本` 的量詞指向書，而同句尾的 `三表` 會污染它；`那一篇` 的最近先行詞是前一句剛提到的另一個模組，而作者的意圖是更前面的那一篇——那一篇實際收三本書，意圖可由該檔核對。

十個低階模型探針，指令逐字相同，只差讀到的範圍：A 組五份讀全文加該書線的相關篇（223 行），B 組五份只讀該段落（9 行）。判讀標準在派發前寫定。

限制有三層。**單一句子、單一語言對**，推廣到其他歧義形態是機制類比。**A 組不是作者自譯的忠實模擬**——它拿得到脈絡而不是意圖，所以它的意圖取用低於真正的自譯；這個缺口偏向不利於本卡的結論，而結論仍然成立，所以方向穩、量級可能被低估。**跨組比對違反一條既有紀律**（讀的範圍不同就是另一批、兩批之間不比對），這裡刻意違反是因為範圍差異正是被操作的自變項，因此結論的射程只到「意圖取用會不會改變輸出」。

推翻方式：拿一句作者有把握、而無脈絡讀者會讀錯的句子，讓有脈絡的譯者去譯，若它主動標記了那個歧義，本卡對那一類不成立。

## 核心原則

**翻譯探針的訊號來自譯者只拿得到文字，這個條件不可讓渡。** 分歧之所以能歸因到原文，前提是譯者無法用意圖補完；一旦譯者拿得到意圖——自己翻自己寫的段落是最極端的形態——中文留下的未決項會被照作者知道的那個讀法填上，填對了，而且不留痕跡。

**會傷到讀者的歧義，正好是作者毫無困難就能解決的那一種。** 作者當場猶豫的位置本來就會被寫清楚；問題出在作者從不猶豫、而讀者無從得知的位置。自譯對這一類全盲，因為它的盲區與作者的盲區重合。

實驗數據是完全分離：

|                        | A 組（有脈絡，n=5） | B 組（無脈絡，n=5） |
| ---------------------- | ------------------- | ------------------- |
| `三本` 譯成書          | 5/5（正確）         | 0/5                 |
| `三本` 譯成財務報表    | 0/5                 | 5/5（錯誤）         |
| 把 `三本` 列進不確定欄 | 0/5                 | 4/5                 |

沒有一份 A 組讀錯，沒有一份 B 組讀對，中間沒有重疊。在寫作當下產出英文的人，會拿到一份寫著 three books 的正確譯文，把它當成通過的證據，然後把這句原封不動發出去。**那份譯文不是檢驗，是一張錯誤的合格證明。**

## 脈絡解掉一部分歧義，並讓另一部分變糟

同一份材料的第二個歧義點走向相反。`那一篇` 的先行詞，A 組有四份主動標記為無法確定——但四份的猜測**全部猜錯**，都指向前一句剛提到的那個模組。B 組沒有任何一份觸及它。

更完整的脈絡在這裡沒有幫助，因為它供給了一個看起來合理的錯誤候選。兩份 A 組報告同時**正確列出了那三本書的書名**，卻把它們判給錯的文章——掌握成員清單而認錯住址。這代表原文的問題不是說得不夠清楚，是句法主動把讀者拉向最近的先行詞。

所以脈絡取用對兩類歧義的作用是相反的：**它解掉「這個詞指哪一類對象」，而讓「這個指涉詞綁到誰」更難察覺**，因為錯的候選現在有了證據。

## 反模式

**把自己產出的譯文當成校對。** 這個做法對作者能解決的歧義全盲，而那是傷害讀者的主要一類。它同時要付兩份內容的維護成本，而過期的譯文比沒有譯文更糟——[#268](/report/current-content-needs-a-carrier-that-reaches-readers/) 的失效在這裡以雙語形態出現。

**翻不出來就把那個成分刪掉。** 一份 A 組譯文把 `那一篇` 整個從句中移除，不確定欄只字未提。譯文通順、中文毫髮無傷、訊號歸零——這是自譯最糟的失效形態，因為它連「翻譯卡住了」這個間接訊號都消掉。判讀報告時要逐項核對原文的成分有沒有在譯文裡出現，只讀譯文順不順會漏掉它。

**用「有沒有英文版」代替「有幾份獨立的英文版」。** 訊號的單位是份與份之間的分歧，不是譯文的存在。一份譯文無論多正確都不產生分歧。

## 修法

**探針往前移、單位縮小，不要改成自己產出。** 每一節的命題收斂之後就對承重段落跑一次，不必等全篇寫完；[#286](/report/translation-forces-disambiguation/) 的順序限制是逐節成立的。九行輸入的 B 組 5/5 抓到那個誤讀，成本是全篇雙語的零頭。

**寫作端要留下的是一個問句，不是譯文。** 寫到指涉詞（那一篇、前者、三本、它）的時候問一句——**沒讀過前文的人拿這一句，能不能定位到唯一的對象**。答不出來就當場具名。A 組標記出來的那一類，不產出譯文也拿得到。

**全篇雙語只在英文本身是交付物時才做。** 那時消歧是附帶收益，維護成本本來就要付。為了消歧而產出的譯文沒有讀者，維護它的動機隨時間歸零，而它會以正確的姿態留在旁邊。

**判讀有脈絡的報告時，把「沒有標記」讀成沒有資訊，不要讀成沒有問題。** A 組在 `三本` 上零標記，而那正是錯得最徹底的一項。

## 判讀徵兆

| 徵兆                                       | 為什麼是訊號                                 | 下一個動作                   |
| ------------------------------------------ | -------------------------------------------- | ---------------------------- |
| 譯者與作者是同一個實例                     | 意圖會補完文字的缺口，且不留痕跡             | 換成只拿得到文字的譯者重跑   |
| 譯文正確而不確定欄空白                     | 這是意圖取用的形態，不是文字清楚的形態       | 拿同一句給無脈絡的譯者對照   |
| 譯文通順而原文的某個成分不在裡面           | 翻不出來的處理是刪掉，訊號被一併刪掉         | 逐項核對原文成分在譯文的落點 |
| 有脈絡的譯者對某個指涉全數標記、而猜測不一 | 脈絡供給了看起來合理的錯誤候選               | 這個指涉要具名，脈絡救不回來 |
| 譯者列得出正確的成員，卻認錯了它的出處     | 句法把讀者拉向最近的先行詞                   | 改寫指涉，不是補說明         |
| 為了消歧而產出的譯文放著沒人讀             | 它的維護動機歸零，而它會以正確的姿態留著誤導 | 用完即棄，或改回獨立探針     |

## 這條原則什麼時候不成立

英文本身是交付物時不成立。那裡兩份內容都有讀者，消歧是順帶拿到的，判斷退回一般的雙語維護問題。

歧義的兩個讀法作者自己也決定不了時不成立——那一類自譯抓得到（實驗裡 `那一篇` 的四份標記），因為作者的困難就是譯者的困難。可操作的分辨是問作者：這個詞你當初想的是哪一個；答得出來就落在本卡的射程內。

譯者與作者是不同的人或不同的實例、而且只交付了文字時不成立。那已經是獨立探針，本卡談的是意圖取用，不是同一個工序。

## 跟其他抽象層原則的關係

[#286 翻譯強制消歧](/report/translation-forces-disambiguation/) 是本卡限定邊界的對象。那張說明機制（中文允許不決定的語法項，英文強制決定），本卡補的是那個機制成立的前提：**強制決定的是譯者，而譯者用什麼來決定，決定了這個探針測得到什麼**。拿得到意圖的譯者一樣會強制決定，只是決定得對——機制照常運作，訊號消失。實驗同時再現了 #286 的補述（收斂到同一個誤讀也是訊號）：B 組 5/5 收斂到錯的讀法，其中一份還沒有把它列進不確定欄。

[#281 理解檢查用低階 model 取樣讀者的實際理解](/report/comprehension-sampled-not-judged/) 的五個設計條件裡，「指令逐字相同」處理的是份與份之間的可比性。本卡補的是另一個維度的同一件事：**餵給每一份的內容範圍也要受控，而且它的作用比指令措辭更大**。實驗裡兩組指令逐字相同、只差讀的範圍，結果完全分離。

[#289 一個詞是不是通用術語，用多份獨立定義的收斂度量](/report/term-probe-measures-register-not-invention/) 是同一個獨立性要求在另一個受測單位上的形態。那裡的對應設計是控制詞（證明分歧可歸因到詞），這裡是脈絡隔離（證明分歧可歸因到文字）。兩者要防的是同一件事：報告上的分歧或收斂，來自受測對象還是來自量測條件。

[#270 敘事的解碼材料要在讀者已讀的文本裡](/report/decodable-from-text-already-read/) 是被違反的那條原則本身，本卡是它的偵測面。那張的判定問句（讀者線性首讀能不能當場復原完整命題）在這裡有了量測形態，而量測顯示**作者側執行那個問句是無效的**——A 組的意圖取用讓它每次都答得出來。

[#168 多輪審查要有冷讀者 frame](/report/cold-reader-frame-vs-informed-reviewer/) 講的是知情 reviewer 會自動腦補脈絡而看不見行話洩漏，本卡是同一個不對稱在翻譯這個工序上的形態。差別在冷讀是靠指定角色來製造無知，這裡是靠切斷輸入來製造無知——切斷輸入可以被驗證（餵了什麼是可查的），指定角色只能被要求。
