口語裡用語氣強調來傳遞程度——「遠端一個字都沒有執行」比「指令沒有被送到遠端執行」多了「一個字都沒有」這個強調，聽的人從語氣就知道重點在「完全沒執行」。搬到文字上之後語氣消失了，讀者拿到的是一個多了修飾成分的句子，他要先拆掉強調結構、還原成事實，再繼續讀。

## 為什麼審查抓不到

這種句式在中文裡完全合語法，而且讀起來更生動。審查時讀到它的反應是「讀得懂」然後跳過——它確實讀得懂，而問題從來不在讀不讀得懂，在讀者要多花一步還原。一篇文章裡有一處，成本可以忽略；散布在每一段，累積起來讀者的工作記憶被語氣結構佔滿，留給技術內容的空間變少。

它跟教室形態（[#355](/report/teaching-is-not-lecturing/)）的差別在於：#355 的形態搬的是教室的結構（情境開場、提問引導、省略主詞），這一條搬的是口語的語氣。兩者的來源不同：教室結構來自「教學」這個詞的誤讀，語氣強調來自中文口語與書面語之間的邊界模糊——同一句話講出來與寫下來都通順，而書面語不需要語氣來傳遞程度。

## 判讀方式

辨識的方式是問：**把這一句的強調結構拿掉，事實有沒有改變。** 沒有改變的就是純語氣成本，改成直述事實。

| 改前（帶語氣強調）       | 改後（直述事實）       | 強調結構        |
| ------------------------ | ---------------------- | --------------- |
| 遠端一個字都沒有執行     | 指令沒有被送到遠端執行 | 一個 X 都沒有 Y |
| 根本沒走到 shell 的解析  | adb 在更前面一步失敗   | 根本沒 X        |
| 徵兆與行尾被改寫完全一樣 | 徵兆與行尾被改寫相同   | 完全 X          |

第一種（「一個 X 都沒有 Y」）最隱蔽，因為它的強調結構本身帶有名詞（「一個字」），讀者要判斷那個名詞是修飾還是指涉——「一個字都沒有執行」的「字」是字面意義還是泛指任何東西？技術文章裡這個歧義會讓讀者慢半拍。

## 跟既有原則的關係

[口語修辭](/report/colloquial-rhetoric-erodes-technical-precision/)管的是口語詞彙（「其實」「碰巧」「搞」），本卡管的是口語句式。兩者的 grep 策略不同：詞彙有固定的關鍵詞可以掃，句式的關鍵詞是語法結構（「一個⋯⋯都」「根本」「完全」），命中範圍很大而多數是合規的技術描述（「完全相同」在描述 md5 比對時是精確的事實陳述），判定要逐處做。

候選 grep：`rg "一個.*都沒|根本沒|完全一樣|完全相同"`，但這條的假陽性率高——「完全相同」在比對 hash 值時是精確事實。判定用上面那個問句：拿掉強調，事實變不變。
