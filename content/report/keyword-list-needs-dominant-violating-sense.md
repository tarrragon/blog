## 論述基礎與限制

本卡的觀察來自一次全站用詞清理。[#234](../word-choice-fits-concept-attributes/) 的物理化錯配有一組 grep 清單（撐 / 掛 / 扛 / 垮 / 頂 / 咬 / 啃），寫作 skill 把它操作化時標成三種錯配裡「唯一有穩定關鍵詞可掃的」一種。照清單掃完並修完 68 處之後，使用者在同一批內容裡指出兩處清單完全沒碰到的錯配：把失敗說成「滑進去」「另一條滑坡」，以及用「拿到的是」承接讀書得到的理解。兩處照 #234 的判準都成立——滑需要斜坡、拿需要手，而失敗與理解兩樣都沒有。

限制：本卡不談用詞錯配的**判準**（那是 #234，而這次的兩個實例證明那個判準是對的），只談**偵測**。兩個實例都是中文，但入選判準本身跟語言無關——它問的是一個詞的違規義項佔它全部用法多少，任何語言都算得出來。

## 核心原則

**一個詞能不能進關鍵詞清單，取決於它的違規義項佔它全部用法的比例；而那個比例跟違規嚴不嚴重完全無關。** 清單是判準的一次抽樣，不是判準本身——抽到的是那些「幾乎只在違規時才出現」的詞，漏掉的是那些「違規義項只佔少數」的詞，而後者的違規可以同樣嚴重。

這條判準讓「擴充清單」這個直覺失效。漏抓兩個詞的自然反應是把它們加進 regex，但兩個實例各自示範了加進去為什麼不會有用：

- **本義合法**：「滑坡」在中文是山崩，「下滑」「滑落」「滑向某個狀態」都是正常中文（毛利下滑、ROE 逐級滑落、register 滑向 opinion piece）。違規的只有從英文 slippery slope 借來的那個義項——把失敗當成可以滑進去的地方、把它當成可數的路徑。全站掃「滑」得到二十幾處，違規三處。
- **詞頻過高**：「拿」在技術寫作裡到處都是（拿到的需求、拿去用、拿它對照自己的處境），全部合規。違規的只有拿一個物理取得動詞去承接認知關係那一種。

清單加進這兩個詞之後，噪音會蓋掉訊號，而下一步一定是有人把它們拿掉——那時被拿掉的不只是噪音，還有那條規則對這兩類的涵蓋。

## 反模式

**把清單的涵蓋當成規則的涵蓋。** 「物理化是唯一有穩定關鍵詞可掃的一種」這句標註在被讀的時候會變成「掃完清單就掃完這一類」。實測是掃完清單、修完 68 處、跑完全站驗證都乾淨之後，同一批內容裡仍有兩類完整的違規在。零命中是「清單沒抓到」，不是「沒有違規」。

**用清單的命中數判斷這一類清乾淨了。** 68 這個數字讀起來像一次徹底的清理，而它量的是清單的產能，不是這一類違規的總量。這跟 [#266](../checkable-anchor-must-be-able-to-fall/) 的失效同源，只是那裡的關鍵詞當分子、這裡當偵測入口。

**依賴外部指正當唯一的補漏機制。** 這兩處都是使用者在旁邊看到的，不是任何 review frame 抓到的——而語言的容錯讓作者自己讀不出來（「滑進去的失敗」「拿到的是理解」通順、意思也到得了）。外部眼睛是有效的，但它不是可以排程的東西，把它當唯一機制等於把偵測交給運氣。

## 修法

1. **判準與清單分開寫，並標明清單是抽樣。** 規則的正文寫可執行的判準（「問這個動詞照字面成立需要什麼物理條件」），清單另起一段標成「目前抽到的高密度詞」。兩者混在一起時，讀規則的人會停在清單。
2. **新詞要進清單前先算違規比例。** 全站掃一次那個詞，數違規佔多少。比例低就不進清單，改寫進判準的說明或做成探針。
3. **補語型態探針**（抓泛用動詞頂替具體關係）：精準的認知動詞（學到 / 看出 / 意識到）容得下子句，物理取得動詞（拿到 / 抓到）只容得下名詞組。因此「⋯⋯的是」後面接一個完整斷言時，前面那個動詞多半選錯了。實測那句「拿到的是自己的哪些反應正在製造沉默」同時犯用詞與語法兩項，而語法那一項是看得見的——**不精準的謂語會在需要接子句時撞牆，撞牆點就是探針**。
4. **本義探針**（抓外語隱喻直譯）：那個詞在中文有沒有自己的本義？有的話，本義是什麼詞性、什麼類別？再問句子把它當成什麼在用。滑坡的本義是一個地質事件，而「另一條滑坡」把它當成可數的路徑——本義是事件、用法是路徑，不相容。詞典查得到不等於用法成立，這個探針攔的正是那個落差。
5. **換詞時同義詞要分散。** 一個泛用動詞換掉之後，替代詞要按語境各自選（拿到 → 學到 / 讀出來 / 掌握 / 得到的教訓），不要一律換成同一個——一律替換會用新模具換掉舊模具，理由見 [#122](../cadence-homogenization-in-batch-writing/)。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                                   |
| ---------------------------------------------------- | -------------------------------------------------------------------------- |
| 某條用詞規則的漏抓實例持續從外部指正進來             | 不要先擴充清單；先算那些詞的違規比例，低的改做探針                         |
| 一個詞在中文有本義、而句子用的是外語搭配裡的義項     | 本義探針命中；問本義的詞性與類別跟句子的用法合不合                         |
| 「⋯⋯的是」後面接的是完整斷言而不是名詞組             | 前面那個動詞多半選錯；換成容得下子句的認知動詞                             |
| 掃完清單、全站零命中，而規則涵蓋的範圍描述得比清單廣 | 零命中只證明清單沒抓到；規則正文與清單要分開寫，並標明清單是抽樣           |
| 想把一個高頻常用詞加進 grep 清單                     | 先掃一次數違規佔比；佔比低就會用噪音蓋掉訊號，且下一個維護者會把它整個拿掉 |
| 換掉一個泛用動詞時所有位置都換成同一個替代詞         | 那是用新模具換舊模具；替代詞按語境各自選                                   |
