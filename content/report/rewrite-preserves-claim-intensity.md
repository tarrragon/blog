## 結論

轉換他人材料（翻譯、轉述、摘要、改寫）時、成品的每個 claim 要停在原文的強度量級。強度是 claim 的一部分：形容詞的讚美量級（great 對 miraculous）、模態與頻率詞的確定性（可能對必然、有時對總是）都在傳遞作者對這個 claim 的信心與定位。轉換把量級拉高（升格）或壓低（降格）時、即使概念類型沒換、句子通順、讀者拿到的也是另一個 claim。

可操作的判斷標準是**鄰詞存在測試**：原文語言存在一個量級更強的專詞、而原文沒有選用它、代表原文停在較低量級。日文有「奇跡」這個常用專詞、日文版選的是「素晴らしい」（很棒）、中譯寫成「奇蹟」就是把日文版迴避掉的量級硬加回去。同語言的轉述用同一個測試：原文寫「暗示」（suggests）而轉述寫「證明」、轉述者替原文換上了它明確沒選的強詞。

在轉換他人材料的範圍內、升格合法的條件是目的被宣告：文案再創作（trans-creation）容許拉高量級、但它要被宣告為再創作；未宣告目的的轉換、預設以保真為判斷標準。原創文案沒有 source、量級屬設計變數、責任對象的完整分流見「強度作為設計變數」段。

## 文體先驗接管：升格的來源

本段是文體先驗機制的 SSoT——#260 的 AI 產出位、#261 的句層節奏、#262 的容器形狀都是同一機制在不同層的形態、引用本段不重述。轉換孤立短句（slogan、標題、金句）時、轉換者——人或語言模型——同時在做兩件事：對位原文、產出目標文體的典型樣貌。上下文越少、後者的權重越大：中文行銷語裡「創造奇蹟」比「做出很棒的東西」更像一句 slogan、於是成品往文體典型滑、翻譯默默變成文案再創作、而且沒有任何一方宣告過這個轉變。

| 放大條件                                     | 作用方式                                           |
| -------------------------------------------- | -------------------------------------------------- |
| 孤立短句、無上下文                           | 文體先驗權重上升、保真的對照材料減少               |
| 目標文體有慣用的高強度句式                   | 成品被慣用句式吸走、量級跟著句式走                 |
| 轉換目的未宣告                               | 翻譯與再創作的界線消失、升格無人負責               |
| 材料本身是轉換產物                           | 上一段的漂移被當成原文、漂移逐段累積               |
| 轉換者有升格誘因（受雇行銷、要證明發現重要） | 刻意升格與文體先驗疊加、接收端偵測見 #260 反比訊號 |

## Case：Build something great 的三段轉換鏈

Claude Code 登入成功頁的英文原文是「Build something great」。日文在地化是「素晴らしいものを作りましょう」：「素晴らしい」是日常語彙裡的高強度讚美、量級對位 great、外加「ましょう」的邀請語氣——這是同量級的合格轉換（語氣軟化是日文在地化慣例、量級沒動）。第三段是把日文句丟給 AI 翻譯、得到「讓我們製造一點奇蹟吧」：「奇蹟」把讚美拉到「超乎常理」的量級、外加原文沒有的「一點」。

鄰詞存在測試在這裡的形式：日文有「奇跡」這個常用專詞、想表達奇蹟的文案會直接用它；日文版選用「素晴らしい」、代表它停在「很棒」。中譯選「奇蹟」、等於替這一步的來源句做了一個它明確沒做的選擇。

這條鏈同時展示鏈式轉換的查證規則：漂移逐段累積、「翻譯的翻譯」把上一段的漂移當成原文；查證要回最上游的語言版本（這裡是英文原文）比對。

## 檢查流程

量級檢查放在句內邏輯檢查（主詞、動詞、修飾語、因果、追問方向）之後、作為強度層的補充：

| 檢查         | 問題                                                   | 失效訊號                             |
| ------------ | ------------------------------------------------------ | ------------------------------------ |
| 強度詞定位   | claim 裡承載強度的詞是哪些（形容詞量級、模態、頻率）？ | 找不到對應詞、強度是成品自己長出來的 |
| 量級對位     | 成品的強度詞跟原文同級嗎？                             | 成品讀起來比原文更有力、更像口號     |
| 鄰詞存在測試 | 原文語言有更強的專詞、原文選用了嗎？                   | 成品用了原文迴避的那個量級           |
| 目的宣告     | 這次轉換是翻譯還是再創作？                             | 升格存在、但沒有任何地方宣告過再創作 |

命中是候選、判定在語意層（[#149](../keyword-bank-hit-is-candidate-not-verdict/) 的兩步驟分工）：明示的意譯、宣告過的文案再創作、目標語言慣例要求的語氣調整（敬語、邀請式收尾）都合規。判定問題是「量級改變有沒有被選擇過、有沒有被宣告過」。

表外另有一條回源規則：手上的材料本身是轉換產物時、找最上游的語言版本再比對——拿譯文當原文、上一段的漂移會被當成原意。原文不可得時（付費牆、口述來源、已下架）、判定為「未驗證轉述」：可保留但要標示、不得作為 claim 的支撐再被引用——缺原文時預設放行是反模式。這條規則的成熟度低於上表判斷標準（單一實例、見關係表的 2 次門檻列）、所以放在表外而非表內。

鄰詞存在測試自己也有成立前提：兩個語言在該語意場都要有可對位的量級階梯。原文語言用一個詞涵蓋目標語言分成兩級的區間時（significant 對「顯著」與「相當程度」）、原文沒有可辨識的迴避選項、測試沒有輸出——此時回上下文推定量級意圖、選跨度最近的詞並標示不確定。

## 強度作為設計變數：本卡的適用邊界

量級升格本身是中性的寫作工具、對錯由文字的責任對象決定。分流問題是：**這段文字對誰負責？**

| 情境                                             | 責任對象 | 量級的地位                                                           |
| ------------------------------------------------ | -------- | -------------------------------------------------------------------- |
| 保真轉換（翻譯、轉述、摘要、引用）               | 原文     | 鎖定原文量級、升格與降格都是缺陷、本卡的檢查流程適用                 |
| 宣告過的再創作（trans-creation、在地化行銷標語） | 訴求效果 | 設計變數、可升格；成品要標示為再創作、且回頭引用時取原文而非再創作版 |
| 原創文案（標語、行銷、產品命名、無 source）      | 訴求效果 | 純設計變數、由受眾、文體、品牌語氣決定；「創造奇蹟」在這裡是合法選項 |

同一個「奇蹟」、在中譯一句日文標語時是超譯、在替自家產品寫中文標語時是誇飾修辭的正當運用。本卡管的只有第一列；後兩列的量級判斷屬於文案設計、約束來自受眾與語域（例如教學語域另有中性語域規則、行銷語域容許誇飾）。分辨能力比禁令有用：把三列混在一起、會在保真情境放行超譯、也會在創作情境誤殺有效的標語。文學翻譯（詩、雙關）對原文負責、卻因音節、韻與意象密度必須調整量級——它在本卡的邊界之外、本卡處理的是資訊型與文案型轉換。

## 判讀徵兆

| 訊號                                           | 該做的事                                             |
| ---------------------------------------------- | ---------------------------------------------------- |
| 譯文比原文更像一句口號                         | 跑強度詞定位與量級對位、確認升格來自原文還是文體先驗 |
| 成品的高強度詞在原文找不到對應                 | 鄰詞存在測試：原文語言有這個量級的專詞嗎、原文用了嗎 |
| hedge 詞（可能、有時、在某些情境）在轉換後消失 | 逐條對回原文；確定性升格跟讚美升格同屬量級漂移       |
| 手上的材料本身是譯文                           | 找最上游語言版本再比對、拿譯文當原文會把漂移當成原意 |
| 轉換很順、但分不清這次的目的是翻譯還是再創作   | 補宣告；未宣告時以保真為判斷標準                     |

**核心**：原文停在的量級、就是讀者該拿到的 claim。轉換者無從分辨原文的量級是刻意還是隨手、而改動的收益歸轉換者、風險歸原作者——所以預設保真、要改就宣告。
