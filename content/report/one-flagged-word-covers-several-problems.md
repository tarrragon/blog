## 論述基礎與限制

這張卡來自 2026-11-14 對一篇音樂鑑賞文章〈聽樂團音樂會〉的四次修改。文章是教學定位，讀者是要去聽一場樂團音樂會的人。原稿談現場與錄音的那一節，開頭兩段是：

> 一場現場演出是一首作品在一個晚上只發生一次的版本。……錄音是其中一次（或幾次剪接而成）的結果，可以重聽；現場是正在發生的過程，每一句確切的樣子在演奏的那一刻才發出聲音，聽眾跟台上同時經歷每一個轉折。
>
> 錄音給不了、而下面的例子裡都聽得到看得到的，還有：

使用者指出兩件事：

- 第一句是廢話，這一段要強調的是每場音樂會隨著樂手、樂器與場地的狀態而不同。教學文章不必像演奏會的宣傳文宣那樣強調一期一會。
- 「給不了」是 LLM 常用的句型，直接跟讀者說「在音樂會裡應該注意這些細節」。

修改依序是：

- **第一次修改**：
  - 刪掉同一資料夾四篇文章裡的六處「給不了」。
  - 開段改寫成樂手、樂器、場地三方面的變因。
  - 馬勒《復活》那一節的「這段落差是錄音與家裡的音響給不了的」改成「錄音常把這段落差縮小，家裡的音響通常也不會開到那個音量」。
- **第二次修改**：
  - 使用者再點名同一句「還是沿用了給不了」。這時檔案裡已經沒有這三個字。
  - 回頭對照，改後的句子仍然用錄音與音響缺什麼來說明現場的價值，清單裡寫聲音幅度的那一項也是同一種寫法。
  - 兩處都改成在音樂廳裡可以留意什麼。
- **第三次修改**：
  - 使用者點名「知道合唱在哪裡進來、結尾往哪裡走，現場就能從那個極小聲的起點跟著一路走到最後」把動作擬人了。
  - 同一類的「跟著……走」「眼睛幫耳朵找到」「讓音樂整體流過」在同一資料夾五個檔裡都有，一起改掉。
- **第四次修改**：照使用者的指示，改掉標題與段標的「聽眾怎麼跟台上一起經歷一場音樂會」。

看完四次的結果，使用者判斷「給不了」跟「錄音給不了」是幾種不同的缺陷。之後使用者補充：「給不了」本身就是把主詞擬人了，LLM 一直有把主詞擬人的習慣，寫文章的時候要注意，檢討時也要查。所以這張卡把「給不了」歸進擬人那一種，不另立詞面的口頭禪。

**三組量測**：

- **字句層 bank 的涵蓋**：寫作 skill 字句層 bank〈正向陳述優先〉的否定 pattern 是 `不[行可是要能該支對符夠必]|無法|沒[做有]|而非|而不是`，不涵蓋「不了」，原稿的六處它一處都沒掃到。當時 bank 也沒有一類專門掃非人主詞配上人的動作。第一次修改後的「錄音常把這段落差縮小」沒有任何否定字，換成哪一條詞彙 pattern 都掃不到。
- **全站其餘 11 處「給不了」**（排除 report 卡與 skill 鏡像）：
  - 主詞全是物：工具、佇列、一致性等級、失敗訊息、課程、書、充電器、類比、工廠方法。
  - 6 處寫在讀者要在幾個選項之間選的位置（事件與 Port、quorum 與 classic 佇列、Bounded staleness 與 Session token、測試名稱與失敗訊息、課程與書當載體）。在那裡，替代品缺什麼就是選擇的依據，對照是內容；動詞照樣是擬人，實際的動作是不支援、不記錄、不輸出。
- **被修的位置**：四次修改在原文裡改到的 28 處，相對位置從 1%（標題）到 97% 都有，在文章前 20% 的有 12 處，只有 19 行的目錄頁也有兩處。這些擬人與文宣句沒有集中在長文章的後段。

**短 context 的對照**：

- **做法**：派三個新的 agent，拿同一份事實摘要各寫同一組三段（現場與錄音、馬勒《復活》、聽的當下），跟原稿的同三段比。
- **抽取**：每份由一個低階模型逐句抽出主詞與動詞，判定由主 session 做；當時用第一版規則的放行類別（樂器代指演奏者、被動句、領域固定動詞），不是現行的判法。
- **結果**：原稿 8 處（每千字 7.9），三份新稿 3、3、1 處（每千字 3.1、3.5、1.2）。三份新稿都照樣寫出「錄音裡沒有的東西」這個對照框架，一份寫了「只發生這一次的演奏」。
- **干擾因素**：
  - 新稿 agent 的 context 仍然載入了全部規則檔，系統提示裡還多了一行這次新加、要求不擬人的備忘。
  - 事實摘要由主 session 用已經去掉擬人的句子寫成。
  - 原稿是審查之前的初稿。
  - 只有三份。
- **解讀**：擬人的密度在新稿較低，跟 context 長度有關的解讀相容，但分不開上面幾個因素。對照框架在新稿照樣出現，比較像是新稿的作者照著摘要的節名「現場演出與錄音的差別」與清單結構寫出來的。

**把擬人寫成檢查規則的過程**：

- 第一版用「主詞是哪一類 × 動詞是哪一類」判，再列出做得了的情形（主詞代指一個人、領域標準用語、物理字面）與排除條款。
- 規則級審查兩次觸發設計稽核：每補一條邊界，冷讀與理解探針就在邊上找到一個能讀出兩種處置的句子（佇列算程式還是物品、書單算不算代指作者、評論文章的慣用說法算不算標準用語）。
- 使用者要求先反省寫法、再反省對規則的理解，最後才考慮簡化。第一次反省的結論是：一個要靠判斷的事項被寫成了條件清單，而且被點名的句子共同的缺陷是實際發生的事被藏起來了，規則因此改成觸發、改寫測試（多出讀者需要的資訊就改）與痕跡。
- 這一版的審查觸發第三次設計稽核：三份理解探針都把「HDD 給不了 SSD 的隨機讀取速度」判成可以留（改寫之後資訊相同），「讀者從主詞讀得回的動作者就留」也跟槽位規則的「判定者不代填槽位」互撞。第二次反省的結論是：使用者在意的是借來的動詞本身，而「主詞要能執行這個動作」本來就是槽位規則的一項，不該另立一套判法。規則因此歸回槽位規則，判法先改成動詞比對（改寫成實際的動作者之後，動詞有沒有換）。
- 動詞比對的 Round 1 又有一半的個案得到兩種處置：改寫句怎麼選、主詞代指誰、句子沒有動作者、因果動詞與受事主語，都是分支的邊界。最後的寫法是使用者選的「只問一句的留意項」：主詞是物時檢查「這個主詞本身，或它在這個領域裡慣用來指的人，能不能執行這個動作」，不能執行就改寫，附正反例與痕跡，不寫分支。這一段的反省另外寫成 [規則的審查走到設計稽核的停點時，先反省寫法、再反省對規則的理解、最後才簡化](/report/rule-nonconvergence-reflect-form-then-understanding/)。

**限制**：

- 證據只有一位作者（LLM 生成端）的一批文章，三種缺陷的分法來自這一批的修改，沒有在別的集合驗過。
- 被修的位置偏向前段，有一部分原因可能是使用者從開頭讀起，這組位置量的是找到的位置，不完全等於存在的位置。
- 「LLM 常把主詞擬人」是使用者的觀察，這張卡沒有量過它在生成端的頻率。

## 核心原則

**讀者點名的是最顯眼的那個詞，那一句可能同時有幾種寫法缺陷，每一種的偵測方法與修法都不同。** 這次的缺陷有下面幾種：

- **把主詞擬人的動詞**：主詞是物（錄音、結尾、眼睛、音樂），動詞是人或會移動的東西才做得出的動作（給、幫、經歷、走、流過）。例子有「錄音給不了的」「結尾往哪裡走」「跟著一路走到最後」「眼睛幫耳朵找到」。動詞是借來的，實際發生的事也常常沒寫出來：錄音的動態範圍比現場窄、合唱團開始唱、音量一層層加大、看到哪一組樂器開始演奏。判斷照寫作 skill〈每一句先填槽位再成句（生成端規格）〉那一項檢查（[Compositional Writing 的 SKILL.md](/skills/compositional-writing/skill/)）：這個主詞本身，或它在這個領域裡慣用來指的人，能不能執行這個動作。「法國號在舞台外演奏」能執行（法國號慣用來指吹法國號的人）；「HDD 給不了 SSD 的隨機讀取速度」不能執行，改成「HDD 的隨機讀取速度比 SSD 慢」。
- **用替代品的缺點界定價值**：句子寫的是被拿來對照的替代品缺什麼，替代品不一定在主詞的位置。例子是「錄音給不了的」與改寫後的「錄音常把這段落差縮小」。買了票的讀者讀到「錄音給不了的」，只拿到錄音缺什麼，沒有拿到現場要注意什麼；讀者要在兩個選項之間選的段落（事件還是 Port、quorum 還是 classic），替代品缺什麼就是選擇的依據。判法、候選與痕跡只寫在字句層 bank〈正向陳述優先〉底下的「只寫對照方缺什麼的句子」（bank 稱對照方，範圍比替代品寬：拿來對照的任何對象都算，事件與 Port 互不取代也算）。這一種換動詞修不好，第二次點名就是證據：「給不了」換成「縮小」之後，讀者拿到的仍然只有錄音缺什麼。
- **文宣式的獨一性斷言**：「只發生一次的版本」「聽眾跟台上同時經歷每一個轉折」「跟台上一起經歷一場音樂會」。判斷方法是定義代換測試：拿話題的定義推不推得出這一句。現場演出本來就只發生一次，這句話沒有交付新的資訊。這類句子的功能是經營期待，服務的是要被吸引的聽眾。教學文章的讀者帶著疑問來，要的是成因：每一場為什麼不同、差在哪裡，以及他知道這些之後能做什麼。這一種也常帶著擬人：「跟台上一起經歷」把聽眾與演出寫成一起行動的同伴。

**三種缺陷常常出現在同一句裡，所以會被當成同一個缺陷。** 「錄音給不了、而下面的例子裡都聽得到看得到的」同時有擬人與替代品的對照兩種缺陷；開段的第一句同時是獨一性斷言與同義反覆。點名的人指出的是讀起來最刺眼的位置，修改的人照著點名的詞修，只修好那個詞；其餘幾種缺陷沒有被改到，修改的人要等點名的人下一次指出才會發現。

**擬人是生成端的習慣，在寫的當下擋。** 主詞能執行這個動作，是句子槽位規則裡的一項；它在這批文章裡沒有被執行，原因是寫與審的步驟裡，沒有一步要求寫的人或審查者逐句做這一項檢查：bank 沒有對應的一類，同源的審查者跟作者共用同一套用詞習慣，讀起來是順的。

## 反模式

- **只換掉被點名的詞**：把「給不了」換成「縮小」「做不到」「缺少」，讀者讀完仍然只拿到替代品缺什麼，或實際的動作者仍然沒寫出來。
- **把這一類補進否定詞的 pattern 就當作處理完**：把「給不了」補進否定 pattern 之後，它也只抓得到這一個詞。擬人的動詞不一定帶否定（走、幫、流過、經歷），替代品的對照在改寫之後沒有固定的字詞。
- **讀者要選的段落連對照一起刪掉**：讀者要在幾個選項之間選時，替代品缺什麼是內容；要改的是藏起屬性的動詞，對照留著。
- **把擬人寫成主詞與動詞的分類表，或另立一套判法**：主詞歸哪一類本身就要判斷，每補一條合規情形就多一條讀得出兩種處置的邊界；另立的判法又會跟槽位規則在每一個邊界互撞；把判斷寫成帶分支的比對程序，分支的邊界照樣讀得出兩種處置。用槽位規則的那一項檢查判，並把改寫句或留下的理由寫成痕跡。
- **用另一個宣傳句取代獨一性斷言**：把「一期一會」換成「每一場都是獨一無二的」，換的只是措辭，句子的功能仍然是經營期待。

## 修法

擬人的判斷照寫作 skill〈每一句先填槽位再成句（生成端規格）〉那一項檢查，偵測、痕跡與嚴重度寫在字句層 bank〈用詞搭配錯位〉的擬人那一項（[字句層 keyword bank](/skills/compositional-writing/keyword-bank/)）；替代品的對照照同一份 bank〈正向陳述優先〉底下的「只寫對照方缺什麼的句子」判；獨一性斷言用 [排比句的變動格填了話題自己的定義](/report/parallel-clause-filled-with-the-topics-definition/) 的定義代換測試，改寫時寫出變因與讀者的用處（樂手、樂器、場地各自怎麼改變一場演出）。這張卡另外補上跟修改流程有關的幾件事：

1. **被點名的詞放回整句，三種缺陷逐一判**，不只處理那個詞。
2. **改完拿改後的句子再判一次**，不只 rg 被點名的那個詞。第一次修改之後如果做了這一步，「錄音常把這段落差縮小」在替代品那一種就會被判出來。
3. **同一個集合一起掃**：擬人照 bank 的 pattern 與主謂抽取找候選，替代品的對照用替代品的名字（這次是「錄音」）當候選，內容集合的結構譬喻照 [結構譬喻頂替主詞與動詞](/report/structural-metaphor-replaces-actor-and-verb/) 的 pattern 掃。這次第三次修改在五個檔裡找到同一類的「跟著……走」，原因是同一批文章互相當範本。

## 判讀徵兆

| 徵兆                                                           | 判讀                                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 改寫之後同一句又被點名，而被點名的詞已經不在句子裡             | 修好的是那個詞，替代品的對照、獨一性斷言或另一個擬人動詞還在改後的句子裡 |
| 主詞是物（錄音、結尾、眼睛），動詞是給、走、幫、經歷           | 擬人的候選，檢查這個主詞或它慣用來指的人能不能執行這個動作               |
| 句子寫的是錄音、線上、複製品這類替代品缺什麼                   | 問讀者讀完這一段拿到了什麼，只拿到替代品缺什麼就要改                     |
| 檢查規則每補一條合規情形，審查就找到一個兩種處置的新句子       | 一個要靠判斷的事項被寫成了條件清單；改成觸發、一問與痕跡                 |
| 「只發生一次」「獨一無二」「一起經歷」寫在教學文章的開段或標題 | 文宣式的獨一性斷言，定義代換測試下沒有新資訊                             |
| 同一種擬人寫法出現在同一批好幾篇裡                             | 同一批文章互相當範本，或生成端的習慣；整個集合一起掃，不只修被點名的那篇 |

## 跟其他抽象層原則的關係

- [正向改寫要保留對照論據、不能空降結論](/report/positive-rewrite-preserves-contrast/)：最接近的既有卡。那張卡的論點是：對照的 Y 是讀者直覺會想到的替代方案時，刪掉對照會讓結論失去依據；兩張卡要判斷的東西不同：照那張卡判的是 Y 在推理裡的角色，照本卡判替代品那一種時，判的是讀者讀完這一段拿到了什麼。讀者只拿到替代品缺什麼時，照本卡改寫成這個對象裡可以注意什麼；讀者拿到本篇對象裡要注意的細節或選擇的依據時，對照留著，跟那張卡的處置一致；判法寫在字句層 bank〈正向陳述優先〉底下的「只寫對照方缺什麼的句子」。
- [描述抽象概念要用貼合屬性的謂語：分析角度不會「說話」、證據不會「撐得住」](/report/word-choice-fits-concept-attributes/)：本卡的擬人那一種是那張卡的同一個機制（主體條件與轉喻鏈），主詞換成了錄音、結尾與感官。那張卡處理抽象概念配上人或物理的動作；本卡補上它在被點名、改寫之後的表現：換掉一個擬人動詞，可能換上另一個。
