## 論述基礎與限制

這張卡來自 2026-11-14 對一篇音樂鑑賞文章〈聽樂團音樂會〉的四次修改。文章是教學定位，讀者是要去聽一場樂團音樂會的人。原稿談現場與錄音的那一節，開頭兩段是：

> 一場現場演出是一首作品在一個晚上只發生一次的版本。……錄音是其中一次（或幾次剪接而成）的結果，可以重聽；現場是正在發生的過程，每一句確切的樣子在演奏的那一刻才發出聲音，聽眾跟台上同時經歷每一個轉折。
>
> 錄音給不了、而下面的例子裡都聽得到看得到的，還有：

使用者指出兩件事：

- 第一句是廢話，這一段要強調的是每場音樂會隨著樂手、樂器與場地的狀態而不同。教學文章不必像演奏會的宣傳文宣那樣強調一期一會。
- 「給不了」是 LLM 常用的句型，直接跟讀者說「在音樂會裡應該注意這些細節」。

修改依序是：

- **第一次修改**：
  - 刪掉同一資料夾四篇文章裡的六處「給不了」。
  - 開段改寫成樂手、樂器、場地三方面的變因。
  - 馬勒《復活》那一節的「這段落差是錄音與家裡的音響給不了的」改成「錄音常把這段落差縮小，家裡的音響通常也不會開到那個音量」。
- **第二次修改**：
  - 使用者再點名同一句「還是沿用了給不了」。這時檔案裡已經沒有這三個字。
  - 回頭對照，改後的句子仍然用錄音與音響缺什麼來說明現場的價值，清單裡寫聲音幅度的那一項也是同一種寫法。
  - 兩處都改成在音樂廳裡可以留意什麼。
- **第三次修改**：
  - 使用者點名「知道合唱在哪裡進來、結尾往哪裡走，現場就能從那個極小聲的起點跟著一路走到最後」把動作擬人了。
  - 同一類的「跟著……走」「眼睛幫耳朵找到」「讓音樂整體流過」在同一資料夾五個檔裡都有，一起改掉。
- **第四次修改**：照使用者的指示，改掉標題與段標的「聽眾怎麼跟台上一起經歷一場音樂會」。

看完四次的結果，使用者判斷「給不了」跟「錄音給不了」是幾個不同的問題。之後使用者補充：「給不了」本身就是把主詞擬人了，LLM 一直有把主詞擬人的問題，寫文章的時候要注意，檢討時也要查。所以這張卡把「給不了」歸進擬人那一層，不另立詞面的口頭禪。

**三組量測**：

- **字句層 bank 的涵蓋**：寫作 skill 字句層 bank〈正向陳述優先〉的否定 pattern 是 `不[行可是要能該支對符夠必]|無法|沒[做有]|而非|而不是`，不涵蓋「不了」，原稿的六處它一處都沒掃到。bank 也沒有一類專門掃非人主詞配上人的動作。第一次修改後的「錄音常把這段落差縮小」沒有任何否定字，換成哪一條詞彙 pattern 都掃不到。
- **全站其餘 11 處「給不了」**（排除 report 卡與 skill 鏡像）：
  - 主詞全是物：工具、佇列、一致性等級、失敗訊息、課程、書、充電器、類比、工廠方法。
  - 6 處寫在讀者要在幾個選項之間選的位置（事件與 Port、quorum 與 classic 佇列、Bounded staleness 與 Session token、測試名稱與失敗訊息、課程與書當載體）。在那裡，替代品缺什麼就是選擇的依據，對照是內容；動詞照樣是擬人，實際的動作是不支援、不記錄、不輸出。
- **被修的位置**：四次修改在原文裡改到的 28 處，相對位置從 1%（標題）到 97% 都有，在文章前 20% 的有 12 處，只有 19 行的目錄頁也有兩處。這些擬人與文宣句沒有集中在長文章的後段。

**限制**：

- 證據只有一位作者（LLM 生成端）的一批文章，三層的分法來自這一批的修改，沒有在別的集合驗過。
- 被修的位置偏向前段，有一部分原因可能是使用者從開頭讀起，這組位置量的是找到的位置，不完全等於存在的位置。
- 「LLM 常把主詞擬人」是使用者的觀察，這張卡沒有量過它在生成端的頻率。

## 核心原則

**讀者點名的是最顯眼的那個詞，詞底下可能疊著幾層問題，每一層的偵測方法與修法都不同。** 這次的三層：

- **把主詞擬人的動詞**：主詞是物（錄音、結尾、眼睛、音樂、工具），動詞是人才做得出的動作（給、走、幫、流過、經歷）。例子有「錄音給不了的」「結尾往哪裡走」「跟著一路走到最後」「眼睛幫耳朵找到」。實際發生的事沒有寫出來：錄音的動態範圍比現場窄、合唱團開始唱、音量一層層加大、看到哪一組樂器開始演奏。判斷問句是主詞做不做得了這個動作。修法是寫出實際的動作者與動作；物當主詞時，用描述它狀態或屬性的動詞（記錄、輸出、不支援、比現場窄）。
- **用替代品的缺點界定價值**：句子的主詞是被拿來對照的替代品，寫的是替代品缺什麼。例子是「錄音給不了的」與改寫後的「錄音常把這段落差縮小」。讀者讀完知道錄音缺什麼，還是不知道在音樂廳裡要注意什麼。這一層換動詞修不好，第二次點名就是證據：「給不了」換成「縮小」之後，主詞仍然是錄音。判斷問句是讀者這時要不要在兩者之間選：
  - 要選時（事件還是 Port、quorum 還是 classic），替代品缺什麼就是選擇的依據，框架合規；動詞照擬人那一層的修法換成實際的動作。
  - 已經選定時（讀者買了票要去音樂廳），對照佔掉了該寫的內容，要改寫成這個對象裡可以注意什麼。
- **文宣式的獨一性斷言**：「只發生一次的版本」「聽眾跟台上同時經歷每一個轉折」「跟台上一起經歷一場音樂會」。判斷方法是定義代換測試：拿話題的定義推不推得出這一句。現場演出本來就只發生一次，這句話沒有交付新的資訊。這類句子的功能是經營期待，服務的是要被吸引的聽眾。教學文章的讀者帶著疑問來，要的是成因：每一場為什麼不同、差在哪裡，以及他知道這些之後能做什麼。這一層也常帶著擬人：「跟台上一起經歷」把聽眾與演出寫成一起行動的同伴。

**三層常常疊在同一句裡，所以會被當成一個問題。** 「錄音給不了、而下面的例子裡都聽得到看得到的」同時是擬人與框架兩層；開段的第一句同時是獨一性斷言與同義反覆。點名的人指出的是讀起來最刺眼的位置，修改的人照著點名的詞修，只修好那個詞；其餘幾層留在改後的句子裡，等下一次點名。

**擬人是生成端的習慣，在寫的當下擋。** 主詞做得了這個動作，是句子槽位規則裡的一項；它在這批文章裡沒有被執行，原因是沒有一個步驟會在寫或審的時候逐句停下來問這一題：bank 沒有對應的一類，同源的審查者跟作者共用同一套用詞習慣，讀起來是順的。

## 反模式

- **只換掉被點名的詞**：把「給不了」換成「縮小」「做不到」「缺少」，句子的主詞仍然是替代品，或仍然是物配上人的動作。
- **把這一類補進否定詞的 pattern 就當作處理完**：否定 pattern 只抓得到「給不了」這一個詞。擬人的動詞不一定帶否定（走、幫、流過、經歷），框架那一層在改寫之後沒有固定的字詞。
- **讀者要選的段落連對照一起刪掉**：讀者要在幾個選項之間選時，替代品缺什麼是內容；要改的是擬人的動詞，對照留著。
- **用另一個宣傳句取代獨一性斷言**：把「一期一會」換成「每一場都是獨一無二的」，換的只是措辭，句子的功能仍然是經營期待。

## 修法

1. **把被點名的詞放回句子裡，逐層問三個問題**：
   - 主詞做不做得了這個動作。
   - 句子的主詞是本篇要讀者注意的對象，還是被拿來對照的替代品；讀者這時要不要在兩者之間選。
   - 拿話題的定義推不推得出這一句；讀者讀完能做什麼。
2. **每一層照它自己的修法改**：
   - 擬人：寫出實際的動作者與動作，物當主詞時用描述狀態或屬性的動詞。
   - 替代品當主詞而讀者不必選：改寫成這個對象裡可以注意什麼。
   - 獨一性斷言：寫出變因與讀者的用處，例如樂手、樂器、場地各自怎麼改變一場演出，以及讀者當晚聽到的跟熟悉的錄音不同時，知道差別從哪裡來。
3. **改完之後拿改後的句子再問一次三個問題**，不只 rg 被點名的那個詞。第一次修改之後如果做了這一步，「錄音常把這段落差縮小」在問主詞是不是替代品的那一問就會停下來。
4. **同一個集合掃同一種寫法**：
   - 擬人用常見的人的動作（給、走、幫、說、告訴、經歷、流過）找候選，逐處問主詞做不做得了。
   - 框架用替代品的名字當候選（這次是「錄音」），逐處問讀者要不要在兩者之間選。
   - 結構與移動譬喻照 #387 的 pattern 掃。
   - 這次第三次修改在五個檔裡找到同一類的「跟著……走」，原因是同一批文章互相當範本。

## 判讀徵兆

| 徵兆                                                           | 判讀                                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 改寫之後同一句又被點名，而被點名的詞已經不在句子裡             | 修好的是那個詞，框架、語域或另一個擬人動詞還留在改後的句子裡             |
| 主詞是物（錄音、結尾、眼睛、工具），動詞是給、走、幫、經歷     | 擬人，實際的動作者與動作沒寫出來                                         |
| 句子的主詞是錄音、線上、複製品這類替代品，而讀者已經選定了對象 | 用替代品的缺點界定價值，讀者拿不到要注意什麼                             |
| 同一種對照寫在讀者要在幾個選項之間選的段落                     | 替代品缺什麼是選擇的依據，對照合規；動詞仍要換成實際的動作               |
| 「只發生一次」「獨一無二」「一起經歷」寫在教學文章的開段或標題 | 文宣式的獨一性斷言，定義代換測試下沒有新資訊                             |
| 同一種擬人寫法出現在同一批好幾篇裡                             | 同一批文章互相當範本，或生成端的習慣；整個集合一起掃，不只修被點名的那篇 |

## 跟其他抽象層原則的關係

- [正向改寫要保留對照論據、不能空降結論](/report/positive-rewrite-preserves-contrast/)：最接近的既有卡。那張卡說對照的 Y 是讀者直覺會想到的替代方案時，刪掉對照會讓結論失去依據；本卡補上邊界：讀者已經選定對象、不必在兩者之間選時，對照本身佔掉了該寫的內容，要改寫成這個對象裡可以注意什麼。判斷問句都是讀者這時要不要在兩者之間選。
- [描述抽象概念要用貼合屬性的謂語：分析角度不會「說話」、證據不會「撐得住」](/report/word-choice-fits-concept-attributes/)：本卡的擬人那一層是那張卡的同一個機制，主詞換成了錄音、結尾與感官。那張卡處理抽象概念配上人或物理的動作；本卡補上它在被點名、改寫之後的表現：換掉一個擬人動詞，可能換上另一個。
- [結構譬喻頂替主詞與動詞](/report/structural-metaphor-replaces-actor-and-verb/)：「跟著一路走」「往哪裡走」是那張卡的移動譬喻，這次出現在鑑賞文章裡，主詞是音樂與聽眾。修法同樣是寫出實際的動作者與動作。
- [排比句的變動格填了話題自己的定義](/report/parallel-clause-filled-with-the-topics-definition/)：本卡的獨一性斷言用的是那張卡的定義代換測試；那張卡的對象是排比句，這次的對象是一句單獨的斷言。
- [教學與檢討內容寫給帶問題來的讀者，不是要被吸引的聽眾](/report/write-for-readers-not-audiences/)：獨一性斷言是那張卡說的服務注意力的技巧，從演講換成了文宣。
