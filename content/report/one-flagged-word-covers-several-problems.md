## 論述基礎與限制

這張卡來自 2026-11-14 對一篇音樂鑑賞文章〈聽樂團音樂會〉的四次修改。文章是教學定位，讀者是要去聽一場樂團音樂會的人。原稿談現場與錄音的那一節，開頭兩段是：

> 一場現場演出是一首作品在一個晚上只發生一次的版本。……錄音是其中一次（或幾次剪接而成）的結果，可以重聽；現場是正在發生的過程，每一句確切的樣子在演奏的那一刻才發出聲音，聽眾跟台上同時經歷每一個轉折。
>
> 錄音給不了、而下面的例子裡都聽得到看得到的，還有：

使用者指出兩件事：

- 第一句是廢話，這一段要強調的是每場音樂會隨著樂手、樂器與場地的狀態而不同。教學文章不必像演奏會的宣傳文宣那樣強調一期一會。
- 「給不了」是 LLM 常用的句型，直接跟讀者說「在音樂會裡應該注意這些細節」。

修改依序是：

- **第一次修改**：
  - 刪掉同一資料夾四篇文章裡的六處「給不了」。
  - 開段改寫成樂手、樂器、場地三方面的變因。
  - 馬勒《復活》那一節的「這段落差是錄音與家裡的音響給不了的」改成「錄音常把這段落差縮小，家裡的音響通常也不會開到那個音量」。
- **第二次修改**：
  - 使用者再點名同一句「還是沿用了給不了」。這時檔案裡已經沒有這三個字。
  - 回頭對照，改後的句子仍然用錄音與音響缺什麼來說明現場的價值，清單裡寫聲音幅度的那一項也是同一種寫法。
  - 兩處都改成在音樂廳裡可以留意什麼。
- **第三次修改**：
  - 使用者點名「知道合唱在哪裡進來、結尾往哪裡走，現場就能從那個極小聲的起點跟著一路走到最後」把動作擬人了。
  - 同一類的「跟著……走」「眼睛幫耳朵找到」「讓音樂整體流過」在同一資料夾五個檔裡都有，一起改掉。
- **第四次修改**：照使用者的指示，改掉標題與段標的「聽眾怎麼跟台上一起經歷一場音樂會」。

看完四次的結果，使用者判斷「給不了」跟「錄音給不了」是幾個不同的問題。

**兩組量測**：

- 寫作 skill 字句層 bank〈正向陳述優先〉的否定 pattern 是 `不[行可是要能該支對符夠必]|無法|沒[做有]|而非|而不是`，不涵蓋「不了」。原稿的六處它一處都沒掃到。第一次修改後的「錄音常把這段落差縮小」沒有任何否定字，換成哪一條詞彙 pattern 都掃不到。
- 全站排除 report 卡與 skill 鏡像之後，「給不了」還有 11 處：
  - 6 處寫在讀者要在幾個選項之間選的位置，替代品缺什麼就是選擇的依據：事件與 Port、quorum 與 classic 佇列、Bounded staleness 與 Session token、測試名稱與失敗訊息、課程與書當載體。
  - 1 處寫的是硬體的實際能力：沒有列 20 V 的充電器輸出不了 20 V。
  - 2 處把讀者指向別的來源：書寫不到的法律邊界要回到主管機關的規定。
  - 1 處在數學類比文章的段標。
  - 1 處在 work-log 描述工廠方法不接受某個參數。

**限制**：

- 證據只有一位作者（LLM 生成端）的一批文章，四層的分法來自這一批的四次修改，沒有在別的集合驗過。
- 「LLM 常用」是使用者的觀察，這張卡沒有量過它在生成端的頻率。

## 核心原則

**讀者點名的是最顯眼的那個詞，詞底下可能疊著幾層問題，每一層的偵測方法與修法都不同。** 這次的四層：

- **詞面的口頭禪**：「給不了」這個詞本身。它是生成端的高頻用詞，「給」沒有說出實際的動作（輸出、提供、支援、記錄）。這一層換成實際的動詞就修好，rg 掃得到。
- **用替代品的缺點界定價值**：句子的主詞是被拿來對照的替代品，寫的是替代品缺什麼。例子是「錄音給不了的」與「錄音常把這段落差縮小」。讀者讀完知道錄音缺什麼，還是不知道在音樂廳裡要注意什麼。這一層換詞修不好，第二次點名就是證據：詞換掉了，主詞仍然是錄音。判斷問句是讀者這時要不要在兩者之間選：
  - 要選時（事件還是 Port、quorum 還是 classic），替代品缺什麼就是選擇的依據，合規。
  - 已經選定時（讀者買了票要去音樂廳），對照佔掉了該寫的內容，要改寫成這個對象裡可以注意什麼。
- **文宣式的獨一性斷言**：「只發生一次的版本」「聽眾跟台上同時經歷每一個轉折」「跟台上一起經歷一場音樂會」。定義代換測試：拿話題的定義推不推得出這一句。現場演出本來就只發生一次，這句話沒有交付新的資訊。這類句子的功能是經營期待，服務的是要被吸引的聽眾。教學文章的讀者帶著疑問來，要的是成因：每一場為什麼不同、差在哪裡，以及他知道這些之後能做什麼。
- **擬人與移動譬喻**：「結尾往哪裡走」「跟著一路走到最後」「眼睛幫耳朵找到」。主詞做不了這個動作，實際發生的事（合唱團開始唱、音量一層層加大、看到哪一組樂器開始演奏）沒有寫出來。

**四層常常疊在同一句裡，所以會被當成一個問題。** 「錄音給不了、而下面的例子裡都聽得到看得到的」同時是詞面與框架兩層；開段的第一句同時是獨一性斷言與同義反覆。點名的人指出的是讀起來最刺眼的位置，修改的人照著點名的詞修，只修好詞面那一層；其餘幾層留在改後的句子裡，等下一次點名。

## 反模式

- **只換掉被點名的詞**：把「給不了」換成「縮小」「做不到」「缺少」，句子的主詞仍然是替代品。
- **把這一類補進否定詞的 pattern 就當作處理完**：pattern 只抓得到詞面那一層。框架那一層在改寫之後沒有固定的字詞，獨一性斷言與擬人也各有自己的形態。
- **全站一律刪掉「給不了」**：讀者要在幾個選項之間選時，替代品缺什麼就是內容；把那幾處改掉，選擇的依據就跟著消失。
- **用另一個宣傳句取代獨一性斷言**：把「一期一會」換成「每一場都是獨一無二的」，換的只是措辭，句子仍然在經營期待。

## 修法

1. **把被點名的詞放回句子裡，逐層問四個問題**：
   - 這個詞有沒有寫出實際的動作。
   - 句子的主詞是本篇要讀者注意的對象，還是被拿來對照的替代品；讀者這時要不要在兩者之間選。
   - 拿話題的定義推不推得出這一句；讀者讀完能做什麼。
   - 主詞做不做得了這個動作。
2. **每一層照它自己的修法改**：
   - 詞面：換成實際的動詞。
   - 替代品當主詞而讀者不必選：改寫成這個對象裡可以注意什麼。
   - 獨一性斷言：寫出變因與讀者的用處，例如樂手、樂器、場地各自怎麼改變一場演出，以及讀者當晚聽到的跟熟悉的錄音不同時，知道差別從哪裡來。
   - 擬人：寫出實際發生的聲音或動作。
3. **改完之後拿改後的句子再問一次四個問題**，不只 rg 被點名的那個詞。第一次修改之後如果做了這一步，「錄音常把這段落差縮小」在問主詞是不是替代品的那一問就會停下來。
4. **同一個集合掃同一種寫法**：
   - 詞面用 rg 掃那個詞。
   - 框架用替代品的名字當候選（這次是「錄音」），逐處問第二個問題。
   - 擬人與移動譬喻照 #387 的 pattern 掃。
   - 這次第三次修改在五個檔裡找到同一類的「跟著……走」，原因是同一批文章互相當範本。

## 判讀徵兆

| 徵兆                                                           | 判讀                                                         |
| -------------------------------------------------------------- | ------------------------------------------------------------ |
| 改寫之後同一句又被點名，而被點名的詞已經不在句子裡             | 修好的是詞面那一層，框架、語域或譬喻那一層還留在改後的句子裡 |
| 句子的主詞是錄音、線上、複製品這類替代品，而讀者已經選定了對象 | 用替代品的缺點界定價值，讀者拿不到要注意什麼                 |
| 同一種對照寫在讀者要在幾個選項之間選的段落                     | 替代品缺什麼是選擇的依據，合規                               |
| 「只發生一次」「獨一無二」「一起經歷」寫在教學文章的開段或標題 | 文宣式的獨一性斷言，定義代換測試下沒有新資訊                 |
| 音樂、段落或感官當主詞，動詞是走、流、幫                       | 擬人與移動譬喻，實際的聲音或動作沒寫出來                     |

## 跟其他抽象層原則的關係

- [排比句的變動格填了話題自己的定義](/report/parallel-clause-filled-with-the-topics-definition/)：本卡的獨一性斷言用的是那張卡的定義代換測試；那張卡的對象是排比句，這次的對象是一句單獨的斷言。
