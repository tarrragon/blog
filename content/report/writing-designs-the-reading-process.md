## 論述基礎與限制

本卡是一系列修正的收攏。同一批書單改寫與全站清掃先後立了四張卡——#270（解碼材料要在已讀文本裡）、#271（編輯後台不進正文）、#272（不預設考核情境）、#234 的判準一般化——各自處理一個可指認的違規形態。使用者隨後指出這些修正處理的是同一個問題：**閱讀的節奏與讀者的引導**。收攏不是重述：它帶出三個先前各卡沒有明說的機制——節奏的語言基礎（單音節）、壓迫力的疊加結構（密度乘指涉）、引導的正形（主動提醒與分層切入點）。

限制：單音節節奏論是語言學層的機制陳述，本站沒有做過閱讀速度或負擔的量測；「壓迫力」的診斷來自使用者對原稿的直接閱讀經驗，樣本是一位讀者、一種文體。三個設計面的劃分從這一批修正歸納，別的寫作問題可能落在三面之外。

## 核心原則

**文章同時有兩個設計對象：意義（說什麼）與閱讀過程（讀者怎麼讀過去）。** 意義正確而閱讀過程沒有被設計的文章，每一行都讀得懂、整篇讀下來卻累——負擔不出現在任何一句上，出現在句與句的累積裡。閱讀過程有三個設計面。

### 節奏：字數是節奏資源，不是壓縮目標

中文是單音節語言，同樣的語意用的音節比多音節拼音文字少，朗讀與閱讀的節奏更快。需要讀者停下來思考的位置，刻意加字延長閱讀時間是合法且必要的手段——「不僅是」寫成「不僅僅是」、「差別是有無」寫成「差別是有或無而非程度上的高低」，多出來的字不承載新資訊，承載的是思考時間。

這條翻轉了「精簡」的預設方向：字數不是預設要壓縮的成本。精簡的義務只在檢索鍵位（title、description、表格鍵欄——[#261](../sentence-self-sufficiency-by-consumption-unit/) 的消費單位分工）；敘事位的字數服務節奏，該慢的位置就加字。[#270](../decodable-from-text-already-read/) 的書評體密度審美在這一軸上是雙重違規——它同時抽走解碼材料與思考時間。

### 壓力：密度與指涉是相乘的負擔

高資訊密度的句子要求高理解力；不指稱人事物（位置指涉、轉喻、長代詞鏈）要求高記憶力——讀者要一路攜帶未解決的指涉往下讀。兩者疊加時每一行同時收兩種稅，閱讀負擔以壓迫力的形式出現。[#270](../decodable-from-text-already-read/) 的解碼測試管單句；本卡補的是總量視角——每一句都過得了解碼測試的文章，仍可能因為高密度句連續出現而整篇壓迫。診斷問句：讀到這一行時，讀者手上有幾個還沒解決的指涉、上一次可以喘口氣的句子在幾行之前。

### 引導：主動提醒與分層切入點，不要求讀者自我檢討

文章不可能要求讀者時時自我檢討。用到前置概念的位置，正形是**主動提醒**：說出這一段會用到什麼（「讀它會用到實質報酬與兩種平均的差異」）、告訴讀者可以去哪裡回顧或補充（「還不熟的話可以先從某本把概念建立起來，再回來讀」）。要求讀者自我評估（「讀之前先想一下我是否具備 X」）比考核宣判溫和，仍然把檢查的工作派給讀者——預設形態是文章自己把提醒與路由做完。

專業識讀的落差用**一層一層的切入點**承接：術語分級（行內展開 / 連卡 / 裸用）、知識卡、讀者路線，每一層都給下一層的入口，讓不同背景的讀者各自找得到能進入的位置。可及性的底線：即使是高專業內容，也不寫成只有同領域小範圍頂尖讀者才能讀——語句與段落的容易理解跟銜接是最基本的要求，不是對深度的妥協；經驗差距用案例與分層補、技術深度不降。

## 對審查的含義

冷讀 frame 問「看不看得懂」，量的是理解的可能性；本卡加兩問，量閱讀的成本與斷點：

1. **讀起來累不累**（節奏與壓力）：這一段要讀者同時記住幾個未具名的指涉；連續幾行是高密度句、思考時間有沒有被襯出來。
2. **卡住的讀者有沒有被接住**（引導）：用到前置概念的位置有沒有主動提醒與路由；識讀落差有沒有分層的切入點，還是一道門檻直接把讀者擋在外面。

這兩問已落地為多輪審查冷讀 frame 的擴充維度。「看得懂」通過而讀者仍反應累或跟不上時，缺的通常是這兩問。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------- |
| 連續多行高密度句、沒有襯字與停頓                     | 節奏過快——在要讀者思考的位置刻意加字延長閱讀時間                       |
| 讀到某一行要同時記住兩個以上未具名的指涉             | 壓迫力——具名、拆段、或把指涉就地解決                                   |
| 段落用到前置概念而沒有回顧提醒與路由                 | 補主動提醒：這裡會用到什麼、可以去哪裡建立概念、再回來讀               |
| 檢核段要求讀者自我檢討或自我評估                     | 換成主動提醒——文章自己把提醒與路由做完，檢查的工作不派給讀者           |
| 文章只有同領域資深讀者讀得動、理由是「內容本來就難」 | 難的是內容不是語句——語句與銜接先修到容易理解，識讀落差用分層切入點承接 |
| 審查回報「看得懂」而讀者反應「讀起來累」             | 冷讀只量了理解——補「累不累」（節奏壓力）與「有沒有被接住」（引導）兩問 |
