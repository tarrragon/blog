## 結論

誇飾的合法性由段落位置的功能決定、判斷單位是段落、以文件或文體整體一刀切兩個方向都會錯。定位用兩條軸：

- **文體契約**：讀者進場時預期字面精確、還是預期修辭。行銷標語、演講開場、詩、賀詞、產品命名——讀者自帶「這是修辭」的解碼器；規格、教學判準、翻譯、incident report、醫療說明——讀者預期每個字承載資訊。
- **行動耦合**：讀者會不會依這段文字做決策或操作。會、強度詞就是資訊的一部分；只是感受或記住、強度詞是情緒能量的載體。

| 文體契約 | 行動耦合低                      | 行動耦合高                                  |
| -------- | ------------------------------- | ------------------------------------------- |
| 預期修辭 | 誇飾自由區：slogan、詩、賀詞    | 管制邊界區：廣告誘導購買、募資頁面          |
| 預期字面 | 有限使用區：教學 hook、開場敘事 | 零容忍區：規格、SLA、判準段、翻譯、安全陳述 |

「Build something great」落在自由區——沒有讀者把它當成可兌現承諾。同一句話出現在 SLA 裡就換了區。同一份文件內合法性會分區：README 開頭的 tagline 可以誇、往下的 feature 清單每一條都在零容忍區。

## 誇飾合理的情境

1. **原創行銷與品牌文案**：法律上的 puffery（誇大性宣傳詞）概念給出現成界線——「世界第一好吃」構不成不實廣告、因為一般消費者顯然會解碼成修辭；「銷量第一」會被查證。合法界線是「一般讀者會不會把它當成事實宣稱」、跟兩軸判準收斂到同一個位置。
2. **宣告過的再創作（trans-creation）**：在地化標語容許升格、前提是成品被標示為再創作、回頭引用時取原文。
3. **演講、動員、團隊喊話**：目的在能量、聽眾知道自己在聽什麼。
4. **教學的 hook、引言、narrative 段**：口語與強度在入口段幫讀者進入論述、進到判準段就要收。
5. **誇飾到荒謬的幽默與反諷**：「這個 bug 毀了我的人生」反而誠實、因為自我拆穿、修辭性完全外顯。

第五點反過來標出誇飾最危險的區間：**中段強度**——強到失實、又沒強到讓人識破。荒謬級誇飾無人誤信、對位級強度是準確、中段是唯一會被當成事實吸收的失實。

## 該警惕的位置

警惕的觸發條件是誇飾出現在讀者會把強度當成資訊的位置：

| 位置             | 形態                               | 警惕理由                                                        |
| ---------------- | ---------------------------------- | --------------------------------------------------------------- |
| 技術宣稱位       | 「快 10 倍」「零停機」「完美相容」 | 強度詞佔了宣稱的位置、讀者會拿去做選型決策                      |
| 轉述位           | 翻譯、引用、摘要比原文更強         | 每一手轉述都是一次升格機會、離原文越遠強度越膨脹                |
| 判斷工具型段落   | 「這一步非常關鍵」而無機制支撐     | 空誇擠掉了本該放機制的位置、讀者帶走情緒沒帶走判準              |
| 安全與風險陳述位 | 「絕對安全」「不可能被繞過」       | false sense of security 的入口形態                              |
| 自評位           | 「教科書級」「完美」評自己的產出   | 品質 verdict 頂替技術理由                                       |
| AI 產出          | 模型摘要與翻譯的系統性升格         | 文體先驗往 slogan 化與 overclaiming 滑、AI 轉述過的內容預設回源 |

「某論文證明了 X」的「證明」常是從原文「suggests」升格來的——轉述位的警惕對二手內容要加倍。

## 操縱訊號

兩個跨位置的接收端判準：

- **支撐存在測試**：強度詞旁邊有沒有機制或數字。「快 10 倍、benchmark 在此」是宣稱、可以查證；裸的「快 10 倍」是誇飾佔位。這個測試跟鄰詞存在測試同款——都把「感覺誇了」換成一個可檢查的存在性問題。
- **反比操縱訊號**：正常寫作裡、越強的宣稱附上越硬的證據；強度與可驗證性反向——越難驗證的地方話講得越滿（「保證獲利」「絕對有效」）——是推銷與詐騙話術的結構特徵、警惕等級最高。

密度是輔助訊號：單點誇飾是修辭、全篇高密度是文體污染、或者有人在賣東西。

## 降格同樣失實

強度的要求是對齊、而「越低調越安全」是另一種失真。「此漏洞可能造成一些影響」描述一個 RCE、跟「創造奇蹟」描述一句 great 是同一種失真、方向相反。Incident report 與風險溝通場景、嚴重性需要對位的強度詞——SEV1 寫得像 SEV3 的後果比誇飾更貴。審查強度時兩個方向都掃：升格看轉述位與宣稱位、降格看風險陳述位與摘要。

## 判讀徵兆

| 訊號                                 | 該做的事                                          |
| ------------------------------------ | ------------------------------------------------- |
| 撞到誇飾、先想「這算不算違規」       | 改問兩軸：這個位置讀者預期字面嗎、會依它行動嗎    |
| 強度詞旁邊沒有機制或數字             | 跑支撐存在測試；補支撐、或把強度降到有支撐的量級  |
| 越難驗證的段落話講得越滿             | 反比操縱訊號、警惕等級最高、逐條查證或標記不可信  |
| 整份文件用同一標準判誇飾             | 改成分區判定：tagline 位與 feature 清單位標準不同 |
| 風險段落讀起來雲淡風輕               | 掃降格：嚴重性與強度詞對位了嗎                    |
| 審查教學內容時想把 hook 的強度也削平 | 回兩軸表：有限使用區的入口段誇飾合法、判準段才收  |

**核心**：警惕的對象是「強度被當成資訊的位置上、強度與事實脫鉤」。位置功能定合法性、支撐存在定可信度、兩個方向（升格與降格）都要對齊。
