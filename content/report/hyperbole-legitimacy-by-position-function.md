## 結論

審查或閱讀時撞到誇飾、它的合法性由段落位置的功能決定——判斷單位是段落、以文件或文體整體一刀切兩個方向都會錯。位置的功能指的是這個位置對讀者做什麼、拆開是兩條軸：

- **文體契約**：讀者進場時預期字面精確、還是預期修辭。行銷標語、演講開場、詩、賀詞、產品命名——讀者自帶「這是修辭」的解碼器；規格、教學判準、翻譯、incident report、醫療說明——讀者預期每個字承載資訊。
- **行動耦合**：讀者會不會依這段文字做決策或操作。會、強度詞就是資訊的一部分；只是感受或記住、強度詞是情緒能量的載體。

| 文體契約 | 行動耦合低                      | 行動耦合高                                  |
| -------- | ------------------------------- | ------------------------------------------- |
| 預期修辭 | 誇飾自由區：slogan、詩、賀詞    | 管制邊界區：廣告誘導購買、募資頁面          |
| 預期字面 | 有限使用區：教學 hook、開場敘事 | 零容忍區：規格、SLA、判準段、翻譯、安全陳述 |

「Build something great」落在自由區——讀者預設把它解碼成修辭。同一句話出現在 SLA 裡就換了區。同一份文件內合法性會分區：README 開頭的 tagline 可以誇、往下的 feature 清單每一條都在零容忍區。兩個評估細則：行動耦合的評估對象是文字對讀者實際做的事、不是它在文件中的順序——一段文字是多數讀者唯一會讀到的部分時（論文 abstract、新聞標題）、它繼承下游內容的行動耦合、落零容忍區、開場位置本身沒有豁免；文體契約的評估對象取這個位置實際會到達的讀者中解碼器最弱的那一群——內部黑話「這個 service 每天都在爆炸」對老同事在自由區、對剛接 on-call 的新人在零容忍區。管制邊界區的核心是讀者拿修辭去做高代價行動、自身解碼器保護不了自己——商業場景的外部規範（不實廣告法、募資揭露義務）是社會對這個格局的回應。

本卡談強度時沿用轉換保真卡（[#259](../rewrite-preserves-claim-intensity/)）的用語：**量級**指強度的等級（「很棒」與「奇蹟」是同類讚美的兩個量級）、把強度往上拉是**升格**、壓低是**降格**。這張矩陣跟 #259 的責任對象分流是同一塊領土的兩種切法：保真轉換（翻譯、轉述）整列落在零容忍區、原創文案與宣告過的再創作分布在預期修辭的上排——對照寫明後、兩套座標可以互換使用。

## 誇飾合理的情境

合理情境的共同點是至少一軸放行——文體契約預期修辭、或行動耦合低到強度只承載情緒：

1. **原創行銷與品牌文案**：英美法系的誇大性宣傳詞（puffery）概念提供參照——純主觀讚美（「世界第一好吃」）被視為修辭、可量測的宣稱（「銷量第一」）須查證、認定界線因法域而異。共同的判斷核心是「一般讀者會不會把它當成事實宣稱」、跟兩軸判準收斂到同一個位置。
2. **宣告過的再創作（trans-creation）**：在地化標語容許升格、前提是成品被標示為再創作、回頭引用時取原文。
3. **演講、動員、團隊喊話**：目的在能量、聽眾知道自己在聽什麼。
4. **教學的 hook、引言、narrative 段**：口語與強度在入口段幫讀者進入論述、進到判準段就要收。
5. **誇飾到荒謬的幽默**：「這個 bug 毀了我的人生」反而誠實、因為強度本身荒謬到自我拆穿、修辭性完全外顯。反諷另計——它靠語境線索（作者立場、上下文反差）反轉極性、跨文化或跨領域的讀者抓不到線索時沒有自我拆穿效果。

誇飾到荒謬的自我拆穿反過來標出誇飾最危險的區間：**中段強度**——強到失實、又沒強到讓人識破。荒謬級誇飾多半自我拆穿、對位級強度是準確；在升格側、中段是唯一會被當成事實吸收的失實量級（降格側的失實另有形態、見「降格同樣失實」段）。荒謬與中段的界線由讀者的領域知識畫、不是強度的絕對值：「保證年化 30%」對金融從業者是荒謬級、對散戶是會被吸收的中段——這也是反比操縱訊號存在的理由、它補的正是解碼器不足時荒謬級失效的區域。

## 該警惕的位置

警惕的觸發條件是誇飾出現在讀者會把強度當成資訊的位置：

| 位置             | 形態                               | 警惕理由                                                        |
| ---------------- | ---------------------------------- | --------------------------------------------------------------- |
| 技術宣稱位       | 「快 10 倍」「零停機」「完美相容」 | 強度詞佔了宣稱的位置、讀者會拿去做選型決策                      |
| 轉述位           | 翻譯、引用、摘要比原文更強         | 每一手轉述都是一次升格機會、鏈越長量級漂移累積越多              |
| 判斷工具型段落   | 「這一步非常關鍵」而無機制支撐     | 空誇擠掉了本該放機制的位置、讀者帶走情緒沒帶走判準              |
| 安全與風險陳述位 | 「絕對安全」「不可能被繞過」       | 假防護感（false sense of security）的入口形態                   |
| 時程與承諾位     | 「下週就能上線」「零遷移成本」     | 估計偽裝成宣稱、讀者拿它排程與簽約、行動耦合極高                |
| 自評位           | 「教科書級」「完美」評自己的產出   | 品質 verdict 頂替技術理由                                       |
| AI 產出          | 模型摘要與翻譯的系統性升格         | 文體先驗往 slogan 化與 overclaiming 滑、AI 轉述過的內容預設回源 |

「某論文證明了 X」的「證明」常是從原文「suggests」升格來的——二手內容的轉述位逐條回一手來源比對。非文字的強度操縱（數據視覺化的軸截斷）在本卡邊界之外——本卡的判斷單位是段落、圖表另有審查工具。

## 接收端判準

兩個跨位置的接收端判準：

- **支撐存在測試**：強度詞旁邊有沒有機制或數字。「快 10 倍、benchmark 在此」是宣稱、可以查證；裸的「快 10 倍」是誇飾佔位。這個測試跟鄰詞存在測試同構——都把「感覺誇了」換成一個可檢查的存在性問題。
- **反比操縱訊號**：正常寫作裡、越強的宣稱附上越硬的證據；「強度與可驗證性反向」指的是相反的分布——越難驗證的段落話講得越滿（「保證獲利」「絕對有效」）。這個分布是推銷與詐騙話術的結構特徵：單點升格常來自作者無意的文風滑動、而「話最滿的段落恰好最難查證」這種全篇分布比單點升格更難歸因於無意、所以這個訊號的警惕等級最高。

密度是輔助訊號：單點誇飾是修辭、全篇高密度是文體污染、或者這份文字的目的是推銷。

## 降格同樣失實

「此漏洞可能造成一些影響」——這句描述的是一個遠端程式碼執行（RCE）漏洞。強度的要求是對齊、「越低調越安全」是另一種失真：把 RCE 寫成「一些影響」跟把 great 譯成「奇蹟」是同一種失真、方向相反。Incident report 與風險溝通場景、嚴重性需要對位的強度詞——最高嚴重度寫得像例行事件（[SEV1 寫得像 SEV3](/backend/knowledge-cards/incident-severity/)）、應變者會依錯的緊急度分級行動、代價直接落在事故現場。審查強度時兩個方向都掃：升格看轉述位與宣稱位、降格看風險陳述位與摘要。

另一類位置的合法性來自語域的**集體校準**：推薦信、悼詞、年度考績評語——所有作者都升格、讀者的解碼器隨之校準、失實因此消失。這類通膨語域裡照字面寫反而被讀成負評、降格的失實格外重——降格在這裡讀起來是反向評價、超出「低報」的範圍。

## 判讀徵兆

| 訊號                                 | 該做的事                                          |
| ------------------------------------ | ------------------------------------------------- |
| 撞到誇飾、先想「這算不算違規」       | 改問兩軸：這個位置讀者預期字面嗎、會依它行動嗎    |
| 強度詞旁邊沒有機制或數字             | 跑支撐存在測試；補支撐、或把強度降到有支撐的量級  |
| 越難驗證的段落話講得越滿             | 反比操縱訊號、警惕等級最高、逐條查證或標記不可信  |
| 整份文件用同一標準判誇飾             | 改成分區判定：tagline 位與 feature 清單位標準不同 |
| 風險段落讀起來雲淡風輕               | 掃降格：嚴重性與強度詞對位了嗎                    |
| 審查教學內容時想把 hook 的強度也削平 | 回兩軸表：有限使用區的入口段誇飾合法、判準段才收  |

**核心**：警惕的對象是「強度被當成資訊的位置上、強度與事實脫鉤」。位置功能定合法性、支撐存在定可信度、兩個方向（升格與降格）都要對齊。
