## 論述基礎與限制

本卡來自一篇書單導言的兩版對照。原稿由 LLM 生成，兩段共約 320 字，命題完整而讀法緊湊；修訂版由使用者改寫、字數約多兩成，並被指定為後續寫作的風格基準。兩版的命題集合幾乎相同——修訂沒有增刪論點，差異全部落在**解碼成本的分配**上：原稿的每一個壓縮手法，修訂版都有一個對應的展開動作。

證據強度：單一實例、單一文體（書單導言）、單一組作者與改寫者，說明得了形狀、說明不了發生率。其中一項不依賴樣本數：原稿的位置指涉自身就數錯了（見反模式一），這是機制推得出來的失效、不是統計觀察。

第二批證據來自同一篇文章的全篇改寫（立卡後依同一判斷標準掃完其餘七個章節）：共修約 15 處，**位置指涉一類約 10 處、佔比最高**——「前者 / 後者」「第一條 / 後面三條」、當作角色詞散用的「起點書」、以及一處指涉對象在另一份文件裡的跨頁形態；計數錯誤在全篇出現第三次（「另外三本都不碰」實為四本），三次計數三次全錯、分佈在兩個不同章節。單邊對比、隱式結論、破折號懸念各只有一到三處。發生率的宣稱仍限於這一篇；分佈形狀（位置指涉主導）在別的文章要重新量。。第三批證據把樣本擴到另一個分類：一次書單分類的全面重審逐段核對後，七處位置指涉的計數為錯，其中兩處由三份獨立的理解探針同時證實——探針自己數出來的段落與文章宣稱的那一段不同，而三份彼此也不一致。錯的形態涵蓋段落序（「倒數第二段」「最後一段」各差一段）、小節序（「最後一節」實為倒數第二節）、段距（「上一段」實為十五段前且跨一個大節）與欄位序（「下面那張表的最後一欄」實為倒數第二欄）。跨兩個分類、四種計數對象，錯誤率都沒有隨作者的仔細程度下降

限制：修訂版自身的部分措辭偏好（口語連接詞、否定式收尾句）不在本卡的主張範圍——本卡抽的是解碼成本的分配原則，不是那份修訂的全部字面。

## 核心原則

**教學敘事的每一句，解碼所需的材料必須已經在讀者手上——已讀過的正文加上模組基線；動用讀者還沒讀到的後文、或只存在於作者腦中的全篇地圖，都是把作者側的成本轉嫁給讀者。** 判定問句可逐句執行：讀者線性首讀讀到這一句時，能不能當場復原完整命題——指涉的對象是誰、對比的兩面是什麼、結論的操作含義是什麼。復原不了的那一項，就是被壓掉的解碼材料。

機制在生成端：作者（人或 LLM）寫敘事時持有全篇地圖——知道每個條目是什麼、論證往哪收——而文學化的壓縮手法（位置指涉、轉喻、單邊對比、破折號懸念）全部預設讀者共享這張地圖。書評與文藝散文可以這樣寫，因為那些文體的讀者接受重讀與回味，壓縮換來的密度是文體價值的一部分；教學內容的讀者帶問題來、線性首讀，解碼失敗直接折損交付。這是一種語域混入：借來的是書評體的密度審美，代價落在資訊結構上。

展開的價格是字數，而價格**依反模式的類型分層**：具名替換（修位置指涉與轉喻）幾乎不加字——把「前兩本」換成兩個書名是代換、不是擴寫；補全對比、寫出操作結論、展開破折號懸念才真的花字數。實測同一篇文章：隱式結論密集的導言兩段改寫後多約兩成，全篇（違規以位置指涉為主）改寫後只多百分之五。這代表最高頻的違規恰好是最便宜的修法，「展開會讓文章膨脹」不構成保留壓縮的理由；花掉的那些字數是把解碼成本從讀者側移回作者側的價格，不是浪費——敘事位的精簡義務本來就低於檢索鍵位（title / description），見 [#261](../sentence-self-sufficiency-by-consumption-unit/) 的消費單位分工。

## 反模式

四種手法在原稿裡各有可指認的句子。共同結構是：句子語法完整、通順、單獨讀不出毛病，缺的材料只有拿讀者的視角走一次線性首讀才會現形——這也是它們能通過同源審查的原因。

**一、位置與數量指涉。** 原稿寫「本主題前兩本為什麼並收」「另外兩本各補一個分界之外的角色」。解碼「前兩本」要求讀者先讀完後文全部條目、再回頭對照——而且對照會失敗：所指的兩本書在篇內排第一與第三個條目，「前兩本」是作者腦中「兩本主線、其餘輔助」那張地圖上的位置，不是文本上的位置。「另外兩本」同樣錯：剩下的條目實際是三本書（其中兩本合佔一個條目）。全篇掃完後同型錯誤出現第三次：另一個章節寫「本主題另外三本都不碰的那一側」，其餘實際是四本——同一篇裡三次計數三次全錯、分佈在兩個章節。位置與數量都是排列的衍生值（derivation）、不是實體自身的事實（fact），跟 [#155](../reference-by-semantic-title-not-number/) 的編號引用同一個機制——差別在 #155 的錯位要等結構重排才發生，這裡的地圖與文本從第一版就沒對齊過，連作者自己都維護不出正確值。修訂版的動作是具名：「《漫步華爾街》與《智慧型投資人》都探討這兩個問題」，指涉錯位從機制上無從發生。

位置指涉有一個極端形態：**指涉對象在另一份文件裡**。同一篇的另一處寫「這個前提由會計那一篇承接，該篇的起點書提供的程度就夠」——「該篇的起點書」是哪一本，解碼材料在另一頁的第一個章節裡，讀者要離開本文、打開那一頁、找到它的起點條目才拿得到。修法相同：查證後具名（《財報就像一本故事書》）。篇內的位置指涉至少還能靠讀完本篇解碼，跨頁形態連這條路都沒有。

**二、轉喻代替命名。** 原稿寫「一份是報酬數字本身的校準，一份是判斷者這一側」——用角色描述加方位隱喻指涉具體的書，讀者拿到的是謎面，謎底在幾個章節之後。修訂版直說對象加角色：「《窮查理的普通常識》處理做判斷的人的心理」。角色描述可以保留，它要跟名字同時在場、而不是代替名字。

**三、單邊對比與隱式結論。** 原稿寫「留下文字的都是重現成功的那些」——對立面（重現失敗的沒有留下文字，所以紀錄本身偏向成功）留給讀者補；又寫「要分開的是評估它們的證據，不是決定本身」——對比本身正確，而它的操作含義（做決定時要同時考慮兩邊）整個留白，讀者拿到一組對比、拿不到下一步。修訂版把兩處都寫完：「留下文字的都是可複製結果，排除掉不可複製的結果」；「要分開評估兩種決策的指標，但是做決定的時候不應該單獨只考慮一邊的問題」。這跟 [#210](../compressed-conclusion-strips-derivation/) 是相鄰的兩種壓縮：那卡壓掉的是結論的推導、讀者能照做而不能調整；這裡壓掉的是命題的另一半、讀者當場就接不起來。

**四、名詞化主詞與破折號懸念。** 原稿寫「這條分界解釋的是本主題前兩本為什麼並收」——抽象名詞（分界）當解釋句的主詞、具體的書降成受詞子句裡的位置指涉；又寫「選擇的持續有效性要的是另一種東西——」——先立一個空位、破折號之後才揭曉。修訂版讓具體實體當主詞（書探討問題、紀錄經過篩選）、用逗號順接直接給內容。

名詞化主詞有一個高頻來源：**框架欄位名滲進句子當主詞**。用固定欄位組寫作時（本例是每本書共用的四項描述框架），欄位名會直接被拿來起句——「讀得出價值的前提幾乎沒有」。使用者的修訂讓書當主詞：「這本書幾乎不需任何前置作業」；框架的涵蓋不靠標籤在句子裡現身，內容本身就認得出對應哪一項。同一句的後半是隱式結論的又一例：「適合分段讀而非通讀」是抽象的讀法標籤，讀者拿不到行動；修訂版寫成可執行的判斷——「不需要通讀，即使只讀其中一個章節都會有幫助」。

**五（結構層）、並列項擠單段、旁註插斷主線。** 原稿把配置的定義、選擇的定義、兩者不獨立的論證、結論全部放在同一段；「多數投資書把篇幅放在選擇上」這句旁註插在「證據分界 → 選書理由」的推導中間。修訂版把兩個並列定義各自獨立成段、一段一命題，旁註移到主線走完之後當收尾。

## 修法

1. **逐句跑解碼測試。** 讀者只靠已讀過的正文加模組基線，能不能復原「指涉對象、對比兩面、操作含義」三項。缺哪一項補哪一項，補的位置在句內或句前、不在後文。
2. **指涉具名。** 首次出現用全名（書名、人名、概念名），同段之後可用短稱（Malkiel 那本）。向後的近距回指（「上一段的兩個條件」）合法——解碼材料已在讀者手上；跨節回指仍建議具名。位置與數量詞（前 N 個、另外 N 個）出現時順手驗一次計數——它們是作者地圖的衍生值，常常是錯的。回指剛提過的對象用近指「這些」；「那幾條」同時犯兩件事——遠指配近距離的先行詞、「幾條」又多宣告一次計數。**集合指涉（其他三篇 / 另外三本）即使計數正確也要給出成員或方向**——數字只證明數過、不承載意義，成員各自的方向（設計、架構、改舊碼）才是讀者要用的資訊；全稱比較（「取得成本高於其餘各本」——宣稱對全體成立、方向不參與意義）與已具名集合的向後回指不觸發。成員多到列不動的時候，該修的是分類規劃（拆出讀者判斷得了的分組）、不是把引用留成數字——列舉困難是分類壞掉的訊號，不是省略的授權。
3. **對比補全、結論寫到操作層。** 「留下的都是 X」補上「Y 沒有留下」；「要分開的是 A、不是 B」補上「所以做的時候該怎樣」。驗收問句：讀者拿這句話能不能決定下一步動作。對比的軸也要寫明：壓縮的二字對舉把拆軸的工作留給讀者——「差別是有無而非程度」的兩邊是不同性質的軸，展開成「差別是有或無而非程度上的高低」，二元軸寫成選言、量軸寫出刻度。
4. **具體實體當主詞。** 解釋句的主詞優先給書、人、系統、資料這類讀者指認得出的東西；「這條分界 / 這個結構 / 這條線」要當主詞，先確認它在前文有完整的定義句。用固定欄位組寫作時特別掃一次段首——欄位名（「讀得出價值的前提是…」）當主詞是這一類的高頻形態，改成被描述的實體當主詞、欄位對應由內容自己承載。
5. **並列定義各自成段、旁註後置。** 一段一命題；跟主線推導無依賴關係的觀察句，移到該段推導走完之後。
6. **命中是候選、不是判決。** 破折號本身合法——下半句立即給出解碼材料的破折號是節奏選擇；「」內引用、明示的反例對照也合規。判定只看一件事：解碼材料在不在讀者已讀的文本裡。**同一個詞可以兩處兩判**：實測同一篇裡「起點書」出現多次——「它當不了起點書」合法，因為第一個章節的標題「起點是《某書》」已經定義了這個角色、向後回指拿得到綁定；「該篇的起點書」違規，因為綁定在另一份文件裡。掃描抓的是詞面、判定看的是綁定位置，兩步不能合併。

## 判讀徵兆

| 訊號                                                        | 該做的事                                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| 句中出現「前 N 個 / 另外 N 個 / 後者 / 這一側」而對象未具名 | 換成全名；順手驗一次計數——位置與數量是作者地圖的衍生值、常常是錯的       |
| 集合指涉只給數字（其他三篇）、計數正確                      | 仍要給成員或方向——數字不承載意義；列不動時修分類規劃、不是留數字         |
| 對比句只寫了一面（「留下的都是 X」）                        | 把另一面寫出來；被篩掉的那一半通常正是論證要用的                         |
| 對比軸壓成二字對舉（有無 / 多寡 / 高低）                    | 展開讓兩軸各自現形：二元寫成選言（有或無）、量軸寫出刻度（程度上的高低） |
| 「要 X 的是 A、不是 B」收尾、而下一步操作沒寫               | 補上操作含義；驗收是讀者拿這句能不能決定下一步動作                       |
| 抽象名詞（分界 / 結構 / 這條線）當解釋句主詞                | 換具體實體當主詞；抽象名詞要當主詞、先確認前文有它的定義句               |
