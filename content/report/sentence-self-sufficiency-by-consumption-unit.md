## 結論

一個語句的自包含義務由它的**消費單位**決定：設計上會被單獨抽離消費的句子（checklist 項、表格格、判準句、grep 命中的行、章節首句）、必須在句內資訊自足；嵌在段落敘事裡的句子、可以依賴鄰句、壓縮合法。判斷單位是句子的消費方式、跟 #260 用位置功能判誇飾是同一個思考形狀。

**資訊充足**是可檢查的正向規格、四個條件：

1. **命題完整**：主詞在場（誰）、謂語完整（做什麼 / 是什麼）、作用對象與範圍明確（對什麼）、成立條件顯式（什麼時候）。省略只在成分可從句內回收時合法。
2. **指涉閉合**：句中每個代詞、縮略形、殘片名詞、在句內找得到先行詞或完整形；跨句指涉要帶復原提示——完整名詞頭先出現、殘片形後用。
3. **實詞可反推**：每個承載內容的詞能反推到具體機制、條件、契約（沿用 #111 的精度判準）；高度壓縮的謂語（「強到失實」）展開所需的內容要在句內或緊鄰處存在。
4. **一句一命題**：對仗與排比裡的每個半句能獨立判真；把多個命題壓進一個節奏單位時、每個命題各自通過前三條。

驗收測試是**抽離重讀**：把句子單獨交給沒讀過上下文的讀者（人或模型）、命題能不能無歧義復原。回收不了的、在單句消費位是缺陷、在敘事位不強制。

正向規格是刻意的設計選擇：「避免為了美感犧牲資訊」這類負向禁令以模糊審美概念為軸、執行者（尤其是 LLM）要先自行定義「什麼算美感導向的簡潔」、而那個定義只能來自造成問題的同一個文體先驗——禁令沒有梯度、合法的簡潔跟失資訊的簡潔在表面上長得一樣。四條件把違規變成可指認的偏差：「缺主詞」「指涉懸空」比「太簡潔了」可執行。

## 為什麼會寫出資訊不足的句子

壓縮把解歧負擔外移。每省一個成分（主詞、名詞頭、修飾語）、句子變短、節奏變好、而解讀所需的資訊轉嫁給讀者手上的 context。人類的線性閱讀有 discourse memory、多數時候付得起這筆轉嫁；抽離消費的讀者付不起——負擔轉嫁直接變成歧義。

推力來自文體先驗：中文技術寫作的語料充滿四字節奏、對仗、殘句收尾、寫的人（人或模型）往這個典型滑、且滑的當下句子讀起來「更好」——失資訊藏在美感裡、寫作者自己看不到、因為他腦中有完整 context、每個殘片對他都可回收。

| 放大條件                     | 作用方式                                                        |
| ---------------------------- | --------------------------------------------------------------- |
| 中文單字多義                 | 單字是多義語素、壓縮砍掉的正是解歧成分（名詞頭、修飾語、主詞）  |
| 消費者是 LLM：單行檢索       | grep-friendly 設計預期句子被單獨命中、句子卻沒有單獨存活的裝備  |
| 消費者是 LLM：attention 稀釋 | 長 context 裡、幾句前的定義對當前行的注意力權重是機率性的       |
| 消費者是 LLM：風格繼承       | 教學與規範文字是生成素材、壓縮歧義的文風生成壓縮歧義的輸出      |
| 消費者是人：跳讀與搜尋落地   | 掃描式閱讀、從搜尋直達段落中間——discourse memory 跟冷讀者一樣空 |

風格繼承是最深的一層：模型延續素材文風、填補歧義用的正是自己的文體先驗——#259 描述的漂移機制、會被壓縮歧義的規範文字在下游重演。

## Case：一條 checklist 項的修前修後

一份 audit reference 的 checklist 項、修前：

> 反比結構無法用文體先驗的無意滑動解釋、所以警惕等級最高

抽離重讀：「反比結構」是三句前「強度與可驗證性反向」的殘片、兩個變數在句內不可回收；「無意滑動」省略了主詞（作者的）與完整形（文體先驗造成的文風滑動）；「解釋不成無意」把一個完整命題壓成六個字。人類讀者順著段落讀能消化、單獨抽出這行的 reviewer（checklist 正是逐項執行的）拿到的是一串殘片。修後：

> 「話最滿的段落恰好最難查證」這種全篇分布比單點升格更難歸因於無意的文風滑動、所以警惕等級最高

每個指涉在句內閉合、長了十幾個字、抽離後命題完整。這條修法出自一次三輪 agent 審查——篇章層的冷讀 reviewer 全數放行、缺陷由讀者異源指出、因為作者與同源 reviewer 都帶著完整 context 讀、殘片對他們全部可回收。

教學文章側是同一件事的第二個實證：章節用字簡潔到讀者辨識不出議題與關心重點、後續寫作要求補足引導與舉例——問題在句層就發生了、段落層的補救是在替句子還債。

## 消費單位的判定

| 消費單位   | 例子                                                      | 自足義務                   |
| ---------- | --------------------------------------------------------- | -------------------------- |
| 單句消費位 | checklist 項、表格格、判準句、章節與段落首句、grep 目標行 | 四條件強制、抽離重讀是驗收 |
| 敘事位     | 推導過程、case 敘述、段落中段                             | 可依賴鄰句、壓縮換節奏合法 |

分配是三角取捨的解法：用詞精準、總 context 精簡、句子自足三者不可能同時最大化——敘事位省下的字、供應給單句消費位的展開。全域加長跟全域壓縮都是錯的答案。

## 判讀徵兆

| 訊號                                           | 該做的事                                                     |
| ---------------------------------------------- | ------------------------------------------------------------ |
| 句子出現四字節奏、對仗、殘句收尾               | 候選訊號、不是判決——先判消費單位、單句消費位才跑抽離重讀     |
| checklist 項或表格格裡有代詞、縮略形、殘片名詞 | 抽離重讀：指涉在句內回收得了嗎、回收不了就展開               |
| 讀者反映「章節簡潔到看不出議題」               | 問題在句層：掃該章的段落首句與判準句、跑四條件               |
| 給 LLM 讀的規範要新增一條規則                  | 規則句預設是單句消費位、寫完先抽離重讀再入庫                 |
| 修文時想把長句「收乾淨」                       | 先判位置：敘事位可收、單句消費位的展開是功能、長度是它的成本 |

**核心**：句子的美感由讀過上下文的人評、句子的資訊由沒讀過上下文的消費者取——單句消費位為後者寫、四條件是它的規格、抽離重讀是它的驗收。
