## 論述基礎與限制

本卡由兩個相互引用的內容分類的冷讀量測抽出，事件在 2026-08-31。受測的是同一週寫成的兩批文章——一批講各地菜色的辨別，一批講零售金融工具的結構——題材無關而作者相同。

量測用二十九份低階模型探針，每份只讀一個檔，指令明令不得開啟其他檔案、不得用對這個網站其他文章的猜測補完。問的是理解不是評價：逐段寫這一段在說什麼與它跟前一段的關係、哪些詞沒解釋就出現、哪一句預設你已經知道某件事、文章指你去哪裡而有沒有說去了拿到什麼、以及讀完之後這篇讓你具備什麼能力。

兩份控制項混在同一批且不標示：一篇自包含的單一事件記錄，一篇成熟模組的成員（開頭就有前置知識，而它明寫了那個前置並連過去）。兩份都零「說不出關係」、最後一題都答得出來，所以探針做得了這個任務，受測項的回報可以歸因到文章。

改寫一篇樣板之後用逐字相同的指令重測過一次，指令與檔案範圍不變、只有內容變了，所以差異可歸因到改寫。隨後兩輪、九個 frame 的審查又推翻了四項——工具的精確度怎麼算、連結數的分母、承諾的判準，以及症狀那一節分開兩組的編碼。修正都記在對應的段落裡，而推翻的過程本身留在修法段，因為那個形態比被修掉的內容有用。

限制有三項。**單一批次**：兩個分類、同一個作者、同一週。**每份讀不同的檔**，所以這不是分歧量測，「多份都這樣」不構成統計證據；處置門檻仍是一份讀錯就是判決，而每一條都回原文找過對應的句子。**段落之間的銜接沒有量到**，而工具要負責任——回報關係時我給的選項裡有「換一個新題目」，探針挑它就算答得出來，所以測不到「這一段為什麼在這個位置」。

## 核心原則

**相互引用的內容集合裡，有一種文章讀得懂而讀者說不出它要交付什麼。** 這是這張卡的出發點，而它是一個觀察——量測看得到它發生，看不到它為什麼發生（推導與被推翻的兩個假說在下一節）。

那種集合會讓串連看起來像義務：這一道菜要跟那一道分清楚、這個工具要接回上一篇的算式。每一條這樣的引用單獨看都成立。**「它們累加起來把本篇的主題擠掉」是一個未經證實的解釋**，寫在這裡是因為它指出的處置方向被後續量測驗證了（見修法段），而不是因為機制被確認了。

處置的順序是——**先讓這一篇說完自己的事，再決定要不要往外開門，開了門也由讀者決定走不走**。這個順序有獨立的證據：一組改寫之後，冷讀者對「這篇讓你具備什麼能力」的回答從答不出來變成答得出來。但那次改寫同時動了四件事（正文只講自己、串連改寫成條件分支、每個連結補承諾、補上承重術語的定義），**哪一件造成翻轉沒有分離過**。

## 症狀：讀得懂，而說不出它要交付什麼

一篇二十六行的焦糖布丁短文有四個內容段，其中兩段在講別篇——跟另一道甜點的三處差異、以及它的名字在幾個國家指什麼。讀那一篇的探針把每一段的內容都答對了，最後一題卻寫「看不出來」，並自己列了三種互斥的可能：為了點菜不點錯、為了理解文化脈絡、還是為了自己做的時候選對版本。

同一批裡有反例。一篇五十五行的茶碗蒸幾乎整篇在講自己的濃度、高湯與溫度時間，只有最後一節做對照。那份探針的最後一題答得又長又準，並且指出了文章實際想教的那件事（為什麼常見食譜的溫度與時間拆開套用會失敗）。

另一個分類裡同樣的分裂：在正文重述了自己所用框架的兩篇，最後一題答得最具體；其中一篇的探針還自己說出它讀完之後缺什麼。**自足的那些被讀懂了，串連多的那些沒有。**

**這兩個例子的長度也不同，所以要把變項分開。** 把同一批十一篇的行數並排之後，長度不預測結果：答不出來的兩篇是二十五行與二十六行，而二十一行、二十三行、二十三行、二十六行四篇都答得出來。**這一半是穩固的。**

**正向的那一半沒有成立。** 初稿宣稱分開兩組的是「本篇有沒有任何一段在講自己」，並宣稱那兩篇是唯二內容段全部在講鄰居的。後續審查回查改寫前的原文，推翻了這個編碼——兩篇的第一節都在講這道菜自己（一篇講它的各地變體且零連結，一篇講它自己的幾個名字）。**兩個資料點都錯了，而那一欄是唯一分開兩組的證據。**

審查另提了一個替代軸（段標是斷言「這是什麼」還是只說「跟什麼不同」），用正確的陽性重算之後同樣不成立：一篇答得出來的文章，兩個段標也都是差異框架。

**所以這裡沒有一個站得住的因果軸，而不是換一個軸。** 兩個陽性加上事後編碼，這樣導出來的任何分界都撐不住。這一節記下的是一個觀察與一個否定：相互引用的集合裡有文章讀得懂而讀者說不出它要交付什麼；而長度不是原因。**是什麼讓那兩篇落到那裡，這次量測沒有回答。**

## 路由交付什麼量得出來

探針逐條回報每個連結「文章有沒有說去了會拿到什麼」。

**分母是探針讀到的那些連結，不是分類的總數。** 每份探針只讀一個檔，所以下面的數字是各檔被回報的連結加總——料理那一批受測的十一篇共七十二個連結，而該分類全部二十三篇有一百六十個。這個分母要寫出來，因為換成分類總數會讓比例差近一倍。

料理受測的那七十二個連結裡，探針判定有承諾的三個。三個全部是同一種形態——**連結前面掛了一個名詞**：機制見、判法見、判讀順序見。探針對這三個都正確預測了目的地的內容，其餘一律回報「文章沒說」。裸的形態有兩種，行內的「見某某」，以及開頭屬性清單裡的「形態：某某」。

金融那一批受測十六篇、探針回報約一百個連結，有承諾的約一半，而承諾集中在每篇都有的收尾路由段裡。同一批文章的行內連結與術語卡連結仍然是裸的，其中一篇八個連結只有一個說得出目的地。

成熟模組的那份控制項同樣大量裸連結，它唯一被探針正確預測的那個，也是唯一寫了「三種載體的選型標準、遷移安全網、取值出口設計」的那個。**裸連結交付零資訊，這一條不是這兩個分類特有的。**

## 修法

**這套判準測的是以論證為交付的單篇。** 個案實跑撞到四種落在射程外的頁面：術語卡的交付本來就是定義（遮掉連結後剩下定義是正常的）、目錄頁的交付是路由（遮掉連結等於拆掉它的功能）、歸納層的交付是問題與解法、完全不在相互引用集合裡的孤立單篇跑這套判準是空轉。**判準之前先過定位這一關**，理由與程序見 [#302 定位決定體例](../positioning-decides-form-before-any-rule-applies/)——那張卡的結論直接適用於這裡的每一條。


**寫完本篇再開門。** 動筆的順序是先把這一篇自己的主題講完整，往外的引用最後才加。順序顛倒的時候，串連會邊寫邊插進來，而每一處插入單獨看都有理由。

**自足的驗收是把連結遮起來。** 把所有往外的連結當成不存在，這一篇還說得完自己在講什麼嗎。說不完的話，缺的那一段要寫進來。**長度的判準是：寫到本篇的下一句成立為止。** 焦糖布丁那一篇要說明為什麼非得冷藏，用得上的是「凝固帶只有三度所以要壓住升溫」這一句，而三度從哪裡量出來、其他成員各自怎麼控溫，本篇的論證不需要——那些留在承擔它的那一篇。

**替換型的關係寫成條件分支。** 「換掉哪一項會變成什麼」讓串連變成本篇的內容——它說明了這個條件為什麼是關鍵的那一個。形態長這樣：

> **焦糖改成上桌前才燒在表面**：糖沒有經歷吸水的那段時間，維持硬脆、敲得開。這一種只用蛋黃、質地更濃，而且留在烤皿裡不脫模，是[另一道甜點]。

那一句同時交代了本篇為什麼非得讓焦糖經歷冷藏（時間是機制的一部分）與另一道菜在哪裡分開。相較之下「跟某某的分野在焦糖的位置與蛋的部位」是純粹的比對，抽掉之後本篇不會少任何東西。

**而替換只是五種關係裡的一種。** 一次個案實跑逐條檢查二十二個連結，只有一個能寫成替換分支——其餘四種各有自己的形態：

| 關係 | 形態                                                     |
| ---- | -------------------------------------------------------- |
| 替換 | 換掉哪一項會變成什麼                                     |
| 組成 | 本篇的哪一步用到它                                       |
| 展開 | 目的地把本篇這一句推導到什麼程度                         |
| 反查 | 從成品的哪個特徵認得出這一類                             |
| 類比 | 兩者共用的那個抽象是什麼（而參數空間不同，沒有可換的項） |

**把條件分支寫成通用解會逼出硬塞**——一次改寫裡有兩篇被套進它而關係型別根本不對，改回各自的形態才通。

**分支不會順便交代目的地，這兩件事要分別做。** 改寫後的重測顯示，四條寫成條件分支的路由全部被回報成「文章沒說去了會拿到什麼」，探針把它們歸類成舉例說明本篇的論點。分支交付的是本篇的內容（差異在哪），目的地的內容（那一篇會給你什麼）仍然要另外寫。

**判斷標準是內容測試：遮住目的地，讀者能不能從這一句預測出那一篇會給什麼。** 預測得出來就算承諾，寫成什麼句型都可以。

**「預測得出來」有可驗收的形式**：讀者要能寫出一句關於目的地的話，而那句話能被拿去目的地檢查對錯。「那一篇會講勾芡」不算——那是主題詞，對錯無從檢查；「那一篇會列出這一類還有哪些成員，並說明台灣與中國對這個字的要求差在哪」算，因為它可以拿去比對。驗收就是真的拿去比對。對得上是承諾成立；**對不上要當成一項 finding 記下來並指定修法**——改承諾的措辭、或者改目的地讓它承接，兩條路擇一，停在「這是承諾寫錯」這個分類上不算處理完。

**這個測試作者自己跑不了。** 作者知道目的地寫了什麼，所以讀那一句的時候永遠預測得出來——預測的材料來自記憶而不是那一句。所以它需要一個不知道目的地的讀者，而「我預測不出來」這個回報要先歸因：是那一句沒給材料，還是這個讀者缺背景。歸因的方法跟其他探針回報一樣，回原文查那一句到底寫了什麼。

句型只是命中率高低的差別，不是判定條件。實測裡「摩擦成本付給了誰，決定了這個市場是零和還是負和，見[某某]」被判定有說，而「摩擦成本與槓桿的互動在[某某]」被判定沒有說——前者交出了那一篇的結論形狀，後者只給了主題。**但把這個差別寫成「要有謂語」的句法規則會產生假陰性**：同一批裡「這一類的完整成員與兩地要求差在哪，在[某某]」照句法規則判成沒承諾，而它已經說了目的地交付的兩件事。

**這一維的可機械化程度低於它看起來的樣子。** 用「見」與「在」比對連結前綴會把兩種形式都算成有承諾，比例比實際判定高一截；改成比對句法角色則會漏掉上面那種假陰性。要量它就得用冷讀，逐條問「這一句讓你預期那一篇會給什麼」。

**本卡的這一條被改過四次。** 初稿寫「條件分支同時是往外的門」，重測顯示四條分支全部被回報成沒有說；改成「連結前面掛一個名詞」，重測顯示掛了名詞的一半仍被判定沒有承諾；再改成「寫成謂語」，審查找出兩個假陰性；改成上面的內容測試之後，探針指出它沒說什麼叫「預測得出來」，才補上驗收形式。

**前三次的共同點是把一個形式當成判準**——形式可以機械檢查，所以它看起來像已驗證的東西。第四次換了性質：判準本身對了，缺的是它的驗收門檻。這個修法序列本身比其中任何一版有用。

行內連結與術語卡連結尤其要補，因為收尾的路由段通常已經有人在照顧。

**遮住連結之後，第一個要查的是那個貫穿全篇的詞。** 自足的標準拉高之後會浮出一層新的缺口：**承重的術語在自己的主場最容易沒有定義**。一次重測裡，同一個詞在兩篇不同的文章裡都是全篇的軸（那個字要求稠度來自它），而兩篇都沒說它是什麼，由兩份不同的探針各自指出來。原因與一般的術語缺口相反——越承重的詞作者寫得越多，陌生感消失得越早，所以停下來定義它的那一刻從來不會到。

**多個高頻詞的時候，承重的是那個「換掉它整篇就垮」的。** 工具每篇給三個候選，而三個裡通常只有一個承擔全篇的軸——判別是把它從標題與核心段落裡拿掉，看那幾句還成不成立。剩下兩個多半是題材的常用詞（溫度、派皮），它們沒有被定義也不影響論證。

**產生候選這一步可以機械化，判定那一步不行。** 把正文的高頻詞排序、濾掉功能詞與這次改寫所採用的行文習慣用語（同一批稿件共用的句型，不是該領域的術語），每篇取前三個；四十四篇跑出來是一百二十九個候選，逐個回原文看首次出現處有沒有一句話說明。**這個工具的精確度沒有量過，因為那一百二十九個候選沒有被逐條查完。** 實際回查的是人從裡面挑出來的少數幾個，挑的時候已經帶著判斷，所以它們的命中情形不能當成這個工具的表現。要知道精確度就得把一百二十九個全部走完，而那件事還沒做。

腳本在 `scripts/loadbearing-terms.py`。射程有三個限制，寫在它的檔頭：只掃連續的漢字（英文術語看不到）；單字要在詞邊界上反覆出現才進候選，否則會被大量複合詞碎片淹沒；比對要取重疊窗，非重疊比對會讓頻率變成字元相位的函數；**主題詞與承重詞在這個工具下不可分**——一篇講連結的文章裡「連結」必然排在前面，而它不是那篇沒定義的詞。第三項是實作過程中撞到的——第一版用非重疊比對，「凝固溫度」出現三次只數到兩次，回報的排序因此不是頻率排序。

**濾詞表要隨這一批的文體調整。** 第一次跑的時候，佔據多數檔案首位的是本批新採用的路由句型而不是任何術語——**新體例會製造自己的高頻詞**，而那些詞對這個掃描是雜訊。判斷標準是問這個詞承不承擔內容：承擔的留下，只是行文接縫的濾掉。

## 每一條判定都要附它的輸入

上面每一條規則的最省力遵循方式都一樣：在腦中判一次，在報告寫一句通過。而**那個判定認真做過與完全沒做，產物完全相同**——這一組規則的所有判定又都由知道答案的作者執行，所以「我判過了」不構成證據。

判定本身不是產物，**判定用的材料才是**：

| 判定                           | 要附上的輸入                                                   |
| ------------------------------ | -------------------------------------------------------------- |
| 這一篇自足                     | 遮掉連結之後剩下的段標清單，逐條標「講自己／講鄰居」           |
| 這個概念不是主線、可以換成連結 | 遮掉它之後仍然成立的那一句原文                                 |
| 這一篇沒有承重術語沒被定義     | 三個候選各一句「拿掉它之後那幾句還成不成立」，不只寫中選的那個 |
| 這條路由有承諾                 | 冷讀者預測出來的那句原話，以及拿去目的地比對的結果             |
| 這一批不必調濾詞表             | 「本批新增濾詞：無」這一行                                     |

**「不適用」「不需要」「份量不夠」這三個結論最省力，因為它們不產出任何東西可供檢查**——判成它們的時候尤其要附輸入。同樣的道理套在數量上：取前三個候選是上限而不是配額，實際查了幾個、還剩幾個沒查，要寫出來。

## 為什麼審查抓不到

**交叉引用在多數審查 frame 裡是加分項。** 路由完整度查的是有沒有連過去，雙向性稽核查的是反向有沒有補，目的地承接查的是那一頁對不對。三者都在確認連結該有而沒有，**沒有一個在問連結佔掉了多少篇幅**。

**逐句讀不出來**，因為每一句都在講一件對的事，而且多半是查證過的事實。

**冷讀 frame 也不一定抓到。** 冷讀問的是讀不讀得懂，而這種文章讀得懂——它只是薄。要問「這篇讓你具備什麼能力」才現形，而那一題的答案是「看不出來」或者三種互斥的猜測。**讀得懂與有內容是兩件事，冷讀預設它們是同一件。**

## 跟其他原則的關係

- [#199 一篇文章只承擔一種功能](../single-function-per-article-sop-vs-retrospective/) 管的是一篇同時塞了兩種功能（操作步驟與批次紀錄），兩種讀者各自找不到自己那半。本卡管的是功能只有一種而篇幅被鄰居佔走。兩者的判定不同：那張卡問這一篇在做幾件事，本卡問這一篇有幾成在講自己。
- [#262 內容超出容器時擴充結構、不壓縮內容](../content-pressure-resolves-by-expansion-not-compression/) 給的三個出口裡有一個是換成連結。本卡界定它的前提——換成連結的條件是本篇的主線不靠它，而判別要用遮住連結的那個驗收。那張卡已經寫了主線概念必須行內展開，本卡補的是怎麼量出主線被搬走了多少。
- [#240 跨模組路由要驗證目的地承接該主題](../routing-destination-must-own-the-topic/) 驗的是目的地對不對，本卡驗的是路由本身交付什麼。兩者可以同時失效也可以各自失效：一個指向正確且承接該主題的裸連結，通得過那張卡而在本卡下是零資訊。
- [#302 定位決定體例](../positioning-decides-form-before-any-rule-applies/) 出自同一批稿件的另一個缺陷，而軸不同——那張卡管這一段的體例屬於哪一種定位，本卡管這一段講的是本篇還是鄰居。同一段可以同時命中兩者。
- [敘事的解碼材料要在讀者已讀的文本裡](../decodable-from-text-already-read/) 是本卡症狀的句子層形態：對照的另一面靠連結承擔的時候，讀者手上就沒有那一面。那張卡逐句判定，本卡判定整篇的篇幅分配。

## 判讀徵兆

這幾條是候選訊號、不是判準。**分開兩組的那條軸目前沒有定論**（見症狀節），所以下面前兩條只用來挑出值得細看的稿件，不用來判定。

- 問一份冷讀「這篇讓你具備什麼能力」，答案是「看不出來」，或者列出兩種以上互斥的可能。**這一條是這張卡唯一經過量測的訊號。**
- 小節標題大量帶著鄰居（專名或「兩道菜」這類類別詞都算），而數段標只是篩選——判定要看那一段講的是本篇還是鄰居。
- 把所有往外的連結遮起來之後，這一篇剩下什麼。剩下的東西該長什麼樣依這一篇的定位而定：教材要剩得下論證，術語卡剩下定義是正常的。
- 文章列出某一項跟另一項的三處差異，而另一項是什麼，本篇沒說。
- 遮住連結的目的地之後，讀者從那一句預測不出那一篇會給什麼。
- 一篇裡出現頻率最高的實詞找不到說明——**而這一條有大量假陽性**：主題詞必然高頻（一篇講連結的文章裡「連結」一定排在前面），先用「拿掉它之後那幾句還成不成立」濾一次。
