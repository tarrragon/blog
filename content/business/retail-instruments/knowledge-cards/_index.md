這個目錄收錄[零售金融工具的結構判讀](../)各篇用到的術語。每張卡處理一個術語的定義、它在計算或判讀裡的位置、以及判讀方式。

收錄的術語分三組，下面各自一張表。**計算參數**是算單一部位損益之前要先查出來的值——曝險規模、持有成本、存活條件。**盤面修正項**是市場公布的數字與實際數量之間的差距，以它們為輸入的指標要先扣掉這個差距才有意義。**操作手法**是社群上流通的做法。

前兩組與第三組的消費方式不同，所以表格的欄位也不同。查參數的人在一個算式中間，他要的是這張卡算出什麼；查手法的人是聽到了一個沒做過的說法，他要的是這個說法指什麼動作——而他手上多半只有俗稱，所以手法那張表把其他稱呼列在卡名旁邊。同一個動作在期貨、加密與股票社群各有不同的叫法，其中有幾個在不同語域指不同的事（「全倉」是最明顯的一個）。手法之間怎麼互相對照、各自動到損益的哪一項，在[社群流行手法的共同結構](../social-trading-patterns/)。

這批術語與[商業概念知識卡片](/business/knowledge-cards/)分屬不同語域：那裡收的是解讀商業分析文章需要的術語（單位經濟、估值、進入市場），這裡收的是計算部位損益、判讀市場微結構、以及辨認社群手法所需的術語，兩套不併入同一個索引。

## 計算參數

| 卡片                                                    | 算出什麼                                           |
| ------------------------------------------------------- | -------------------------------------------------- |
| [Contract Multiplier（契約乘數）](contract-multiplier/) | 指數點數換算成金額，決定曝險規模與成本比例         |
| [Basis（基差）](basis/)                                 | 跨期或跨市場的價格差，決定組合部位的殘餘曝險       |
| [Funding Rate（資金費率）](funding-rate/)               | 永續合約按時間累積的持有成本，同時反映部位擁擠度   |
| [Liquidation Price（清算價）](liquidation-price/)       | 強制平倉的觸發價格，決定部位的存活條件             |
| [Implied Volatility（隱含波動率）](implied-volatility/) | 選擇權價格中的估計成分，決定方向以外的損益來源     |
| [Margin Financing（融資）](margin-financing/)           | 擔保維持率，決定台股信用交易部位被追繳與斷頭的位置 |

## 盤面修正項

| 卡片                                      | 要扣掉什麼                                             |
| ----------------------------------------- | ------------------------------------------------------ |
| [Free Float（流通量）](free-float/)       | 掛牌總量與實際可交易數量的差距，決定價格對資金的敏感度 |
| [Wash Trading（沖洗交易）](wash-trading/) | 回報成交量與實際換手的差距，決定量能指標可不可信       |

## 操作手法

| 卡片                                                                       | 其他稱呼                                                                         | 這是什麼動作                                     |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------ |
| [凹單](letting-losses-run/)                                                | 常與攤平混用；letting losses run 只涵蓋其中一種形式                              | 走到原定該認賠的價位而不認賠，繼續持有或繼續加碼 |
| [Locked Position（對鎖）](locked-position/)                                | 鎖倉、鎖單、多空對鎖、多空雙開                                                   | 開反向部位把帳面損益停在當下                     |
| [Martingale（馬丁格爾加碼）](martingale/)                                  | 倍投、馬丁、馬丁格爾機器人                                                       | 每次虧損後把下注金額加倍                         |
| [Averaging Down（攤平）](averaging-down/)                                  | 向下攤平、向下加碼、逢低補倉                                                     | 下跌後繼續買進，拉低平均成本                     |
| [Cross Margin / Isolated Margin（全倉與逐倉）](cross-and-isolated-margin/) | 全倉、逐倉、獨立保證金（加密合約平台用語）；股票語域的「全倉」「滿倉」是另一件事 | 選擇保證金算整個帳戶還是算單一部位               |
| [Copy Trading（跟單交易）](copy-trading/)                                  | 複製交易、帶單、喊單                                                             | 讓平台把別人的下單複製到自己帳戶                 |
| [Leveraged Token（槓桿代幣）](leveraged-token/)                            | 3L / 3S、正 2、反 1                                                              | 買一個由發行方代為維持槓桿倍數的代幣             |
