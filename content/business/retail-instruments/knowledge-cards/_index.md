這個目錄收錄[零售金融工具的結構判讀](../)各篇用到的計算基礎術語。每張卡處理一個術語的定義、它在計算或判讀裡的位置、以及判讀方式。

收錄的術語分兩組。前一組是計算單一部位損益所需的參數——曝險規模、持有成本、存活條件。後一組是判讀盤面數字所需的修正項：市場公布的供給量與成交量各自與實際數量有差距，兩個差距都要先扣掉，以它們為輸入的指標才有意義。

這批術語與[商業概念知識卡片](/business/knowledge-cards/)分屬不同語域：那裡收的是解讀商業分析文章需要的術語（單位經濟、估值、進入市場），這裡收的是計算部位損益與判讀市場微結構需要的參數，兩套不併入同一個索引。

## 收錄卡片

| 卡片                                                    | 承擔的計算或判讀責任                                 |
| ------------------------------------------------------- | ---------------------------------------------------- |
| [Contract Multiplier（契約乘數）](contract-multiplier/) | 把指數點數換算成金額，決定曝險規模與成本比例         |
| [Basis（基差）](basis/)                                 | 跨期或跨市場的價格差，決定組合部位的殘餘曝險         |
| [Funding Rate（資金費率）](funding-rate/)               | 永續合約按時間累積的持有成本與部位擁擠度             |
| [Liquidation Price（清算價）](liquidation-price/)       | 強制平倉的觸發價格，決定部位的存活條件               |
| [Implied Volatility（隱含波動率）](implied-volatility/) | 選擇權價格中的估計成分，決定方向以外的損益來源       |
| [Free Float（流通量）](free-float/)                     | 實際可交易的數量，決定價格對資金的敏感度             |
| [Wash Trading（沖洗交易）](wash-trading/)               | 回報成交量與實際換手之間的差距，決定量能指標可不可信 |
