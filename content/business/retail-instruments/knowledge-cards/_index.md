這個目錄收錄[零售金融工具的結構判讀](../)各篇用到的計算基礎術語。每張卡處理一個術語的定義、它在損益計算裡的位置、以及判讀方式。

這批術語與[商業概念知識卡片](/business/knowledge-cards/)分屬不同語域：那裡收的是解讀商業分析文章需要的術語（單位經濟、估值、進入市場），這裡收的是計算衍生品部位損益需要的參數，兩套不併入同一個索引。

## 收錄卡片

| 卡片                                                    | 承擔的計算責任                                 |
| ------------------------------------------------------- | ---------------------------------------------- |
| [Contract Multiplier（契約乘數）](contract-multiplier/) | 把指數點數換算成金額，決定曝險規模與成本比例   |
| [Basis（基差）](basis/)                                 | 跨期或跨市場的價格差，決定組合部位的殘餘曝險   |
| [Funding Rate（資金費率）](funding-rate/)               | 永續合約按時間累積的持有成本與部位擁擠度       |
| [Liquidation Price（清算價）](liquidation-price/)       | 強制平倉的觸發價格，決定部位的存活條件         |
| [Implied Volatility（隱含波動率）](implied-volatility/) | 選擇權價格中的估計成分，決定方向以外的損益來源 |
