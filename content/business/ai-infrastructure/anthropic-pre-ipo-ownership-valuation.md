Anthropic 在 IPO 前夕的股東結構與估值，可以拆成這幾個部分：各類股東（早期與成長期的財務投資人、Amazon 與 Google、IPO 時同步認購的晶片與雲端業者、共同創辦人與員工、長期利益信託與公益基金）各自用什麼工具、在什麼價格取得股份；各輪[可轉換特別股](/business/knowledge-cards/convertible-preferred-stock/)的價格換算成拆股後每股之後的估值軌跡；IPO 價格區間的中間值乘上不同的股數分母，各得到多大的市值；[可轉換本票](/business/knowledge-cards/convertible-note/)的公允價值變動怎麼讓估值上升在 Anthropic 帳上記成損失，以及這個效果在上市後怎麼延續；Amazon 與 Google 的持股上限、超過上限時換發的不計息本票，以及跟算力里程碑連動的後續出資；晶片、記憶體、晶圓代工與雲端業者在 IPO 同步認購的條款；[多重股權結構](/business/knowledge-cards/multi-class-shares/)下 Class A、N、T、F、E 各自的投票權與經濟權；上市之後仍會持續發生的[股權稀釋](/business/knowledge-cards/dilution/)；以及[閉鎖期](/business/knowledge-cards/lock-up-agreement/)依股東群組分批解禁的安排。資料依據是 Anthropic 2026-11-10 提交的第二次修正版 IPO 註冊文件（S-1/A-2），股數與價格以這一版為準，正式定價後會改變；2026 年前九個月的報表未經查核。Anthropic 算力租約與 Broadcom 本票的融資結構寫在 [Anthropic 的算力融資結構](/business/ai-infrastructure/anthropic-compute-financing/)；員工手上的股份在離職時怎麼處理、競業條款在加州的效力，寫在[上市前公司的員工股權與離職限制](/business/financial-analysis/pre-ipo-employee-equity-departures/)；把同一份申報文件當成材料，評估一家上市前公司的經營風險與財報可信度，寫在[上市前企業的經營風險與財報可信度](/business/financial-analysis/pre-ipo-risk-and-statement-credibility/)。

## 股東取得股份的工具與價格

Anthropic 的股東依取得股份的工具分成幾群，每一群在 IPO 時轉成不同類別的普通股。S-1/A-2 用「Preferred Stock Conversion」「Convertible Notes Conversion」這類名稱描述 IPO 前一刻發生的轉換。Amazon 與 Google 的投資多半經由本票購買協議（note purchase agreement，NPA）進行：協議約定公司可以發行可轉換本票、特別股或無表決權普通股給對方，以及每一種的條件。下表把各群股東、他們手上的工具與轉換後的股別對在一起：

| 股東                                    | 手上的工具                                                                    | 取得價格的基礎                                             | IPO 時轉成的股別              |
| --------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------- | ----------------------------- |
| 早期與成長期的財務投資人                | 各輪可轉換特別股（Series A 到 H）                                             | 每一輪的認購價                                             | 依系列轉成 Class A 或 Class N |
| Google                                  | 2023、2024 年的本票（已全部轉成無表決權特別股）、Series G-2、Series H         | 本票的轉換價、G-2 每股 259.1364 美元、H 每股 589.0095 美元 | Class N                       |
| Amazon                                  | 2023、2024 年的本票（超過持股上限的部分換發成新的本票）、Series G-2、Series H | 本票的固定轉換價（拆股後 2.0928 與 5.0478 美元）、G-2、H   | Class N（受持股上限）         |
| 晶片、記憶體、晶圓代工與雲端業者        | IPO 同步私募                                                                  | IPO 價格                                                   | Class N                       |
| 共同創辦人與員工                        | 普通股、員工認股權、限制型股票單位（RSU）                                     | 認股權的履約價（加權平均 2.91 美元）、RSU 授予時的公允價值 | Class A                       |
| 長期利益信託（Long-Term Benefit Trust） | 一股 Class T                                                                  | 無經濟權                                                   | Class T                       |
| 共同創辦人組成的 Founder LLC            | IPO 前發行的一股 Class F                                                      | 無經濟權                                                   | Class F                       |
| Anthropic Public Benefit Fund           | 公司捐入的 846,840,960 股 Class N                                             | 公司發行，無對價                                           | Class N（全資子公司持有）     |

同一家公司的股東，取得每股的成本從一兩美元到 IPO 價格不等，「取得價格的基礎」一欄的差距來自取得的時點與工具。同一輪特別股依投資人的類型分成幾個子系列，有表決權的系列（A、C-1、D-1、D-2、E-1、F-1、G-1、H-1）轉成 Class A，給策略投資人的無表決權系列（B、C-2、D-3、E-2 到 E-5、F-2、G-2 到 G-4、H-2 到 H-4）轉成 Class N。

Amazon 那一列的「換發」是這樣來的：Amazon 的本票有持股上限，轉換之後會讓 Amazon 超過上限的那部分本金，公司收回原本票、換發一張不計息的新本票，S-1/A-2 稱為 rollover note，本文寫成換發本票；它在上市後分季轉換，條件寫在〈Amazon 與 Google 的持股上限與轉股安排〉。

表上有兩個以公益為目的的主體。長期利益信託（LTBT）依 S-1/A-2 的設計，由跟公司沒有財務利害關係、專長在 AI 安全、國家安全、公共政策與社會企業的受託人組成，持有的那一股 Class T 讓它選任董事會的過半數；Anthropic 依德拉瓦州法設立為公益公司（public benefit corporation，PBC），董事依法要在股東的財務利益與章程寫明的公益目的之間權衡；Anthropic Public Benefit Fund 是它的全資子公司，宗旨就是那個公益目的，公司捐入股份讓它持有。兩者都沒有分配盈餘的經濟權。特別股與本票的條款寫在 S-1/A-2 的〈Certain Relationships and Related Person Transactions〉與財報附註，員工股權的條款寫在〈Executive Compensation〉。

## 各輪價格換算成拆股後每股的估值軌跡

Anthropic 在 2026-09-17 把 Class A 與 Class N 普通股一股拆成十股，特別股的轉換率同比例調整，所以每股特別股在 IPO 時轉成十股普通股。各輪特別股的認購價除以十，就是換算成上市後每股普通股的成本。S-1/A-2 的關係人交易一節列出 Series C 以後各輪的期間與認購價：

| 輪次        | 期間          | 每股特別股認購價（美元） | 換算成拆股後每股普通股（美元） | 對前一輪的倍數 |
| ----------- | ------------- | ------------------------ | ------------------------------ | -------------- |
| Series C    | 2023-03 至 06 | 11.2261                  | 1.12                           | —              |
| Series D    | 2024-01 至 05 | 30.0045                  | 3.00                           | 2.7            |
| Series E    | 2025-01 至 03 | 56.0865                  | 5.61                           | 1.9            |
| Series F    | 2025-08 至 09 | 140.9676                 | 14.10                          | 2.5            |
| Series G-1  | 2026-01 至 02 | 259.1364                 | 25.91                          | 1.8            |
| Series H-1  | 2026-05 至 06 | 589.0095                 | 58.90                          | 2.27           |
| IPO（假設） | 定價日        | —                        | 74.00（區間中間值）            | 1.26           |

倍數一欄是本文的換算：相鄰兩列「換算成拆股後每股普通股」相除。Series H-1 是 IPO 前最後一輪，S-1/A-2 寫明這一個子系列募得約 457.3 億美元（同一輪的 H-2 到 H-4 另計；Google 投入 100 億、Amazon 投入 50 億）；從 G-1 到 H-1 的四個月內，每股價格升為 2.27 倍，IPO 區間中間值 74 美元再是 H-1 的 1.26 倍。Amazon 2023 與 2024 年本票的固定轉換價（拆股後 2.0928 與 5.0478 美元）落在 Series C 到 E 之間，所以 IPO 價格越高，這兩批本票換到的股份價值越高，這一點是〈可轉換本票的公允價值變動與損益〉那筆損失的來源。

IPO 價格乘上股數就是[市值](/business/knowledge-cards/market-cap/)，而股數的分母有幾種選法，選法決定得出的數字：

- **會計上流通在外的 Class A 與 Class N**：IPO 與同步私募之後約 74.28 億股 Class A 加 48.12 億股 Class N，合計約 122.4 億股，乘上 74 美元約 9,057 億美元。這個計算基礎不含公益基金持有的股份：那批股份法律上流通在外，但由全資子公司持有，會計上不算流通。
- **法律上流通在外的全部 Class A 與 Class N**：S-1/A-2 的稀釋分析用的股數是 130.87 億股（含公益基金那 8.47 億股），乘上 74 美元約 9,684 億美元。本文其他地方說「占 Class A 與 Class N 合計」的比例，都用這個分母。
- **再加上已經存在、之後會變成股份的權利**：17.74 億股認股權（加權平均履約價 2.91 美元，這裡以總股數計，沒有扣掉履約款可以買回的股數）、10.27 億股服務條件尚未滿足的 RSU、Amazon 換發本票可轉的 15.64 億股、員工捐贈配對計畫最多可能發行的 5.53 億股（計畫內容在〈上市之後仍會發生的稀釋〉）。這些全部轉成股份時，分母還要再加約 49 億股，用這個分母算出的市值超過 1.3 兆美元。S-1/A-2 自己的完全稀釋表對認股權用庫藏股法（假設履約款拿去以 IPO 價格買回股份），淨增加的股數比總股數少約 0.7 億。

這幾個市值都是本文用 S-1/A-2 的股數乘上假設價格算出來的，Anthropic 沒有在文件裡寫出市值。一篇報導寫的「估值」沒有交代分母時，兩家公司估值的差距可能有一部分來自分母的選法，換到同一種分母之後，差距才反映公司價值；拿市值除以營收、跟同業比營收倍數時，還要對齊營收的認列方式（[上市前企業的經營風險與財報可信度〈營收認列的判斷點：總額或淨額〉](/business/financial-analysis/pre-ipo-risk-and-statement-credibility/#營收認列的判斷點總額或淨額)）。估值方法本身（市值、企業價值與各種倍數的分工）寫在[企業估值方法〈EV 和市值的差異〉](/business/financial-analysis/valuation-methods/#ev-和市值的差異)。

## 可轉換本票的公允價值變動與損益

Anthropic 2026 年前九個月淨損 1,040.39 億美元，其中 943.24 億來自「可轉換本票、衍生負債與未來股權簡單協議（simple agreement for future equity，SAFE：投資人先付錢、等下一輪定價時才換成股份的協議）的公允價值變動」。這個項目的成因是 Anthropic 把這些工具列為負債，而且以[公允價值](/business/knowledge-cards/fair-value/)衡量：每一季重新估一次它們值多少，估值的增加記為損失。

Amazon 2023 年那批本票示範了這個機制。這批本票本金 21.86 億美元，持有人 Amazon 可以用每股 2.0928 美元轉換，可轉的股數是 21.86 億除以 2.0928，約 10.45 億股。IPO 價格 74 美元時，這些股份值約 773 億美元，是本金的 35 倍左右。從持有人這一側看，Amazon 得到的是「用固定的低價換股」的權利，Anthropic 的股價越高，這個權利越值錢；從發行人這一側看，Anthropic 將來要交給 Amazon 的股份價值也越高，所以 Anthropic 的負債增加，增加的部分在 Anthropic 的損益表記為損失。兩批 Amazon 本票合計本金 62.03 億、可轉 18.40 億股，乘上 74 美元約 1,362 億，S-1/A-2 資產負債表上 2026-09-30 的可轉換本票負債是 1,305.02 億，兩者的量級一致。

這筆損失不需要付現金：本票轉股時，負債轉成股東權益，Anthropic 沒有付出任何現金。不付現金不代表沒有人承擔成本：Amazon 以 62 億本金換到價值約 1,362 億的股份，差額由其他股東以持股比例下降的形式承擔；換發本票到期仍沒有轉換的部分，則要以現金償還或跟商業款項抵銷。S-1/A-2 的資本化表把 IPO 前一刻的轉換算進去：Amazon 的 18.40 億股可轉股數裡，有 2.77 億股在 IPO 時轉換，可轉換本票負債從 1,305.02 億降到 1,108.73 億，剩下的 1,108.73 億就是那 15.64 億股的換發本票；帳面 1,575.10 億的可贖回可轉換特別股（列在負債與股東權益之間）也全部轉成普通股。這兩項轉換，再扣掉上市時 RSU 交付要代繳稅款而新增的負債約 38 億，股東權益從負 1,498.73 億變成擬制數（假設這些轉換在 2026-09-30 完成）正 234.49 億。

帳上 1,561.93 億的累積虧損，由下列各項累積而成（本文加總損益表 2023 年到 2026 年前九個月的逐年數字）：公允價值變動損失約 1,351 億、營業損失約 129 億、其他收支淨額約 104 億（主要是 2026 年與 Amazon、Google、AMD 的融資協議初始認列與後續公允價值變動），扣掉利息收入約 30 億，再加上所得稅、2023 年以前的累積虧損與 2025 年買回普通股的影響，各約 1 到 4 億。非現金的公允價值損失占了絕大部分。

公允價值的估法本身是查核的重點。Ernst & Young 在 2025 年報表的查核報告裡把「可轉換本票的公允價值」列為[關鍵查核事項](/business/knowledge-cards/critical-audit-matter/)：Anthropic 用兩種方法估值再加權平均，一種是或有請求權分析（contingent claims analysis，把本票當成一組依未來情境支付的權利、用選擇權的方法估價），另一種把它當成等量的普通股估價，兩種方法的權重取決於上市的可能性、後續融資與次級市場的成交，而估出的數字「對兩種方法的權重特別敏感」。2025 年底可轉換本票的公允價值是 417 億，全年認列的損失是 345 億。上市之後股價有每日的市價，估值的判斷空間縮小，但重新衡量本身沒有結束。

上市之後，Amazon 的換發本票仍是以公允價值衡量的負債，所以 Anthropic 的損益會繼續隨自己的股價反向變動：股價上漲，換發本票的價值上升，記為損失；股價下跌，記為利得。換發本票可轉約 15.64 億股，假設公允價值接近轉換價值，股價每變動 1 美元，負債大約變動 15.6 億美元，這是本文的近似推算，實際的變動還受估值方法與轉換時點影響。上市後的淨損益因此含一項由股價決定的成分，營業損益與營業現金流不含這一項；Anthropic 營業層的損益與營業現金流（前九個月營業現金流正 65.69 億）寫在[上市前企業的經營風險與財報可信度〈經營風險：成本結構與營業現金流〉](/business/financial-analysis/pre-ipo-risk-and-statement-credibility/#經營風險成本結構與營業現金流)。S-1/A-2 的擬制每股虧損只剔除了已經轉股與 IPO 時轉股那幾批本票的公允價值變動（2026 年前九個月 147.27 億），換發本票的變動仍留在擬制淨損裡。

## Amazon 與 Google 的持股上限與轉股安排

Amazon 與 Google 都是 Anthropic 的大股東，同時是它的算力供應者與銷售通路。兩家的持股都以 Class N 持有，這一類股份沒有表決權，經濟權與 Class A 相同，轉讓給沒有關係的第三方時轉成 Class A。IPO 與同步私募之後，Amazon 持有約 19.21 億股、Google 約 17.90 億股 Class N，以法律上流通在外的 130.87 億股計，各約占 14.7% 與 13.7%（本文計算）。

兩家的持股都有上限，上限決定了它們的投資怎麼轉成股份：

- **Amazon 的上限是 12%**，上限的分母比上面的 130.87 億股更大：它包括全部流通股，再加上認股權、RSU 與其他可轉換證券可以換到的股數。所以 Amazon 依流通股算是 14.7%，依上限的分母算仍在 12% 以內，IPO 時能轉換的 2.77 億股就是依這個分母算出的最大數。轉換之後會超過上限的那部分本金，由公司換發成不計息的換發本票：每季末以固定轉換價、IPO 價格與前十個交易日成交量加權平均價（VWAP）三者最低者轉換，仍以上限為界；到期（2034 至 2035 年）還沒轉換的部分，Anthropic 以現金償還，或由 Amazon 選擇把這筆償還額，跟 Amazon 依商業協議應付給 Anthropic 的款項抵銷。Amazon 可以自行放棄上限，但這次 IPO 沒有放棄。上限的分母隨總股本變大，Amazon 的換發本票可以轉換的股數也跟著增加。
- **Google 的上限是 14.99%**（依 Google 2026 NPA 計算，分母是發行後、所有可轉換證券都轉換後的總股本）。Google 的出資在換股時會超過上限的部分，同樣以不計息的換發本票處理。

兩家在 2026 年簽的新協議，各自包括一筆特別股認購與一個後續出資的額度，額度跟 Anthropic 的算力建置或營收連動：

- **Amazon 2026 NPA（2026-04）**：承諾以每股 259.1364 美元認購 1,930 萬股 Series G-2（約 50 億）；另有一個 200 億的額度，Amazon 在 2026 年 5 月投入 Series H 的 50 億從額度扣除後，剩 150 億。額度依 Anthropic 與 Amazon 商業協議約定的算力容量里程碑，每完成一個開放 50 億（S-1/A-2 沒有揭露里程碑的量法，例如以多少機櫃或電力容量計）；IPO 後每次動用都以里程碑達成日前 30 日的 VWAP 發行 Class N，可動用到 IPO 後 30 個月，或兩家的特定商業協議終止時提前結束。
- **Google 2026 NPA（2026-03）**：承諾認購 3,860 萬股 Series G-2（約 100 億）；另有最高 300 億的本票或無表決權普通股額度，可動用到 2030 年底，觸發條件是第三方算力協議的特定條件與過去十二個月營收目標。Google 在 2026 年 5 月投入 Series H 的 100 億從額度扣除，剩 200 億；協議同時給 Google 一個在 IPO 同步私募以 IPO 價格認購最多 100 億的選擇權，Google 全數行使，這 100 億再從額度扣除，剩 100 億。

這些條款讓投資人的出資跟它自己的生意連動：Amazon 的額度在 Anthropic 完成約定的算力容量時開放，Anthropic 拿到的錢又用來向雲端業者購買算力。持股上限把兩家的經濟權限制在一定比例之下，而 Class N 沒有表決權，所以兩家都不取得投票上的控制。S-1/A-2 的風險因素寫出這種安排的代價：雲端業者同時是投資人、合作夥伴與客戶，可能產生利益衝突。同一批本票與特別股在 Amazon 自己的帳上怎麼入帳、估值變動出現在它損益表的哪一行，寫在 [AI 大廠本業以外的業務〈對算力交易對手的持股：入帳方式與損益出現的位置〉](/business/ai-infrastructure/value-chain/big-tech-adjacent-businesses/#對算力交易對手的持股入帳方式與損益出現的位置)。

## 供應商在 IPO 同步認購的條款

Google、NVIDIA、AMD、Broadcom、Micron、Microsoft 與 TSMC 分別同意以 IPO 價格認購 Class N，七家合計 260 億美元。這筆私募的條款有幾點跟一般 IPO 的新股不同：

- **金額固定，股數跟價格反向**：這些業者認購的是固定金額，IPO 價格越高，換到的股數越少；以 74 美元計是 3.51 億股。
- **Anthropic 不付承銷費**：私募的價款以現金全部進 Anthropic。
- **不受閉鎖期限制**：這批股份是未經登記的限制性證券，要依登記或豁免規定才能轉賣（例如 Rule 144，它規定未登記股份要持有一段期間、並在數量限制內才能於公開市場賣出），但不受承銷商的閉鎖期協議或股東與公司簽的閉鎖約定（market standoff agreement）約束；Google 另有權要求公司為它這批股份辦理轉售登記。
- **IPO 不以私募完成為條件**：私募預定在 IPO 完成後立即交割，交割還需要股東依章程給的同意；私募沒完成，IPO 照樣成立。
- **部分認購抵掉既有的承諾**：Google 的 100 億就是 Google 2026 NPA 給它的那個私募認購選擇權（見〈Amazon 與 Google 的持股上限與轉股安排〉）。AMD 在 2026 年 7 月的設備供應協議裡承諾，Anthropic 可以要求它以股權投入最多 50 億美元；這次私募 AMD 以現金付 25 億（包含在 260 億裡），同時算作那 50 億承諾的一部分。承諾剩下的 25 億不在 260 億裡，依 AMD GPU 交付與部署的里程碑累計開放，累計金額要先超過 AMD 在私募已付的 25 億，超過的部分 Anthropic 才能動用（第一個里程碑預計在 2027 年）。

除了 Google 與 AMD，其餘五家各認購多少，S-1/A-2 沒有分別揭露。這筆私募屬於供應商以股權投資的形態出資，錢流與風險的歸類寫在[供應商融資的形態〈依賣方的貨由誰的錢支付把供應商融資歸類〉](/business/ai-infrastructure/vendor-financing-forms/#依賣方的貨由誰的錢支付把供應商融資歸類)，供應商同時是股東、算力供應者與通路的整體安排寫在 [Anthropic 的算力融資結構〈供應商入股 Anthropic 的安排〉](/business/ai-infrastructure/anthropic-compute-financing/#供應商入股-anthropic-的安排)。

## Class A、N、T、F、E 的投票權與經濟權

Anthropic 上市後有五類普通股，經濟權（分配股利與清算時的剩餘財產）與投票權分給不同的類別：

| 股別    | 持有人                                                   | 投票權                                                             | 經濟權        |
| ------- | -------------------------------------------------------- | ------------------------------------------------------------------ | ------------- |
| Class A | 公開市場投資人、員工、財務投資人                         | 一股一票                                                           | 有            |
| Class N | Amazon、Google、同步認購的業者、部分財務投資人、公益基金 | 無（法律另有規定除外）                                             | 有，與 A 相同 |
| Class T | 長期利益信託（LTBT）                                     | 一般事項無；選任與解任董事會過半數的 Class T 董事                  | 無            |
| Class F | Founder LLC（七位共同創辦人）                            | 一般股東表決事項（包括選任 Class T 以外的董事）合計 50.1% 的表決權 | 無            |
| Class E | 共同創辦人以外的員工（章程授權，上市時尚未發行）         | 只在特定事項投票                                                   | 無            |

員工有經濟權的股份（行使認股權、RSU 交付取得的股份）是 Class A；Class E 是章程另外授權、準備發給共同創辦人以外員工的一類股份，只有限定事項的投票權、沒有經濟權，S-1/A-2 的擬制股數裡還沒有發行。所以同一位員工可以同時持有 Class A 與 Class E，兩者分管經濟權與那部分投票權。

公開市場的新投資人買到的是 Class A：IPO 後新投資人合計約 8.25 億股（IPO 新發行的股份，加上共同創辦人等賣方股東在 IPO 中賣出的股份），占 Class A 與 Class N 合計約 6.3%，是經濟權的一小部分；而董事會過半數由 LTBT 選任，其餘一般事項的過半表決權由 Class F 掌握，所以 Class A 的票在多數事項上不足以改變結果。只有在 Founder LLC 的成員無法對 Class F 的投票方式取得多數時，Class F 的票才大致依 Class A 的投票結果按比例投出。Anthropic 因此是 Nasdaq 規則下的「受控公司」（controlled company），S-1/A-2 寫明它只援用其中一項豁免：提名與公司治理委員會不全由獨立董事組成；董事會過半數獨立、審計與薪酬委員會全由獨立董事組成的要求，它仍然遵守。

Class F 的控制有落日條款（sunset），觸發條件看 Founder LLC 的成員。七位共同創辦人一開始都是成員（S-1/A-2 稱為 Continuing Founders），Founder LLC 依成員的多數決行使 Class F 的表決權。成員在下列任一情形發生時退出：自行辭去成員資格、過世或失能、持有的 Class A 降到他自己上市時持股的 2% 以下、因「cause」被除名（包括 Founder LLC 協議列明的競爭行為），或開始一段經核准的休假；IPO 後十年內，成員過世或失能時可以補入繼任成員。成員人數少於三位、持續 90 天之後，開始一段 450 天的過渡期，過渡期滿，Class F 與 Class E 由公司無償贖回，治理結構隨之調整。

新投資人每股付 74 美元，換到的有形資產淨值很少：S-1/A-2〈Dilution〉一節估計 IPO 後每股擬制有形資產淨值 8.21 美元，新投資人每股立即承受 65.79 美元的帳面稀釋。這是每股價值的稀釋（IPO 價格減每股有形資產淨值），跟〈上市之後仍會發生的稀釋〉講的持股比例下降是兩種量法（[股權稀釋](/business/knowledge-cards/dilution/)）。這個數字反映的是新股東付的價格大多是在買未來的獲利能力，帳上的淨資產只占一小部分。營收與成本能不能持續、財報數字可不可信，判讀方法寫在[上市前企業的經營風險與財報可信度](/business/financial-analysis/pre-ipo-risk-and-statement-credibility/)；把獲利能力換算成估值的方法寫在[企業估值方法〈不同階段和模式的估值方法選擇〉](/business/financial-analysis/valuation-methods/#不同階段和模式的估值方法選擇)。

## 上市之後仍會發生的稀釋

Class A 股東的持股比例在上市後還會被幾個已經寫進文件的機制攤薄，每一個機制的觸發條件不同：

- **公益基金的追加發行（下稱公益發行）**：董事會通過的框架是，股價每比上一個里程碑高 50%，董事會可以裁量再發行最多 2% 的流通股（分母含認股權、RSU 與其他可轉換證券）給 Anthropic Public Benefit Fund。第一個里程碑是 IPO 價格的 1.5 倍，下一個是那個價格的 1.5 倍，依此類推；每過一個里程碑，董事會就多一次最多 2% 的發行選項，要不要發由董事會決定。
- **員工捐贈配對計畫**：員工承諾把部分股權捐給慈善用途，公司以 Class N 配對捐出。計畫保留 9.34 億股；依員工已歸屬的股權與他們的承諾計算，公司最多可能要發行的配對股數是 5.53 億股；2027 到 2036 年每年初自動增加保留股數，增加的上限是當時有經濟權普通股的 1%。
- **投資人與供應商協議下的後續發行**：Amazon 的換發本票每季轉換、Amazon 2026 NPA 剩下的 150 億、Google 2026 NPA 剩下的 100 億、AMD 剩下的 25 億，以及 Anthropic 可以發給 Broadcom（或其融資夥伴）、只能用來支付 Broadcom 機櫃租金、最高 420 億、以 VWAP 九折（營收條件未達成時八五折）轉換的本票（條款寫在 [Anthropic 的算力融資結構](/business/ai-infrastructure/anthropic-compute-financing/)）。這些出資以發行時的市價或折價換股，股數取決於當時的股價。
- **員工股權**：既有的認股權與 RSU、新的 2026 年股權激勵計畫（保留 19.2 億股，每年自動增加）與員工認股計畫（ESPP）。

上市後每一股的持股比例每年被攤薄多少，由這幾個來源合起來決定，而各來源增加的股份在季報上出現的位置不同：員工股權反映在股份基礎給付與行使的股數，投資人與供應商的出資反映在籌資現金流與 Class N 的增加，公益發行與捐贈配對反映在 Class N 的增加與捐贈費用。

## 閉鎖期依股東群組分批解禁的安排

IPO 之前的股東幾乎全部簽了[閉鎖期](/business/knowledge-cards/lock-up-agreement/)協議（跟承銷商 Goldman Sachs 與 Morgan Stanley 簽）或與公司簽的閉鎖約定。S-1/A-2 的承銷一節把股東分成幾群，每一群的閉鎖期長度與提前解禁的比例不同；下表的比例都以各股東在上市前一個參考日的持股為基數，天數從招股說明書的日期起算，財報公布日之後的天數從那個公布日起算：

| 股東群組                                                     | 全部解禁的時點                                             | 提前解禁                                                                                                                                     |
| ------------------------------------------------------------ | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 非創辦人的董事、高階主管、現任與前任員工、顧問               | 2027 年第一季財報公布後第二個交易日，或第 180 天，取較早者 | 上市首日起可賣持股的 10%；2026 年年報公布後再加 35%                                                                                          |
| 部分其他股東（certain stockholders，S-1/A-2 沒有列出成員）   | 同上                                                       | 第 27、48 天各 6%，第 62、76 天各再 7%；2026 年年報公布後再 12.5%，年報公布後第 13、27、41、55、69 天各再 9.5%                               |
| 部分持有完全稀釋股數 0.5% 以上的股東（S-1/A-2 沒有列出成員） | 2027 年第三季財報公布後第二個交易日，或第 365 天，取較早者 | 比例較小的分批（每批約 2% 到 7%）：上市後第 27 到 76 天、2026 年年報後、2027 年第一季財報後（或第 180 天，取較早者）、第二季財報後，各有幾批 |
| 共同創辦人（不含在 IPO 中出售的股份）                        | 同上                                                       | 2027 年第一季財報公布後第二個交易日或第 180 天，取較早者，起可賣持股的 29%                                                                   |

S-1/A-2〈Shares Eligible for Future Sale〉的解禁表把這些比例加總換算成股數：上市首日最多約 3.16 億股（員工群組的 10%）；上市後第 27、48、62、76 天各約 3 億到 3.5 億股；2026 年年報公布後約 17 億股，之後在年報公布後第 13 到 69 天之間每兩週左右再約 4.7 億股；2027 年第一季財報公布後（或第 180 天）約 30 億股。S-1/A-2 的招股摘要估計，在第 180 天之前最多約 36 億股可能變成可以賣出。承銷商可以提前解除閉鎖。

分批解禁的時點就是公開市場賣壓可能增加的時點。對照 IPO 時新投資人手上的 8.25 億股，上市首日可以賣出的 3.16 億股接近它的四成；2026 年年報公布後與 2027 年第一季財報公布後那兩批，股數是新投資人持股的兩到四倍。IPO 同步私募的 Class N 不受閉鎖，但是限制性證券，賣出要走登記或 Rule 144。

## 新股東在這個結構裡拿到的權利與承擔的風險

把前面各節放在一起，IPO 時用 74 美元買進 Class A 的新股東，處境可以從這幾個面向描述：

- **經濟權**：新股東合計約占 Class A 與 Class N 的 6.3%，其餘由財務投資人、Amazon、Google、供應商、員工與公益基金持有，而公益發行、捐贈配對、投資人與供應商協議下的發行與員工股權會持續攤薄這個比例。股價每過一個上漲里程碑，董事會就多一次發行公益股份的選項；董事會發行時，新股讓所有既有股東的持股比例一起下降，股價上漲的收益因此有一部分以新股的形式轉到公益基金。
- **控制權**：董事會過半數由 LTBT 選任，一般事項的過半表決權在 Founder LLC，新股東的投票在多數事項上不改變結果。這個安排在 Founder LLC 還有三位以上成員時持續，成員的退出條件決定它什麼時候結束。
- **損益的組成**：上市後，Amazon 換發本票的公允價值仍隨股價反向進入損益，股價上漲的季度淨損會因此擴大，這一項不反映營運；Anthropic 營業層的損益寫在 [Anthropic 的算力融資結構〈九個月淨損的組成〉](/business/ai-infrastructure/anthropic-compute-financing/#九個月淨損的組成)，現金承諾的到期分布寫在同一篇的〈九千億美元承諾的口徑與到期分布〉。
- **賣壓的時點**：最早的一批在上市首日，最大的兩批在 2026 年年報與 2027 年第一季財報公布之後，股數都是新投資人持股的數倍。
- **大股東也是交易對手**：Amazon 與 Google 的出資跟 Anthropic 的算力建置與營收目標連動，兩家同時是它的算力供應者與銷售通路（S-1/A-2 揭露 2026 年前九個月 Anthropic 約 44% 的營收經由雲端業者的市集銷售）。大股東的利益跟新股東在股價上一致；在算力的採購價格與市集的分潤比例上，大股東是收錢的一方，Anthropic 付得越多，大股東的商業收入越高，而新股東的盈餘越少。上市後的關係人交易揭露與雲端合約的變動，會顯示這兩邊的條件怎麼變。

這些面向彼此有依賴：各群股東取得股份的工具與價格，決定他們的成本與賣出的誘因；各類股份的投票權與經濟權怎麼分，決定新股東能影響什麼；上市後的稀釋機制與解禁時點，決定新股東的比例與市場上的股份供給之後怎麼變。把這組拆法當成一般方法，評估另一家上市前公司的經營風險與財報可信度，寫在[上市前企業的經營風險與財報可信度](/business/financial-analysis/pre-ipo-risk-and-statement-credibility/)。
