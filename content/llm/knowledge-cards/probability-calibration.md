Probability calibration（機率校準）描述**模型給出的機率與它實際答對的頻率之間的對應程度**。一個校準良好的模型，在所有它給出 80% 信心的題目裡，大約有 80% 答對；校準不良的模型，可能在 80% 信心的題目裡只答對一半。信心值能不能拿來當決策依據，取決於這個對應關係有沒有被量過。

## 概念位置

| 概念                                                                   | 量測對象                                                                   |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 準確率（accuracy）                                                     | 整體答對的比例，不看信心                                                   |
| 機率校準（probability calibration）                                    | 信心的高低與答對頻率是否相符                                               |
| 一致性（consistency）                                                  | 同一題多次取樣是否給出同一個答案                                           |
| [LLM-as-Judge](/llm/04-applications/llm-as-judge/) 的 calibration 步驟 | judge 的評分與人的評分是否一致，屬於評分對齊，跟本卡的機率校準是不同的量測 |

量測方式是把題目依模型的信心分組（例如 0–10%、10–20%⋯⋯），每組算實際答對的比例，畫成信心對準確率的圖；完全校準時各點落在對角線上。偏離對角線的程度可以濃縮成一個數字，常見的是 expected calibration error（ECE）：各組「信心與準確率的差距」依題數加權平均。

## 設計責任

讀到「模型很有把握」「十次取樣有九次選 A」這類敘述時，判讀的重點是：

1. **一致不等於正確**：多次取樣的一致比例量的是模型對這一題的傾向有多集中，傾向本身可能建立在錯誤的前提上。模型在輸入含有錯誤前提的題目上，常常以很高的一致性選錯，這正是校準最容易失效的位置（見 [4.23 System 1 決策模型](/llm/04-applications/system-one-decision-model/)）。
2. **校準依題型而變**：同一個模型在一類題目上校準良好，不代表在另一類題目上也是。拿信心當門檻之前，要用同一類題目量過。
3. **訓練後處理會改變校準**：預訓練後的 [base model](/llm/knowledge-cards/base-model/) 與經過 [RLHF](/llm/knowledge-cards/rlhf/) 的模型，在同一組題目上的校準程度可能不同，換模型或換版本就要重新量。
4. **失敗模式**：把未經校準的信心直接當成機率使用，例如「信心高於 0.9 就自動採用」。在校準不良的題型上，這條規則放行的錯誤答案，會跟正確答案一樣有把握。
