本模組處理的是資料整批進入程式之後的工具選擇。前七個模組寫的是程式碼本身的結構，這一個模組的軸換成資料：一次進來多少、運算發生在哪一端、超過記憶體之後往哪裡走。

## 讀者定位

有程式經驗、SQL 大致能寫，但沒有做過批次資料處理的工程師。Web 後端背景的讀者會發現這一側的工具跟熟悉的那一套幾乎沒有交集，而模組的第一篇就在解釋這件事。

## 推導源頭

各篇的判斷標準都折算回 8.2 的那條軸：運算發生在資料庫端還是程式的記憶體端。8.3 是這條軸兩側的產物比對，8.4 是兩側共用的抽象，8.5 是記憶體端那一側的容量上限。8.1 在軸之前，負責說明為什麼會有這條軸要分。
