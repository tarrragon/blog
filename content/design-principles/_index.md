本模組承擔語言無關的軟體設計原則：模組的邊界怎麼畫、哪些程式碼該放在一起、違反時在程式碼與修改紀錄上留下什麼痕跡。這些原則在每種語言的寫法不同（Python 的套件與 re-export、Go 的 package、Dart 的 library），所以本模組只放定義與判斷標準，實作細節放在各語言模組。

## 與其他教材的分工

| 教材                                                   | 承擔什麼                               | 本模組的關係                                         |
| ------------------------------------------------------ | -------------------------------------- | ---------------------------------------------------- |
| [DDD](/ddd/)                                           | 領域模型的理論：entity、不變式、聚合等 | DDD 依單一職責切 domain 與 event；本模組給原則的定義 |
| [Python](/python/)                                     | Python 的語言與工程實踐                | 本模組原則的 Python 實作（拆模組、re-export、測試）  |
| [Code Smell 檢查清單](/record/code_smell/)             | 壞味道的偵測規則與修正範例             | 本模組給壞味道的定義與它違反的原則                   |
| [SOLID 寫作方法論](/record/solid-writing-methodology/) | SOLID 映射到文章體系                   | 同一組原則用在文件上的版本                           |

路由方向是單向的：本模組的定義不依賴任何語言的實作；語言模組引用本模組的卡片建立概念。
