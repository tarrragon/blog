## 這份紀錄是什麼

`multi-round-review` 與 `compositional-writing` 兩個 skill 各跑一次低階 model 讀者探針，初測與複驗各六批、每批三份，共三十六份。本檔記派發前登記的門檻、逐項的歸因與處置、以及複驗的翻轉結果。**寫在對話裡的表在 repo 裡不存在**，所以這一份留在這裡。

## 派發前登記（寫於派發之前）

finding 分兩類，門檻不同——兩類的既有規則本來就不同，混用會讓其中一類被另一類的門檻放行：

| 類別     | 判定                                           | 門檻                                                |
| -------- | ---------------------------------------------- | --------------------------------------------------- |
| 理解錯誤 | 讀者說出的內容與文件不符，或指涉被讀到錯的對象 | 歸因為文件造成的，**一份即處置**                    |
| 閱讀負擔 | 讀者最終理解正確，但回報累、回頭重讀、想跳過   | 同一位置 **2/3 以上即處置**，不看讀者最終有沒有理解 |

切換條件：同一位置用同一種手段改過兩次而命中未動，第三次改為外移。本批只有兩輪，這條不會觸發，仍然寫下以免事後補訂。比對對象取兩輪聯集，不取單輪高峰。

**已知污染（派發前宣告）**：subagent 繼承本專案的 `AGENTS.md` 與 `CLAUDE.md`，而探針方法論的核心詞在那兩份裡的詞頻非零（探針 14、frame 10、歸因 11、命中 15；外移 0、疲勞 0、集合探針 0）。影響方向單向——探針可能用繼承的知識補平文件的缺口，所以**回報有 finding 可信，回報無 finding 的證據力被削弱**，不得據此宣稱該維度乾淨。「換一個不帶規範檔的配置重測」在目前的派發介面上沒有跑通過的做法，所以這是限制、不是待辦。

**`per` 連結那一項是這批最有用的一則。** 初測 3/3 說連結沒交代去了會拿到什麼，我補了被點名的三條；複驗仍然 3/3，而三份指的都是**沒被點名的那幾條**。這是「finding 清單列的是抽樣位置」的現場實例——修完之後要用該類的特徵掃全檔，不是照清單逐條劃掉。第二批處置改成全檔盤點：八條 principle 連結、八條目的地承諾。

## 第二批處置

- mrr `per` / `詳見` / `見` 連結：全檔八條逐一補上「那裡給什麼」
- mrr frame 表：表前加三組分類（無條件跑 / 看批次規模 / 看內容性質），並寫明這張表是逐列查的、不是線性讀完的
- mrr 探針派發契約：補 N 取三到五與它的下界理由，並把「低階」的判準寫成兩個性質（推理能力較弱、單位成本低到可以一次派好幾份）而不是某個型號

## 達門檻而本輪未處置的，與理由

**〈基本原則〉段剩下的 1/3。** 那一份的理由指向本輪新加的 per 連結承諾——「反覆出現 per [連結] 那裡… 的引用形式」。這是同一個 session 內第三次觀察到修法把命中推到新增內容上。1/3 低於派發前寫死的門檻（閱讀負擔 2/3），**記錄不處置**。把它寫下來是為了讓下一輪拿得到這個序列，而不是讓它在下一輪被重新發現。

**compositional-writing 的核心原則段：初測 3/3、複驗 3/3。** 連續兩輪達門檻，依登記的門檻要處置，而本輪只做了一項壓縮（交界段），整段仍然偏長。它的處置不是再壓縮一次——依換手段的條件，同一手段改過兩次而命中未動就要換手段，而這一段的下一個手段是**按單一責任把 SKILL.md 拆開**（`skill-design-guide` 的〈超標了怎麼辦〉給了四格診斷與拆分判準）。那是一件獨立的工作，不在本批之內。

把它寫在這裡而不是留在對話裡，是為了讓下一輪拿得到「初測 3/3、複驗 3/3、已用過一次壓縮」這個序列——沒有這個序列，下一個人會從壓縮重新開始。

## 收尾時翻掉的一項分類判定

`structuring-with-solid.md` 第 69 行的 O 原則邊界，一份冷讀在初測與複驗都列為歧義，而我當時歸成閱讀負擔類、套了 2/3 的門檻，以「1/3 未達門檻」略過。

收尾時回原文歸因才發現分類錯了：原文寫「O 管結構骨架、內容不在管轄範圍」只涵蓋 O，而同檔〈類比的邊界〉寫的是整個清單——**兩處的轄域不同，而讀第一處的人拿不到第二處**。探針的那個「多餘讀法」其實是對的。它屬於「找得到逐字對應的句子」那一類，依登記的門檻是一份即處置。

**教訓不在門檻的數值上，在分類的那一步。** 派發前寫死兩類門檻的時候，要一併寫下**兩類的判別依據**，否則 finding 會落進錯的門檻而被合法地放掉——而放掉的理由看起來完全合規（「1/3，未達 2/3」）。

## 這次量測自己的限制

單一批次、每批三份、兩輪。數值門檻取自這一次的分佈，換對象要重新校準。複驗只跑一輪，所以「連續兩輪」在本批的操作形式是初測與複驗，這與跑五輪之後回頭看累計不是同一種證據。
