本分類收錄綁定特定程式語言或框架的教學系列：Python（入門 `python/basic/` 與進階 `python/advanced/`）、Go（入門 `go/basic/` 與進階 `go/advanced/`）、PHP 的伺服器執行模型（`php/`），以及 Flutter 與 Dart（`flutter/`）。2026-11-03 這些系列從首頁的頂層分類搬進本分類，同一個語言的入門與進階合進同一個語言資料夾；舊網址由各頁 frontmatter 的 `aliases` 導向新位置。

## 子分類與排序

列表頁依 weight 排出子分類，weight 沿用搬移之前首頁列出這些系列的順序：

| weight | 子分類                           | 收錄                                                                                            | 排在這個位置的理由                                   |
| ------ | -------------------------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1      | [Python](/programming/python/)   | 入門：以 Hook 系統為範例的語言基礎與重構；進階：asyncio、元編程、CPython 內部機制、C/Rust 擴展  | 沿用首頁順序                                         |
| 2      | [Go](/programming/go/)           | 入門：語言精神、型別、標準函式庫、錯誤處理與測試；進階：並發模式、WebSocket、runtime 與服務架構 | 沿用首頁順序                                         |
| 3      | [PHP](/programming/php/)         | PHP 在伺服器上的執行模型：CGI、mod_php、FastCGI、PHP-FPM、OPcache、常駐 worker                  | 範圍只有伺服器上的執行模型，比 Python 與 Go 的系列窄 |
| 4      | [Flutter](/programming/flutter/) | Dart 型別設計、狀態與渲染、測試策略與工具鏈                                                     | 框架層教材，章節從 work-log 的 case 聚類             |

語言子分類之內，入門（`basic/`，weight 1）排在進階（`advanced/`，weight 2）之前：進階系列的目標讀者是讀完入門系列的人。

## 分類的範圍與相鄰分類

- 語言無關的設計原則與 DDD 放 [軟體設計](/software-design/)；各語言系列引用那裡的定義，那裡不依賴任何語言的實作。
- 跨語言的後端能力（資料庫、快取、佇列、觀測、部署）放 [Backend](/backend/)；語言系列寫實作，連回 Backend 的能力與選型。
