勾芡濃湯是**湯用澱粉勾芡到濃稠**的那一類。稠度來自澱粉的糊化，不來自熬煮收汁，機制見 [勾芡](../../techniques/starch-thickening/)。

台灣叫「羹」的幾乎全部落在這裡，而這也是台灣的「羹」跟中國用法分岔的地方——那邊質地夠濃稠就算，稠度來自什麼都行；台灣要求稠度是勾芡來的。詳見 [羹](../../naming/geng/)。

## 這個形態底下有哪些菜

| 菜     | 主料               | 單篇                           |
| ------ | ------------------ | ------------------------------ |
| 肉羹   | 豬肉與魚漿混成的塊 | [肉羹](../../dishes/rou-geng/) |
| 魷魚羹 | 發泡過的魷魚       | 未寫                           |
| 花枝羹 | 花枝               | 未寫                           |
| 蝦仁羹 | 蝦仁               | 未寫                           |
| 羊肉羹 | 羊肉               | 未寫                           |
| 豆簽羹 | 豆簽（豆製麵條）   | 未寫                           |
| 大麵羹 | 油麵               | 未寫                           |

換的是主料，湯與勾芡那一層各家有自己的配方而作法同一套。豆簽羹與大麵羹的主料連肉都不是，這說明「羹」指的是湯的形態而不是裡面放什麼。

## 主料自己也可能是黏合出來的

[肉羹](../../dishes/rou-geng/) 的塊是瘦肉、肥肉與魚漿打成泥再捏成的，魚漿在裡面當黏合劑，並不是從整塊肉上切下來。所以那一碗有兩層稠化：塊靠魚漿成形，湯靠澱粉勾芡。

這個結構跟 [sformato（義式蒸蔬菜泥）](../../dishes/sformato/) 是同一種——那一道的主體是蔬菜，蛋只負責把泥黏成一塊。兩道菜相隔很遠而解的是同一個問題：**把散的材料變成有形狀的塊，而黏合劑不能搶走主料的味道。**

## 跟蛋液凝凍的分界

[egg custard（蛋液凝凍）](../egg-custard/) 那一類也是把液體變稠，而稠化的機制與成品的狀態都不同：蛋液凝凍靠蛋白質受熱連結成網，成品是半固體、舀得起來、離開容器仍有形狀；勾芡濃湯靠澱粉抓水，成品仍然是液體，只是流得慢。

中國說的「雞蛋羹」落在蛋液凝凍那一邊而不在這裡，這正是台灣讀者對不上那個名字的原因。
