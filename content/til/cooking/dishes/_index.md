這個子分類收錄**一道菜一篇**，是這個分類實際的內容所在。名字、形態、手法三個索引都指到這裡，完整的作法與判讀只寫在這裡一次。

## 全部並排

這張表把幾個軸放在一起，用來看哪兩道確實相近、哪兩道只是名字看起來像。

| 菜                                              | 形態     | 手法                 | 調味                   | 在一餐裡的角色       |
| ----------------------------------------------- | -------- | -------------------- | ---------------------- | -------------------- |
| [crème caramel（焦糖布丁）](creme-caramel/)     | 脫模凝凍 | 水浴烘烤             | 甜                     | 甜點                 |
| [crème brûlée（烤布蕾）](creme-brulee/)         | 留皿凝凍 | 水浴烘烤 + 表面燒糖  | 甜                     | 甜點                 |
| [flan pâtissier（派皮布丁塔）](flan-patissier/) | 派皮塔   | 直接烘烤             | 甜                     | 甜點，單片販售       |
| [英式 flan（開放式塔）](english-flan/)          | 派皮塔   | 直接烘烤             | 甜或鹹                 | 隨餡而定             |
| [pastel de nata（葡式蛋塔）](pastel-de-nata/)   | 派皮塔   | 直接烘烤（高溫快烤） | 甜                     | 單顆的點心           |
| [quiche（法式鹹派）](quiche/)                   | 派皮塔   | 直接烘烤             | 鹹                     | 正餐或前菜，冷熱皆可 |
| [港式蛋撻](hk-egg-tart/)                        | 派皮塔   | 直接烘烤             | 甜                     | 單顆的點心           |
| [sformato（義式蒸蔬菜泥）](sformato/)           | 蒸蔬菜泥 | 水浴烘烤             | 鹹                     | 主菜旁的配菜         |
| [茶碗蒸](chawanmushi/)                          | 留皿凝凍 | 蒸氣                 | 鹹（高湯、醬油、味醂） | 會席裡獨立的一道     |
| [中式蒸蛋（雞蛋羹）](chinese-steamed-egg/)      | 留皿凝凍 | 蒸氣                 | 鹹（生抽、香油）       | 配飯的家常菜         |

茶碗蒸與中式蒸蛋的形態與手法都一樣，而材料、調味與在一餐裡的角色全部不同——這一組說明了為什麼「手法相同」推不出「是同一道菜」。同一件事在派皮塔那幾列上更明顯：五道菜共用一個形態與一種手法，而甜鹹、餡的來歷與吃法各自不同。
