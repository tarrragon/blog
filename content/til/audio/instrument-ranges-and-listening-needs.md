這篇寫聽的內容與喇叭規格之間的對應，分成聲音的頻率組成，以及聆聽用途對喇叭的要求：

- **聲音的頻率組成**：一個音由基音、泛音與起音的雜訊組成，各自落在哪個頻段；人聲、弦樂器、管樂器、鍵盤、打擊樂器與管風琴的基音範圍；合成器與電影音效的低頻；喇叭重現不出基音時，音高靠泛音還聽得出來的條件；以及高頻端為什麼很少成為挑喇叭時的分界。
- **聆聽用途對喇叭的要求**：以影片與人聲為主、原聲音樂（古典、爵士、民謠）、流行與搖滾、電子音樂與嘻哈、電影、遊戲、背景與小音量聆聽，各自要求的低頻延伸、頻率響應的平直、擴散角度與最大音壓，以及對應的喇叭配置。

頻率、八度與各頻段聽感的對照表在〔[家用音響的基礎概念](/til/audio/audio-fundamentals/)〕的〈頻率、八度與波長〉；喇叭的頻寬、[擴散角度](/til/audio/knowledge-cards/directivity/)與最大音壓這幾項規格的定義與量法，以及多媒體、書架、2.1 聲道、落地喇叭這些配置的適用條件，在〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕。文中的頻率是大約的範圍，寫到能拿去對照喇叭規格表上頻寬的程度；聽感上要分辨的是聲音落在低頻、中頻還是高頻，以及喇叭是否放得出那一段，用不到更精確的數字。

## 一個音的頻率組成：基音、泛音與起音

樂器或人聲發出的一個音，由幾種頻率成分疊加而成，各自決定聽感的一部分：

- **基音**（fundamental）：這個音的音高本身的頻率。低音提琴最低的幾個音，基音在 40 Hz 上下；鋼琴中央 C 的基音在 260 Hz 上下。
- **泛音**（overtone）：基音以上的頻率成分。弦樂器、管樂器與人聲的泛音多半落在基音的整數倍上（二倍、三倍、四倍……，這種泛音也叫**諧波**，harmonics），從基音往上一路延伸到幾 kHz。同一個音高的小提琴與長笛聽得出差別，原因是兩者各個泛音的相對音量不同；所以樂器的**音色**（timbre）主要由泛音決定。
- **起音的雜訊**（attack transient）：琴弓接觸琴弦、鼓棒打上鼓皮、吹奏的氣流衝進吹嘴那一瞬間的非週期成分，多落在 2 kHz 以上的中高頻，決定的是起音的清晰度，也就是聽者分辨「這一下是撥弦還是拉弦」的依據。

所以一件樂器在喇叭上要聽起來對，牽涉的頻段比它的基音範圍寬得多：基音決定音高與厚度，泛音決定音色，起音決定清晰度。各頻段偏多或偏少時的聽感，在〔[家用音響的基礎概念](/til/audio/audio-fundamentals/)〕的頻段對照表。

## 人聲與各類樂器的基音範圍

下表是常見人聲與樂器的最低音大約落在哪裡，以及它們的聽感特徵主要在哪個頻段。最低音決定了這件樂器對喇叭低頻延伸的要求；最高的音多半在幾 kHz 以內，遠低於喇叭的高頻上限。

| 聲音             | 最低音的基音大約落在                          | 聽感特徵所在的頻段                                         |
| ---------------- | --------------------------------------------- | ---------------------------------------------------------- |
| 說話             | 100–250 Hz（男聲低、女聲高）                  | 母音的辨識在中頻，子音的清晰度在中高頻                     |
| 歌聲             | 男低音在 80 Hz 上下                           | 歌手的共鳴與齒音在中高頻                                   |
| 小提琴           | 200 Hz 上下                                   | 泛音延伸到高頻，琴弓的起音在中高頻                         |
| 大提琴           | 60 Hz 上下                                    | 基音與低次泛音在低頻到中低頻，決定琴身的厚度               |
| 低音提琴、電貝斯 | 40 Hz 上下，五弦貝斯更低                      | 低次泛音在 80–250 Hz，決定低音線的音高是否清楚             |
| 吉他             | 80 Hz 上下                                    | 撥弦的起音在中高頻                                         |
| 鋼琴             | 30 Hz 上下                                    | 最低幾個音的基音很弱，聽到的音高主要來自泛音               |
| 低音管、低音號   | 40–60 Hz                                      | 吹奏的起音與低次泛音在中低頻                               |
| 定音鼓、大鼓     | 定音鼓 70 Hz 上下；大鼓的能量集中在 50–100 Hz | 鼓棒的敲擊聲在中高頻                                       |
| 鈸與鈴鼓         | 沒有明確的基音                                | 能量在中高頻到高頻                                         |
| 管風琴           | 最長的音管低到 20 Hz 以下                     | 最低的幾個音是聽者用身體感覺到的壓力，多半沒有可辨識的音高 |

表上多數樂器的最低音在 50 Hz 以上：人聲、小提琴、大提琴、吉他，以及鋼琴最左邊一個八度以外的音域都是。基音掉到 50 Hz 以下的只有幾類：低音提琴與電貝斯的最低幾個音、鋼琴最左邊的一個八度、低音號、大型打擊樂器，以及管風琴。

## 少了基音時的音高：缺失基音與它的條件

喇叭的低頻延伸不到某件樂器的基音時，那個音的音高通常還聽得出來。原因是泛音落在基音的整數倍上，彼此的間距等於基音，聽覺系統從這個間距推出基音：喇叭只放出一個低音的二倍、三倍、四倍泛音時，聽者聽到的仍然是那個低音的音高，即使基音本身沒有發出來。這個現象叫**缺失基音**（missing fundamental），其他中文資料也寫作缺失基頻。小型喇叭、手機與筆電喇叭還放得出貝斯的旋律，靠的就是這個機制。

聽覺系統從泛音推回的只有音高。基音本身的能量（貝斯與大鼓推動空氣的那股厚度）推不回來，沒有泛音可以推算的聲音也推不回來，所以這個機制成立的範圍取決於聲音帶著多少泛音：

- **有豐富泛音的聲音**（撥弦與拉弦的低音、鋼琴的低音、人聲）：喇叭延伸到 50 Hz 上下時，掉的只是最低幾個音的基音，音高與旋律靠泛音保留，聽感上少一點厚度。
- **接近純音、泛音很少的聲音**（合成器的正弦波低音、管風琴最低的幾個音管、電影的低頻音效）：沒有泛音可以推算，喇叭延伸不到時，這個聲音整個消失，聽者連它存在都聽不出來。

這就是〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕〈各種配置的適用條件〉裡「只聽人聲與原聲樂器時，延伸到 50 Hz 上下通常足夠；常聽管風琴、電子音樂或看電影時，要到 40 Hz 以下」的來源：前一類的低音有泛音，後一類的低音大部分是基音本身。

## 合成器與電影音效的低頻

合成器與電影音效的頻率不受樂器的物理尺寸限制，可以做得比任何原聲樂器都低，而且常常刻意做成泛音很少的形態：

- **電子音樂與嘻哈**的低音常用正弦波或接近正弦波的合成音，例如以 Roland TR-808 鼓機的大鼓聲為原型、拉長成有音高的低音（常叫 808 bass），基音多落在 30–60 Hz，在整首歌裡持續出現。喇叭放得出這一段時，聽者聽到的是一層持續的低頻壓力；放不出來時，聽到的只剩大鼓的敲擊聲與中頻的旋律，聽起來空。
- **電影**的多聲道音軌有一個只放低頻效果的**LFE 聲道**（low-frequency effects），爆炸、引擎、雷聲這類音效的能量常延伸到 30 Hz 以下。一般的對白、配樂與環境音放在其他聲道，LFE 聲道裡的內容幾乎全部是基音本身，缺失基音的機制補不回來。
- **流行與搖滾**的低音介於兩者之間：電貝斯與大鼓是有泛音的原聲或接近原聲的聲音，基音集中在 40–100 Hz；部分曲目另外疊了合成器的低音。

## 高頻端：喇叭之間的差別在平順度與擴散

高頻端很少成為挑喇叭時的分界。表上樂器的基音最高只到幾 kHz，泛音與鈸的能量延伸到 15 kHz 以上；而多數書架喇叭的高頻上限已經標到 20 kHz 以上，人耳的高頻上限又隨年齡下降（〔[家用音響的基礎概念](/til/audio/audio-fundamentals/)〕的〈頻率、八度與波長〉）。所以兩對喇叭在高頻的差別多半出現在 2–5 kHz 的平順度與高頻的擴散角度，延伸到哪裡的差別小：

- **2–5 kHz 的平順度**：這一段是人耳最敏感的頻段，也是子音、起音與歌手共鳴峰所在的頻段。這裡偏高時，人聲與小提琴聽起來刺耳、聽久了疲勞；偏低時，人聲退後、細節變少。
- **高頻的擴散角度**：高音單體與中低音單體交接的頻段擴散角度是否連續，決定了反射聲的音色是否跟直達聲一致（〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕的〈單體尺寸、指向性與音路的分工〉）。

## 各種聆聽用途對喇叭的要求

不同的用途聽的是表上不同的頻段，所以對喇叭各項規格的要求不同。下面每一種用途各自寫出它依賴的頻段、喇叭的哪一項規格決定聽感，以及對應的配置。各項規格的定義在〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕的〈挑喇叭時看的量測規格〉。

**影片、Podcast 與以人聲為主的內容**：聽者要的是聽清楚每一個字。說話的基音在 100 Hz 以上，字的辨識靠中頻的母音與中高頻的子音，所以這種用途幾乎不依賴最低的那一段低頻。決定聽感的是中頻到中高頻的[頻率響應](/til/audio/knowledge-cards/frequency-response/)是否平直：中低頻偏多時人聲發悶、跟背景音樂混在一起，中高頻偏少時子音模糊。低頻量感過多的喇叭反而讓對白被背景音樂蓋過。一對單體小、量測平直的桌上型喇叭，或內建中置聲道的 soundbar，就滿足這種用途。

**原聲音樂（古典、爵士、民謠）**：聽者要的是樂器的音色與樂團各聲部的平衡。音色由泛音決定，泛音從低頻一路分布到高頻，所以頻率響應在整個中段平直、離軸頻率響應平順，比低頻延伸更影響聽感。低頻延伸到 50 Hz 上下時，低音提琴與大提琴的旋律靠泛音完整保留；要聽到管風琴最低的音管、或大型管弦樂的大鼓與定音鼓那股壓力，才需要 40 Hz 以下。管弦樂的**動態範圍**（dynamic range：最小聲與最大聲之間的音量差）大，全團齊奏的段落比平均音量大聲得多，所以房間大、聆聽距離遠時，最大音壓不夠的喇叭在全團齊奏的段落失真，或被限制器壓低音量。

**流行與搖滾**：大鼓與電貝斯的能量集中在 40–100 Hz，而且整首歌持續出現。決定聽感的是這一段的量感，以及在平常聽的音量下這一段是否被壓住。多媒體喇叭的 DSP 在小音量時把這一段拉高、音量開大時用限制器壓回來（〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕的〈衝程與低頻音量〉），所以這種用途對喇叭的要求，主要是單體的振膜面積與衝程足以在平常的音量下推動這一段，書架喇叭多半滿足；要大音量時，看最大音壓。

**電子音樂與嘻哈**：合成器的低音落在 30–60 Hz、泛音少，缺失基音補不回來，所以喇叭的低頻延伸直接決定這一段是否重現得出來。多數書架喇叭延伸到 50–70 Hz，放不出這一段的下半部；落地喇叭到 35–45 Hz，書架喇叭加超低音喇叭（2.1 聲道）可以到 30 Hz 以下。這種用途是書架喇叭之後加超低音喇叭換到最明顯變化的情形。

**電影**：對白、配樂、音效與 LFE 聲道同時存在，要求是上面幾種用途的合集：對白的中頻要平直清楚，LFE 聲道要延伸到 30 Hz 上下，爆炸這類瞬間的大音量要求最大音壓。另外兩項是電影特有的：聲音的方向（中置聲道把對白固定在螢幕上、環繞聲道給包圍感），以及聲音與畫面的同步。soundbar、立體聲喇叭與多聲道三種做法的比較在〔[家用音響系統的組成](/til/audio/home-audio-system-guide/)〕的〈以電視與電影為主：soundbar、立體聲喇叭與多聲道〉，影音延遲的設定在〔[數位訊源的構造與選擇](/til/audio/digital-streaming-source-guide/)〕的〈有線介面：USB、光纖、同軸與 HDMI ARC〉。

**遊戲**：除了配樂與音效的頻段（跟電影相近），遊戲的玩家要靠聲音判斷腳步、槍聲從哪個方向來，而且聲音要跟操作同步。方向感來自兩支喇叭左右分開、聆聽位置在兩支喇叭的中線上，所以桌上近場聆聽時，喇叭左右拉開、高音單體對準耳朵高度，定位最清楚；兩支喇叭擠在螢幕下方或只有一個箱體時，左右的分離有限。同步取決於訊號的路徑：藍牙的編碼與無線傳輸會加上延遲（〔[數位訊源的構造與選擇](/til/audio/digital-streaming-source-guide/)〕的〈藍牙的音訊編碼格式〉），USB 或類比的有線連接延遲較小。需要分辨前後與上下方向時，耳機配合遊戲的虛擬環繞比一對喇叭精準，因為兩支喇叭的聲音只能從玩家前方發出。

**背景與小音量聆聽**：喇叭開在小音量、聽者在房間裡走動或做別的事。小音量時人耳對低頻的敏感度下降（〔[家用音響系統的組成](/til/audio/home-audio-system-guide/)〕的〈聆聽音量與人耳對低音的敏感度：等響曲線〉），所以低頻延伸再深的喇叭，小音量時聽到的低音仍然偏少，補償要靠 loudness 開關、tone control 或依音量調整低頻的 DSP。聽者不坐在固定的聆聽位置時，聽到的大部分是牆面的反射聲，反射聲的音色由離軸頻率響應決定，所以離軸頻率響應平順、擴散角度較寬的喇叭，在房間各處聽起來比較一致。

把這幾種用途依賴的頻段並排，從人聲到電子音樂與電影，依賴的最低頻段越來越低：人聲用途依賴中頻的平直，原聲音樂依賴整個中段的平直與離軸的平順，流行與搖滾依賴 40–100 Hz 在平常音量下的量感，電子音樂與電影依賴 30–50 Hz 的延伸與大音量下的最大音壓。一個人通常同時有好幾種用途，一對喇叭滿足全部用途的條件，是它的頻寬與最大音壓達到其中依賴頻段最低、音量最大的那一種用途的要求，因為那一種的要求涵蓋了其他用途依賴的頻段與音量。規格表上的頻寬怎麼讀（−3 dB 或 −6 dB 點、無響室與房間的差別）、在家裡怎麼用測試音確認實際的延伸，在〔[喇叭的規格與構造](/til/audio/speaker-specs-and-construction/)〕的〈挑喇叭時看的量測規格〉與〈各種配置的適用條件〉。
