# system-design 版本紀錄

新到舊。版號的兩個住址是本檔與 `SKILL.md` frontmatter 的 `metadata.version`。

**Version**: 0.2.0 — 加入行動 App 的上線（商店審核前置時間、提前內建遠端啟用、多版本相容與強制更新、熱更新的範圍與政策限制、依速度排列的回退手段）、從後台切換功能開關（角色、操作紀錄、生效範圍）、上線監控（依版本與開關分組比較、各層指標）；需求盤點、決策時機（App 的 API 屬定案、版本回報與當機回報屬先做）與觸發指標表（行動 App 一組）同步

**Version**: 0.1.0 — 首版：需求盤點、容量估算、決策時機分類（定案／先做／延後）、延後設計的觸發指標目錄（後端、前端、基礎設施）、上線設計（功能開關、A/B 測試、先擴充才能上線或切換的變更）。素材來自一次短網址服務的系統設計討論：比對外部系統設計筆記後補上的議題，以及其中被判為過度設計而改成延後的項目（Bloom filter、非同步寫入）。
