# 關鍵詞清單只裝得下違規義項佔多數的詞：其餘的錯配要用探針抓

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層 keyword bank 的用詞錯配段引用。
>
> **何時讀**：某條用詞規則已經有 grep 清單、而漏抓的實例持續從外部指正進來時；或想把一個新詞加進既有 grep 清單之前。

## 核心原則

一個詞能不能進關鍵詞清單，取決於**它的違規義項佔它全部用法的比例**；而那個比例跟違規嚴不嚴重完全無關。清單是判準的一次抽樣，不是判準本身——抽到的是那些「幾乎只在違規時才出現」的詞，漏掉的是那些「違規義項只佔少數」的詞，而後者的違規可以同樣嚴重。

這條判準讓「漏抓就擴充清單」這個直覺失效。兩類詞加進去不會有用：

- **本義合法的直譯**：那個詞在本語言有自己的本義，違規的只有從外語搭配借來的義項。實例（中文）：「滑坡」的本義是山崩，而「下滑」「滑落」「滑向某個狀態」都是正常用法；違規的只有 slippery slope 借來的那個義項——把一個失敗當成可以滑進去的地方、把它當成可數的路徑。一次全站掃描得到二十幾處，違規三處。
- **詞頻過高的泛用動詞**：實例（中文）：「拿」在技術寫作裡到處都是（拿到的需求、拿去用、拿它對照自己的處境），全部合規；違規的只有拿一個物理取得動詞去承接認知關係那一種（「拿到的是理解」——讀書得到的是理解，不是可以拿走的物件，該說學到 / 讀出來 / 得到的教訓）。

清單加進這兩類之後，噪音會蓋掉訊號，而下一步一定是有人把它們拿掉——那時被拿掉的不只是噪音，還有那條規則對這兩類的涵蓋。

## 反模式

**把清單的涵蓋當成規則的涵蓋。** 「這一類唯一有穩定關鍵詞可掃」這種標註在被讀的時候會變成「掃完清單就掃完這一類」。一次實測是掃完清單、修完六十幾處、全站驗證乾淨之後，同一批內容裡仍有兩類完整的違規在。零命中是「清單沒抓到」，不是「沒有違規」。

**用清單的命中數判斷這一類清乾淨了。** 那個數字量的是清單的產能，不是這一類違規的總量。

**依賴外部指正當唯一的補漏機制。** 語言的容錯讓作者自己讀不出來——不精準的謂語通順、意思也到得了。外部眼睛有效，但它不是可以排程的東西，把它當唯一機制等於把偵測交給運氣。

## 修法

1. **判準與清單分開寫，並標明清單是抽樣。** 規則正文寫可執行的判準（例如「問這個動詞照字面成立需要什麼物理條件」），清單另起一段標成「目前抽到的高密度詞」。兩者混在一起時，讀規則的人會停在清單。
2. **新詞進清單前先算違規比例。** 全站掃一次那個詞，數違規佔多少。比例低就不進清單，改寫進判準的說明或做成探針。
3. **補語型態探針**（抓泛用動詞頂替具體關係）：精準的認知動詞（學到 / 看出 / 意識到）容得下子句，物理取得動詞（拿到 / 抓到）只容得下名詞組。因此「⋯⋯的是」後面接一個完整斷言時，前面那個動詞多半選錯了。實測那句「拿到的是自己的哪些反應正在製造沉默」同時犯用詞與語法兩項，而語法那一項是看得見的——**不精準的謂語會在需要接子句時撞牆，撞牆點就是探針**。
4. **本義探針**（抓外語隱喻直譯）：那個詞在本語言有沒有自己的本義？本義是什麼詞性、什麼類別？再問句子把它當成什麼在用。滑坡的本義是一個地質事件，而「另一條滑坡」把它當成可數的路徑——本義是事件、用法是路徑，不相容。詞典查得到不等於用法成立，這個探針攔的正是那個落差。
5. **換詞時同義詞要分散。** 一個泛用動詞換掉之後，替代詞按語境各自選（拿到 → 學到 / 讀出來 / 掌握 / 得到的教訓），不要一律換成同一個——一律替換會用新模具換掉舊模具。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                             |
| ---------------------------------------------------- | -------------------------------------------------------------------- |
| 某條用詞規則的漏抓實例持續從外部指正進來             | 不要先擴充清單；先算那些詞的違規比例，低的改做探針                   |
| 一個詞有本義、而句子用的是外語搭配裡的義項           | 本義探針命中；問本義的詞性與類別跟句子的用法合不合                   |
| 「⋯⋯的是」後面接的是完整斷言而不是名詞組             | 前面那個動詞多半選錯；換成容得下子句的認知動詞                       |
| 掃完清單、全站零命中，而規則涵蓋的範圍描述得比清單廣 | 零命中只證明清單沒抓到；規則正文與清單要分開寫，並標明清單是抽樣     |
| 想把一個高頻常用詞加進 grep 清單                     | 先掃一次數違規佔比；佔比低就會用噪音蓋掉訊號，下一個維護者會把它拿掉 |
| 換掉一個泛用動詞時所有位置都換成同一個替代詞         | 那是用新模具換舊模具；替代詞按語境各自選                             |

## 跟其他原則的關係

- [word-choice-fits-concept-attributes](word-choice-fits-concept-attributes.md)：直接的上游，本卡只動它的偵測層。用詞錯配的**判準**沒有問題（「滑進去的失敗」「拿到的是理解」照它的判準都成立），被推翻的是操作化時加上的「這一類唯一有穩定關鍵詞可掃」。
- [avoid-overused-generic-words](avoid-overused-generic-words.md)：軸不同的姊妹——那張的訊號是密度（同一個泛用**名詞**反覆出現），本卡管泛用**動詞單次出現就不精準**。也解釋了為什麼「拿」這種高頻詞不該加進那張卡的 grep 清單。
- [regional-idioms-evade-keyword-bank](regional-idioms-evade-keyword-bank.md)：同一個結構在地區用語軸上的實例——grep 抓不到、同源讀得懂會放行。本卡給出那一類抓不到的入選判準（違規義項佔該詞用法的比例太低），並把「只能靠在地讀者」補上兩個可排程的探針。
- 字句層另有一條對稱的規則：keyword bank 命中是候選不是判決（偽陽性要再判定）。本卡處理的是偽陰性（沒命中不表示沒有）。兩者合起來說明關鍵詞只適合當入口的一部分，兩端都要有別的東西接。
- 作者讀不出自己語域的那條原則（register 違規要靠文體異源的眼睛）跟本卡同型，共同機制是語言容得下、通順度不下降；差別在那條靠異源的眼睛，本卡要把那雙眼睛的一部分換成可排程的探針。
- [cadence-homogenization](cadence-homogenization.md)：換詞時同義詞要分散那一條的理由住在那裡。
