# 理解檢查看多個低階 model 的分歧，不看單一高階 model 的判斷

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被 Round 2 的低階 model 讀者探針 frame 引用。
>
> **何時讀**：機械檢查與多輪 reviewer 都跑完，仍不確定讀者會不會誤解文章的脈絡與表達時。

## 核心原則

驗證文章會不會被誤解，判準要放在**多份獨立理解之間的分歧**上，不放在任何一個 reviewer 的判斷上。

三種檢查方式的分工：

| 方式                    | 判準來源         | 抓得到                         | 結構性抓不到                     |
| ----------------------- | ---------------- | ------------------------------ | -------------------------------- |
| grep 與 regex           | 形態匹配         | 已知形態、大量掃描、零成本重跑 | 語意——同一串字在不同脈絡合規與否 |
| 單一高階 model reviewer | 該模型的判斷     | 結構、事實、承重論點的反證     | 自己的理解力會把作者留下的坑填平 |
| 多個低階 model 讀者     | 份與份之間的分歧 | 歧義位置、指涉斷裂、施事者缺失 | 深層事實錯誤、跨檔一致性         |

第三列的判準不在任何模型身上。五個讀者對同一個指涉詞給出三種答案時，不需要任何一個讀者察覺「這裡有歧義」——分歧本身就是證據。這繞過了同源審查的結構上限：不依賴 reviewer 有沒有能力發現自己被卡住。

**低階模型在這個用途上是優點不是妥協。** 推理能力越強，越容易在讀到殘缺的句子時自動補完，坑因此被填平而不會現形；成本與速度也決定了能不能大量同步派發，而這個方法的判準需要多份才成立。

## 設計條件

五個條件缺一不可，少任何一個這個 frame 都會退化。

- **指令逐字相同**：差異才只來自模型的理解。指令有差別時，分歧無法歸因。
- **不給審查框架**：問「你讀到什麼」而不是「這寫得好不好」。給了審查框架，低階模型會退化成品質較差的 reviewer，優勢全部消失。
- **明令標記不確定、禁止推測填平**：模型被訓練出來的「有幫助」傾向會把空缺補起來。要它們寫「文章沒說」而不是猜一個答案。
- **問理解不問評價**：每段在講什麼、每個動作是誰做的、指涉詞各指什麼、讀完之後會做什麼。
- **判準是分布不是結論**：任何單一份報告都不作為判決，要看幾份落在同一處。

## 探針的提問模板

對每個段落問四題，全篇問三題。

段落層：這一段在講什麼（一句話）／這一段的動作各是誰做的（沒說就寫「文章沒說」）／指涉詞各指什麼（不確定就寫「不確定，我猜是 X」）／讀完之後會做什麼（沒有就寫「沒有動作」）。

全篇層：這篇要我知道的最重要的一件事是什麼／讀完之後我知道該怎麼做嗎（並說明打算怎麼做）／有沒有哪一句讀了兩次以上才確定意思（寫第一次讀成什麼、第二次讀成什麼）。

最後一題是最便宜的高價值訊號：它讓模型自陳卡頓位置，而卡頓位置在多份之間收斂時，判定成本近乎為零。

## 判讀

| 收斂度       | 判定                                                       |
| ------------ | ---------------------------------------------------------- |
| 全體一致誤讀 | 最強訊號，該處必改；作者與高階 reviewer 都看不到它         |
| 過半收斂     | 候選，逐處判定是句子成分問題還是脈絡問題                   |
| 單份         | 個案；若那一份的讀法構成事實錯誤，仍要檢查句子成分         |
| 零分歧       | 該處的表達沒有問題，不代表內容正確——事實層由別的 frame 管 |

分歧點的修法多數落在補句子成分與具名指涉，不是補段落。判別可機械執行：**把主詞、受詞與指涉對象補回去之後，那一句還讀不懂嗎**——補回去就懂了是成分問題（改句子、不加內容），補回去仍不懂才是脈絡問題（補前情、定義、路由）。兩者的修法方向相反，只看到「讀不懂」就補內容會讓文章持續膨脹而問題還在。

## 一次量測

五個低階模型對一篇約 120 行的技術紀錄執行逐字相同的指令，該篇當時剛通過三輪九個高階 reviewer 的審查並依 finding 改寫過三次。結果：全體一致誤讀一處、過半收斂四處、單份三處，共十處修正，全部是補句子成分與具名指涉、沒有新增段落。

全體一致的那一處，九個高階 reviewer 沒有一個讀錯——他們讀得懂，所以那個位置對他們不構成問題。**低階模型讀不懂的地方，才是真的寫得不夠清楚。**

正面校準同樣重要：五份對「讀完知道該怎麼做嗎」的答案一致且正確，代表文章的主要交付沒有失敗。這個方法分得出主線與支線，不是無差別的噪音來源。

## 這條原則什麼時候不成立

事實正確性、跨檔一致性與承重論點的反證都要高階 reviewer，低階模型在這些維度上的產出不可信。

大量已知形態的掃描仍然由 grep 承擔，那裡它比派模型便宜好幾個量級。本卡處理的是機械檢查覆蓋不到的那一層，不是取代它。

零分歧只證明表達沒有歧義，不證明內容對。這個 frame 與事實查核是兩件事，跑了它不能省掉後者。

限制：一次量測、單篇、單一模型家族；樣本數五是該次用的數字，最佳 N 沒有測。
