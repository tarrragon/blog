# bibliography-verification 版本紀錄

新到舊。

**Version**: 1.0.0 — 新建。書目查證的流程（抽連結與清點沒附連結的書目、依站點登記表分流、curl 抓頁面、瀏覽器查證被擋的網站、連不到書店時的退路、否定宣告、記錄）、欄位與連結層級的判定（含版本不同時錯的是連結、法條引用舊版時查沿革）、對網站的請求守的界線（固定的 User-Agent、被擋不換標頭、robots.txt、只用使用者可見的瀏覽器、同一網站的請求間隔），以及分流腳本 `scripts/fetch_pages.py` 與它的單元測試。站點登記表登記 Amazon、三民、天瓏與一個作者網站用 curl，博客來與全國法規資料庫用瀏覽器（博客來對 curl 回 403；全國法規資料庫的 robots.txt 對所有爬蟲寫 `Disallow: /`）。來源是 2026-11-17 在本機對一份研究方法書單的 23 條連結做的查證：博客來對腳本送的瀏覽器 User-Agent 回 403，改在 Chrome 讀頁面核對；Amazon 對 curl 的預設 User-Agent 回 503，對瀏覽器的 User-Agent 回 200。
